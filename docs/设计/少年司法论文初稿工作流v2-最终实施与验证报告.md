## 五、学到的遣词造句与行文结构

### 1. 遣词造句

学到的是跨作者稳定的功能规则，不是作者句子库：

- 他人观点、法条、事实、比较材料和本文推理必须分清身份；
- 主张强度服从证据能力：描述、关联、机制假说、因果、结构推断和规范建议不能互相冒充；
- 限定语要具体限定样本、法域、时点、对象或证明能力，机械添加“可能”“一定程度上”不能修复推理断裂；
- 转折要改变论证任务，例如“能解释 A，但不能处理 B”，而不是只换连接词；
- 过渡要交代上一节已答什么、还剩什么、为什么必须增加新材料／理论／接口，以及下一节输出什么；
- 反驳先恢复最强版本和有效域，再说明命中点、未命中点和修正后的主张；
- 小结交付后文可直接使用的一句有边界命题，不重复材料；
- 引注紧贴法源、事实、他人观点或比较材料；本文自己的推理桥梁不能借邻近脚注伪装成来源明示；
- 摘要是承诺清单，不是补证；结论只回收正文已经证明的产出、边界和未完成事项；
- 拒绝模仿单一作者的比喻、反问、连续句式、对称标题、数字目录和强识别措辞。

### 2. 章、节与字数

24 篇没有支持“必须五章”或“每节必须两千字”的硬规则，只支持粗略规划：

- 一级功能区：样本 3—7 个，中位数 5；起草时可先按约 4—6 个规划；
- 二级单元：样本 2—20 个，中位数 10.5；起草时可先按约 8—15 个规划；
- 按正文约 2 万字：问题进入约 1000—2000 字；两至三个核心证明区合计约 11000—14000 字；规则／制度输出及边界约 3000—5000 字；另设独立结论时约 600—1200 字；
- 一个完整论证动作的段落组：较常见约 425—975 字、7—15 句，中位约 638 字、10 句；
- 上述区间可以重叠，不机械相加；实际篇幅须在章节功能表完成后，按新题的争点、材料密度和证明责任重算。

### 3. 迁移和用户内容保护

- 主工作流和手册同时保留 normalized 与 exact 新旧历史指纹；
- 工作流和手册的破坏性判断只认保留 Markdown 缩进、空行和行尾空格语义的 exact 指纹；
- 用户改过的主文件、手册和旁本均不覆盖；
- 任何已存在 `.new.md` 都只读，新版递增另存 `.new.2.md`；
- 历史出厂主文件自动升级时，旧件先原子移入 `.user-backup-auto-upgrade-*`，再独占创建新版；
- 用户在校验后恰好保存，内容会恢复到主文件或保留在自动恢复备份；
- 改名后的备份读取、新版创建等 I/O 失败会先恢复主路径，避免工作流从列表中消失；
- Windows FAT/exFAT 不支持硬链接时，改用不覆盖并发目标的原子回移恢复历史主文件；
- 旧合并工作流迁移时，源文件先原子移入 `.agent-ws-migration-backup-*` 私有恢复目录；恢复件永久保留但不进入顶层列表，最终校验后的迟到保存不再被 `unlink` 删除；
- 迁移生成可见保留件时使用硬链接优先、独占复制回退；POSIX 下并发创建的同名目标不会被 `rename` 覆盖；
- 并发创建时用户文件获胜，出厂新版进入安全旁本；
- 自动恢复备份、迁移恢复目录和伴随手册均不进入顶层工作流列表。
