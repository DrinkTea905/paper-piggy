### 3. 全文推理链

印刷链为：

`轻罪出罪压力 → 四项制度功能 → 可观察指标 → 适用率与监督考察偏离 → 适用范围／程序原因 → 扩围＋统一门槛＋两类不起诉排序＋协作考察 → 四层公诉审查`

真实推理依赖由两条链在改革方案处汇合：
