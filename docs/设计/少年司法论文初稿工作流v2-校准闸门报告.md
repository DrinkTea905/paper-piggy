- 并列分类；
- 累积支撑；
- 真正的步骤链；
- 可压缩的背景或标题兑现单元；
- 不可省略的理论、规范或证据转换层。

### 3. `not_present`

`not_present` 是完整字段的明确值，不是漏填。成文总卡中共有 13 个字段使用它，原因如下：

- 6 篇没有规范化“本文创新”自标签，但分别记录了作者明示任务和经裁决成立的真实增量；
- C04、C06 的标题没有明示冲突；C04 标题还没有明示实证方法，正文已经补足；
- C06 不是单一命名理论竞争型文章，因此“单一理论”和“为何非替代理论不可”均为 `not_present`；原文也没有独立结论，G22 据实登记为 `not_present`；
- C02 未发现可可靠归属的个人化比喻或连续标志性句式。

另有 4 篇未进入独立重读，独立重读字段据实写 `not_present`；这与卡片字段缺失不同。

## 七、两条路线目前出现的初步结构原型

以下均是**未冻结候选**，不能进入运行时。

### 1. 依赖驱动的上位原型

> 精确问题 → 不可省略的转换层 → 检验／诊断 → 可追溯输出 → 有限回收

它只描述功能依赖，不规定章节数、标题、篇幅比例或固定顺序。

### 2. 教义学路线候选

> 既有规范／竞说 → 共同解释缺口 → 中层区分 → 法条或程序接口 → 标准／规则

支持：C01、C02、C03，C04 提供实证异型。限制：作者分布仍偏窄；各文的“三重根基”“三说”“四／六／三”“五要素”均不得进入通用原型。

### 3. 理论—制度建构路线候选

> 现实／理论落差 → 对象与适用域 → 理论或机制选择 → 条件／反例压力测试 → 制度边界或有限含义

支持：C05、C07、C08。限制：C07、C08 只提供成年刑事法的方法补强；必须在后续少年司法样本中再验证。

### 4. 实证叠加型设计记录

> 精确缺口 → 透明研究设计与限制 → 分析框架／评价基线 → 分项诊断 → 同轴标准或改革

目前只由 C04、C06 两篇、两组作者支持，不满 3 篇，只保留为设计记录。

完整规则、支持文献、反例、作者分布、适用边界与初步去向见[校准候选规则登记表](少年司法论文初稿工作流v2-校准候选规则.md)。

## 九、对 schema 的修订建议

建议用户确认后，将 `calibration-1.1` 修订为 `calibration-2`，再用于其余 16 篇。建议项不是对现有卡片的否定，而是校准后发现的结构化增强：

1. **增加证据身份阶梯**：至少区分法源／作者命题、样本描述、无控制关联、机制假说、规范评价、未来制度建议。
2. **增加规范输出来源字段**：每一标准或制度动作标记为“前文直接推出／有限经验支持／额外规范论证／待验证政策候选”。
3. **增加理论模式分支**：区分“单一命名理论竞争”与“规范评价前提／分析框架”；后一类不因没有命名理论而判缺陷。
4. **增加理论选择压力测试**：记录替代理论、选择标准、理论新增的解释力，以及该理论可能制造的权力扩张或适用风险。
5. **增加章节关系枚举**：并列分类、累积支撑、步骤依赖、镜像转译、可选增厚、可压缩背景，防止只写自然语言后难以跨卡统计。
6. **增加结尾形态字段**：区分独立结论、正文末尾短回收和无回收；检查功能，不强制“结论”标题。
7. **增加附件边界与版面归属字段**：明确栏目主持语、英文摘要、拼接附件、续页和另一文章的边界。
8. **增加裁决去向的多值结构**：同一争议可出现“主命题保留、子命题降级、表达删除迁移”，避免把复杂裁决压成单一状态。
9. **增加原型证据等级**：单篇标签、同作者重复、跨作者设计记录、一般候选、盲测后冻结，禁止单篇作者习惯提前升级。
10. **强化原创性归属锁**：固定分类、阶段链、原则组、符号、比喻和高识别度标题分别登记，不因近义改写解除归属。

建议保留现有 G01—G26、章节功能图和动作卡主体，采用“新增结构字段＋机器检查”的兼容修订，不推倒重做已裁决卡。
