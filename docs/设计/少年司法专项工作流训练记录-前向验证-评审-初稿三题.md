- 教义学候选规则的法源位阶、解释论／立法论分栏、真实负担、机构—权限—程序—效果—救济闭环、规范资格／事实可靠性双阈值、信息生命周期和八项少年司法闸门，三题均被稳定触发。

- “默认双卡—明确推荐—用户选择前停止”应作为运行时硬闸门保留。

### 2. 无需修改、降级、删除或新增候选根规则

三题没有出现错误路由、第三主路线、保护主义扩权、证据越级或越过用户选择闸门。两项轻微扣分属于既有规则在运行时模板中的显式程度，不构成新方法缺口：

1. 运行时双卡清单应明确要求两条路线在“核心问题、中心观点、三级提纲、材料任务和不适用边界”五处形成实质差异；
2. “所需材料”栏应明确要求进入实体论证的文献逐篇读取并核到精确印刷页。

这两项分别是既有差异化规则和原文核验规则的实现映射，不是候选规则的增删改，因此不触发重新跑三题的回归要求。
