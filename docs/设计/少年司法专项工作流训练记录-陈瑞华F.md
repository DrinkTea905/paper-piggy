### 2. 问题如何提出

- **作者明示**：以审判中心改革、国家监察体制改革和检察公益诉讼扩张三项外部冲击为起点，指出旧有“法律监督”总括说不能解释检察机关的新职责组合，因而需要从改革经验重新提炼法律职能（顺序页 1—3，印刷页 3—5）。
- **训练提炼**：先列制度变化，再问既有上位概念为何失灵，最后把问题改写成“不同任务各自属于何种功能、应配置何种权力并受何种程序控制”。这一“外部冲击—旧概念失灵—功能重分—制度配置”链可迁移。

### 3. 概念如何拆分和界定

- 作者先将检察机关定位为国家利益和社会公共利益代表、法律统一实施的维护者，再把法律职能拆为诉讼职能、监督职能和司法审查职能（顺序页 3—7，印刷页 5—9）。
- 诉讼职能再分刑事公诉与公益诉讼；刑事公诉内部又区分定罪公诉、量刑公诉、程序公诉及特殊没收申请（顺序页 6—8，印刷页 8—10）。
- 监督职能被分为行政监督与诉讼监督；司法审查则以审查逮捕为原型，并与公诉、监督相区分（顺序页 8—14，印刷页 10—16）。
- **训练提炼**：概念不是按机构名称同义反复，而应按决定对象、相对人、法律效果、中立要求和救济接口拆分；同一机构可以拥有多项功能，但不能据此抹去角色冲突。

### 4. 法源与规范关系

- 作者以宪法和刑事诉讼法中的检察定位、公益诉讼改革、监察体制改革及审查逮捕实践为制度背景，但文章主任务是职能理论重构，不是逐条法解释（印刷页 3—5、8—16）。
- 其规范链为：国家/公共利益代表定位→诉讼、监督、审查三类功能→相应权力类型→程序形态与机构关系（印刷页 5—16）。
- **少年司法迁移要求**：任何“未成年人检察一体化”方案都应反向列出法源、权限来源与特别程序要求，不能以“综合保护”替代法定权限。

### 5. 规范、类型、模式或理论如何建构

1. 从三项改革经验证明旧理论的解释赤字（印刷页 3—5）。
2. 以国家利益/公共利益代表和统一法律实施为上位定位（印刷页 5—8）。
3. 按作用对象和法律效果建立三类职能及其子类型（印刷页 8—14）。
4. 以审查逮捕的准司法化讨论司法审查职能，并说明听证化、裁决化趋势（印刷页 14—16）。
5. 用“检察官仍具有追诉取向，不能真正中立”的反例暴露角色冲突（印刷页 13、15—16）。

### 6. 竞争观点与最强反驳

- 最强旧说是把全部检察活动统一归入“法律监督”；作者认为它无法解释公诉、公益诉讼和司法审查的不同结构与效果（印刷页 3—9）。
- 作者反对把法院与检察院都理解为同质司法机关，强调法院为中立裁判者，检察官是国家利益代表和对抗一方（印刷页 8）。
- **尚未解决的外部反驳**：既然作者在侦查监督和逮捕审查部分承认检察官追诉取向、并非中立，却又主张扩大其对强制措施的司法审查，如何用外部审查、回避、听证和救济消解结构性偏向，原文没有完成闭环（印刷页 13—16）。

### 7. 机构、权限、程序、法律效果和救济

| 项目 | 原文与训练记录 |
|---|---|
| 机构 | 检察机关、法院、侦查机关及公益利益相对人；法院被界定为中立裁判者，检察机关为利益代表和法律实施维护者（印刷页 5—9） |
| 权限 | 公诉、公益诉讼、诉讼监督、行政监督、审查逮捕和作者建议的强制措施审查（印刷页 8—16） |
| 程序 | 公诉、抗诉、纠正违法、准司法听证及审查决定等不同程序应与职能对应（印刷页 9—16） |
| 法律效果 | 起诉/量刑请求、纠正违法、抗诉、批准或不批准逮捕等效果不能因同属“监督”而混同（印刷页 9—16） |
| 救济 | 文章谈及抗诉和审查机制，但对检察机关自身准司法决定的外部救济、回避和复审未形成完整设计；应显式记为“原文未展开” |

### 8. 实施条件与边界

- 准司法审查需要调查、听证和裁决能力，但作者同时承认检察官的公诉取向会妨碍真正中立（印刷页 14—16）。
- 作者把检察机关扩大审查描述为现实中的“较小之恶”取舍（印刷页 16），这是特定成年刑事司法机构条件下的方案，不得当作普遍制度原则。
- 人员分工、回避、外部监督、儿童沟通、法律援助和社会支持资源，原文没有展开。

### 9. 严重案件与低风险案件压力测试

- **严重案件**：追诉压力越高，集公诉、监督和审查于同一机构的偏向风险越大；不能因公共安全压力降低独立审查和高证明要求。
- **低风险案件**：若“综合保护”使检察机关同时成为决定者、教育者、监督者和救济入口，可能把支持转为持续控制；应先检验最小干预和退出机制。
- 两项均为少年司法迁移要求，不是作者的实体结论。

### 10. 少年司法八闸门

| 闸门 | 本篇可提供的方法 | 迁入前的补强结论 |
|---|---|---|
| 最有利于未成年人 | 用功能分解防止“保护”总括词掩盖不同权力 | 必须把儿童个体利益与抽象国家/公共利益分开权衡；原文未提供该标准 |
| 发展中能力 | 无直接论证 | 必须按具体决定、理解水平和时间动态评估，不能由年龄或机构判断替代 |
| 支持性参与 | 准司法听证提示程序接口 | 必须配置适龄说明、律师/支持者、表达和复核机会 |
| 关系自主 | 角色冲突审计可识别机构依赖 | 必须审查监护人、检察官和服务机构的权力关系；原文未展开 |
| 最小干预 | 功能与权力逐项对应可防授权泛化 | 不得从“综合保护”推出更广权力；先问是否可由较少干预机关或服务完成 |
| 比例原则 | 不同权力应对应不同对象和效果 | 对自由、隐私、教育和家庭生活的限制须逐项必要、适合、均衡 |
| 机构支持义务 | 功能不能脱离程序能力 | 儿童沟通、有效辩护、社会工作和服务供给必须成为机构义务而非儿童负担 |
| 有效审查与救济 | 暴露同一机构追诉与审查的冲突 | 需设置外部审查、回避、异议、申诉及不利决定的理由说明 |

结论：八项均不能仅凭本篇通过；本篇只提供“功能—权力—程序—冲突”审计方法。

### 11. 合意性安排专项检查

本篇不直接讨论监督考察协议。若将其方法用于附条件不起诉，应先把检察机关的起诉决定、协议协商、服务供给、履行评价、撤销和复核拆成不同功能，再检查是否由同一主体形成不可纠正的闭环。一次签字不能消除这种结构性冲突。

### 12. 可迁移方法与不可迁移实体结论

**可迁移方法**

1. 外部改革冲击→旧概念解释失败→功能重分。
2. 功能→权限→程序→法律效果→救济的全链对应。
3. 同一机构多重角色的兼容性审计。
4. 用最强角色冲突反例检验制度方案。

**不可迁移实体结论**

- 检察机关当然是少年司法中全部国家/公共利益的唯一代表。
- 审查逮捕当然属于检察司法审查，或全部强制措施都应交检察机关审查。
- “较小之恶”、法院现实能力不足等特定制度判断。
- 公诉子类型、抗诉结构及成年刑事诉讼的具体机关配置。

4. 用检察权滥用、信息不对称、值班律师无效和司法审查形式化逐层攻击理想模型（印刷页 14—16）。
5. 再追溯实质真实、实质刑法正义、形式平等、反自由裁量和被告人客体化五项观念/结构障碍（印刷页 16—18）。
6. 以“效率—协商权滥用的长期平衡”收束，而非宣告现行模式已经正当（印刷页 18—19）。

### 6. 竞争观点与最强反驳

- **理想模型**：把被追诉者视为理性经济人，以放弃部分程序和权利换取可预期的量刑优惠；公平协商可使结果具有正当性（印刷页 11—14）。
- **作者自己的最强经验反驳**：在押、缺乏法律知识且没有律师及时帮助者难以有效行使权利，甚至被作者描述为在权利行使上近似“无行为能力”；其与检察官达成的是“城下之盟”，值班律师事后见证不能补足平等协商（印刷页 14—16，尤其 15）。
- **制度反驳**：法院在被告人不提出异议时通常形式确认量刑建议，无法发现被迫认罪、证据不足或检察裁量滥用（印刷页 16）。
- **结构反驳**：缺乏沉默权、有效辩护和足以制衡控方的诉讼筹码，使“协商”缺少对等基础（印刷页 18）。
- 因而本篇最有价值的不是把“公力合作”移植给儿童，而是训练工作流主动寻找使名义协商失真的权力条件。

### 7. 机构、权限、程序、法律效果和救济

| 项目 | 原文与训练记录 |
|---|---|
| 机构 | 检察官主导；嫌疑人参与；辩护人/值班律师提供或未能提供帮助；法院审查；被害人通常只在赔偿后拥有有限否决影响（印刷页 7—12） |
| 权限 | 检察官提出量刑方案和程序选择；被追诉方接受、拒绝或提出意见；律师咨询和协商；法院审查量刑建议与自愿性（印刷页 7—10） |
| 程序 | 阶梯式从宽、量刑协商、具结、快速审理和司法审查（印刷页 7—10、15—16） |
| 法律效果 | 放弃无罪辩护及部分普通程序以换取量刑优惠；法院多采纳检察建议（印刷页 10—14、16） |
| 救济 | 原文批评审查形式化，并建议实质审查和律师全程参与；反悔、上诉、无效及恢复普通程序的完整效果未在本篇形成系统方案 |

### 8. 实施条件与边界

- 真正协商依赖及时律师、阅卷、会见、调查、公开量刑基准、合理报酬和连续代理；原文指出值班律师多数不具备这些条件（印刷页 15—16）。
- 被追诉者的羁押状态、法律知识、信息差和控方威胁/诱导能力会改变自愿性和明智性（印刷页 14—15）。
- 法院必须审查事实基础、法律依据、真实自愿和量刑妥当性；无异议不能成为形式审查理由（印刷页 16）。
- 文化和结构障碍说明，域外制度不能只移植协议形式，还要检查沉默权、律师能力、裁判不确定性、控方筹码和自由裁量控制（印刷页 16—18）。

### 9. 严重案件与低风险案件压力测试

- **严重案件**：量刑优惠和效率压力不得降低定罪证明标准；缺乏律师、证据疑点或存在重刑威胁时，应提高审查强度并保留普通程序。
- **低风险案件**：不能为了提高适用率而用阶梯式优惠、羁押压力或技术性流程制造认罪；低风险者应先考虑无条件分流和最小干预。
- **少年司法迁移**：儿童案件的依赖、权威顺从、发展中能力和家庭关系会放大本篇已经识别的成年协商不对等。

### 10. 少年司法八闸门

| 闸门 | 本篇可提供的方法 | 迁入前的补强结论 |
|---|---|---|
| 最有利于未成年人 | 区分程序获益与权力风险 | 不能把“较轻结果”自动等同最有利；还要比较无条件不起诉和其他更少干预方案 |
| 发展中能力 | 作者已识别知识、羁押和理解缺陷 | 对儿童须按决定逐项评估理解、后果预见、压力反应和能力波动 |
| 支持性参与 | 律师在场时点和实际权限是关键变量 | 需从首次协商前就提供儿童专门律师、适龄说明、支持者和充足时间 |
| 关系自主 | 权威压迫使表面选择失真 | 审查检察官、监护人、律师和服务机构关系；监护人同意不能覆盖儿童反对 |
| 最小干预 | 效率不能独立证明程序必要 | 低风险者先排除起诉和强制条件，不得以协商扩大控制网络 |
| 比例原则 | 筹码和量刑优惠须受界限控制 | 条件、放弃的权利、潜在不利后果与实际风险/需要逐项均衡 |
| 机构支持义务 | 阅卷、会见、调查和实质审查构成制度前提 | 应转化为国家供给义务，资源不足不得由儿童承担不利后果 |
| 有效审查与救济 | 形式审查失败是本篇核心反例 | 设置独立审查、撤回、反悔不加重、协议无效、恢复程序和上诉 |

结论：本篇对八闸门的价值主要是提供反面压力测试；不得把其成年量刑协商正当化直接迁入。

- 对辩诉交易、实质真实和刑法正义的具体评价。
- 量刑协商具有持久生命力或不可或缺的预测。

### 2. 问题如何提出

- **作者明示**：传统程序正义以对抗式审判为经验基础，重过程参与和裁判中立，却不能完整解释认罪认罚、刑事和解等非对抗程序中当事人放弃部分参与以控制结果的现象（顺序页 1—7，印刷页 1—7）。
- 作者不接受“协商司法背叛程序正义”或“程序正义在协商程序中例外”的二元回答，而提出另一种以结果控制为中心的程序正义形态（印刷页 3、10—11）。
- **训练提炼**：当新实践无法被旧理论解释时，先准确标出旧理论的经验域和解释赤字，再提出新理论的概念、要素、根基、适用域和反例。

### 3. 概念如何拆分和界定

- 传统理论内部先分程序工具主义与程序本位主义；作者再将二者共同归入“对抗性程序正义”，其共同焦点是过程控制（印刷页 3—7）。
- “协商性程序正义”以结果控制为核心：当事人通过对话、协商、妥协和放弃部分程序，塑造可接受结果（印刷页 10—11）。
- 作者把它界定为“有限度的纯粹程序正义”：合意不能越过事实基础、罪刑法定、证明标准和罪责刑相适应等外部限制（印刷页 11）。
- 五项要素是可弃权性、弃权自愿性、可协商性、结果获益性和最低限度参与性（印刷页 11—14）。
- 理论根基是诉讼主体性、理性选择和功利主义（印刷页 15—17）。

### 4. 法源与规范关系

- 原文以认罪认罚、刑事和解、争议焦点整理、未成年人刑事程序及企业合规不起诉为经验/制度对象（印刷页 2—3、7—10、17—20）。
- 五要素是理论性评价标准，不等同于现行法条；事实和法律外部底线构成协商处分的限制（印刷页 11—14）。
- **少年司法迁移要求**：原文在印刷页 18 直接提出附条件不起诉和认罪未成年人可适用协商性程序正义，但这一延伸必须由 24 篇少年司法核心重新校验，不能因作者明示而自动成为专项规则。

### 5. 规范、类型、模式或理论如何建构

1. 描述协商实践对传统理论的挑战（印刷页 1—3）。
2. 重构传统程序正义的两派及其共同局限：非对抗程序、庭外程序、客观结果和当事人实体收益（印刷页 3—7）。
3. 比较认罪认罚与刑事和解两种公力/私力协商模式并列出争议（印刷页 7—10）。
4. 提出协商性程序正义，界定其与纯粹程序正义的关系和外部边界（印刷页 10—11）。
5. 提炼五要素（印刷页 11—14）。
6. 以主体性、理性选择和功利主义提供哲学基础（印刷页 15—17）。
7. 延伸至争议焦点整理、未成年人程序和合规不起诉（印刷页 17—20）。

### 6. 竞争观点与最强反驳

- 竞争观点一：协商司法背叛程序正义。作者回应是传统理论只解释过程控制，结果控制也可以体现主体性（印刷页 3、10—15）。
- 竞争观点二：协商程序不需要程序正义。作者以自愿、律师、参与、审查和反悔说明最低程序保障仍不可缺（印刷页 3、9—14）。
- **作者自己记录的反例**：羁押、如实回答义务、无有效律师、检察抗诉和法院量刑风险会压缩自由选择（印刷页 9—10）。
- **最强外部反驳**：理性选择模型假设行为人有完备知识、稳定偏好和计算能力（印刷页 16），却没有说明在权力不对等、贫困、认知差异和儿童发展中能力下如何成立；“结果获益”还可能遮蔽条件负担、长期标签和程序放弃成本。

| 权限 | 放弃或行使程序权利、协商、达成协议、司法审查、反悔和上诉（印刷页 11—14） |

| 法律效果 | 通过放弃部分程序换取量刑、赔偿或不起诉等结果收益；受事实和法律底线限制（印刷页 11—14） |
| 救济 | 作者把程序反悔、提出异议、上诉和转回普通程序列入自愿和最低参与，但不同制度中反悔效力并不一致（印刷页 12—14） |

### 8. 实施条件与边界

- 自愿至少要求知情、真实表达、司法审查和反悔；协商还要求平等对话、实际筹码和律师帮助（印刷页 12—13）。
- 理性选择模型本身以完备知识、稳定偏好和计算能力为前提（印刷页 16）；这是需要检验而不是默认存在的条件。
- 作者承认刑事和解中的赔偿制度、即时履行和结果不确定会制造被迫选择（印刷页 9—10）。
- 对未成年人程序，原文只概括认罪自愿、监督措施自由选择、陈述、庭审和帮教参与（印刷页 18），未构造能力支持、条件调整、技术性违约和独立救济。

### 9. 严重案件与低风险案件压力测试

- **严重案件**：事实基础、高证明标准和实体法底线不能因合意降低；结果越严厉，弃权和协商审查越严格。
- **低风险案件**：结果获益不能成为附加监督和教育负担的自动正当化；应先比较无条件不起诉或更少干预处理。
- **儿童压力测试**：权威顺从或短期获益偏好可能使一次性选择看似“理性”，但不代表能理解长期教育、隐私、升学或撤销后果。

### 10. 少年司法八闸门

| 闸门 | 本篇可提供的方法 | 迁入前的补强结论 |

### 2. 问题如何提出

- **作者明示**：现行法已对未成年人建立附条件不起诉，地方又在醉驾案件探索类似机制；轻罪占比上升背景下，问题不再只是扩大不起诉，而是如何由“治罪”转向“治理”，用差异化监督考察消除犯罪原因（顺序页 1—2、14—15，印刷页 145—146、158—159）。
- 作者把相对不起诉与附条件不起诉区分：前者直接程序出罪，后者因为监督考察和教育矫治更耗资源，不能只用效率论证，而须另寻协商、公共利益、犯罪预防和社会治理基础（顺序页 10—14，印刷页 154—158）。

### 3. 概念如何拆分和界定

- 中国实践被分为轻罪自然人附条件不起诉与企业合规附条件不起诉；前者再以未成年人和醉驾为主要原型（印刷页 145—150）。

### 12. 可迁移方法与不可迁移实体结论

**可迁移方法**

1. 用更简单替代方案检验制度是否具有独立必要性。
2. 中国实践诊断→比较模式→理论基础→完整制度链的建构顺序。
3. 把条件拆为基础/专门类别，再逐项检查目的、必要性和实施资源。
4. 把社会支持组织、专业人员和评估能力纳入制度组件。
5. 从启动、协议、履行、评估到决定建立全流程接口。

**不可迁移实体结论**

- 将附条件不起诉扩至所有可能判处三年以下轻罪。
- 所有参与者都必须承担统一社区服务、报告等基础性惩罚义务。
- 检察机关当然可以充当社会医生、教师和工程师。
- 不履行协议即可恢复起诉而无须区分原因和比例。
- 地方醉驾、德国、美国或企业合规经验可直接移植到未成年人。
- “消除内生犯罪原因”及预防效果已获因果证明。

### 1. 稳定的问题意识

1. **拒绝名义替代结构**：无论是“法律监督”“财物处置”“公力合作”“程序正义”还是“教育矫治”，作者持续追问名义下实际有何功能、主体、权力、程序和效果（2018：印刷页 3—16；2019 对物：204—223；2019 协商：5—18；2021：1—17；2023：145—162）。
2. **从经验到理论**：以改革、地方试点和制度运行作为问题来源，再提炼概念、模式或理论，不满足于法条释义（2018：3—5；2019 协商：5—10；2021：1—3；2023：145—155）。
3. **被决定者的主体化**：反对把当事人当作国家处置对象，强调参与、影响结果和救济；但主体化有时被理解为理性处分和结果获益，留下能力与权力条件争议（2019 对物：211—216；2019 协商：14—18；2021：11—17）。
4. **制度必须形成全链**：概念或价值最终都要落到机构、权限、程序、效果、实施资源和一定救济接口（2018：8—16；2019 对物：214—223；2023：160—163）。
5. **国家权力既是推动者也是风险源**：检察机关能够组织改革、协商和社会支持，却同时可能因追诉取向、裁量、绩效和多重角色使程序失真（2018：13—16；2019 协商：14—18；2023：157—163）。

## 十四、F 批跨文候选规则

> 以下只是供后续跨批提炼和前向验证的候选规则。它们尚未经过 24 篇少年司法核心重新校验、独立复核、交叉对抗和裁决，不能写入运行时工作流。

### A. 教义学候选规则

1. **独立不利益决定对象化**：遇到协议条件、监督评价、撤销等被当作附属事项的决定，分别识别法源、权限主体、相对人、证明对象、法律效果和救济。
2. **弃权/同意的证明命题化**：分别说明签字、沉默、未异议、监护同意和履行行为能够证明的事实；任何一项均不得自动证明理解、能力、公平或持续同意。
3. **条件效力全链**：每一条件都回答制定权限、内容界限、适龄说明、履行能力、变更、违约归责、撤销程序和救济。
4. **机构角色冲突审计**：同一机关兼任协议方、支持者、监督者、评估者、撤销者和复核者时，必须设置分工、回避或外部审查。

### B. 理论—制度建构候选规则

1. **理论假设清单**：任何协商/自主理论先列其知识、能力、偏好、筹码、可拒绝性和资源假设，再用儿童发展和权力关系证据逐项验证。
2. **名义协商—真实协商五层审计**：信息、独立支持、实质筹码、非惩罚性拒绝/撤回、有效审查缺一不可。
3. **更少干预反事实**：附条件方案必须与无条件不起诉、警告和纯服务转介比较；若后者同样实现目的，附加监督不得成立。
4. **服务先于归责**：项目不可达、资源中断和合理调整缺失先归入机构支持义务，不得直接转化为儿童违约或风险。
5. **全周期制度链**：入口筛选→共同形成条件→服务供给→持续参与→阶段评估→条件变更→违约分级→撤销听证→救济→退出与记录后果。

### C. 综述候选规则

1. 将作者纵向材料按“经验诊断—规范理想—制度建议”分层，不把后文自引视为独立验证。
2. 对每一理论同时列出前提、反例、证据层、实施条件和未决争议。
3. “作者观点变化”必须由早期/后期指定页直接支持，并区分真实修正、研究对象变化和表述粒度变化。
4. 协商制度综述至少以权力结构、能力支持、条件负担、审查救济四轴组织，不能只按制度名称或国家排列。
5. 比较法制度、地方实践、规范建议和效果主张分别标注证据强度，项目完成率不得直接写成矫治或再犯效果。

## 十五、少年司法八闸门的本批汇总裁剪

1. **最有利原则**裁剪“结果优惠即最有利”：短期不起诉或从宽只是一个因素。
2. **发展中能力**裁剪“理性人”默认：能力是具体决定、动态并可由支持增强的。
3. **支持性参与**裁剪“最低参与/一次签字”：参与须贯穿条件形成到撤销。
4. **关系自主**裁剪“本人或监护人同意即自主”：需审查权威、依赖和利益冲突。
5. **最小干预**裁剪“附条件总比起诉好”：必须与无条件分流比较。
6. **比例原则**裁剪“教育矫治天然温和”：统一劳动、报告、治疗、限制和失败后果均须实质审查。
7. **机构支持义务**裁剪“不能履行即个人失败”：先审查服务、交通、费用、时间和合理调整。
8. **有效审查与救济**裁剪“检察机关综合负责即可”：协议方、监督者和撤销者不可成为唯一复核者。
