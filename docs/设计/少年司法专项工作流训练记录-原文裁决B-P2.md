本文所称八项迁移闸门固定为：

1. `G1 最有利于未成年人`：保护目的必须落实为可核验的权利与较小净伤害，不能作为扩大权限的口号。
2. `G2 发展中能力`：能力须个别、动态、适龄评估，不能由年龄、罪名、家庭或品格标签替代。
3. `G3 支持性参与`：儿童须获得适龄说明、律师或可信赖成人支持、表达和质疑机会。
4. `G4 关系自主`：家庭、学校、社工和机构关系既可能支持也可能施压，不能把服从或依赖当作真实选择。
5. `G5 最小干预`：只采取能实现具体目的的最低强度、最短期限措施，并设置退出。
6. `G6 比例原则`：措施须有合法目的、适合性、必要性和狭义均衡，严重性不自动替代个案论证。
7. `G7 机构支持义务`：住所、保证、照护、服务和合理调整不足首先触发国家与机构补足义务。
8. `G8 有效审查与救济`：不利决定须有告知、书面理由、记录纠正、定期复核和实质独立的救济。

## 二、Q09：竞争制度模型、规范位阶与实施前提

### Q09-1 用“制度功能轴／制度模式轴”组织争议

- **裁决：**`保留`
- **原文依据：**`UBBSPRAD`第726—730页先检讨保护主义、国家亲权和干预／转处之间的张力，明确不同法制具有不同功能配置；第734—736、741—743页再以支持、矫正、分流组织制度功能。`XDVR96NW`第1217—1221页则并列责任能力、刑事政策、教育矫治和折衷理论，并比较个别能力、列举罪名、恶意补足与例外移送等模式。两文足以支持先问“制度要完成什么功能”，再问“以何种权限和程序实现”，但不能由功能名称直接推出唯一机构答案。
- **八项迁移闸门：**G1要求各功能比较儿童净利益而非口号；G2把能力与年龄、罪名和群体画像分开；G3把儿童参与作为每种模式的共同评价项；G4审查家庭和机构关系中的支持与施压；G5比较各模式实际介入总量；G6逐项比较目的、手段与负担；G7把资源供给列为制度变量；G8把复核和救济列为模式评价的必备轴。
- **双向压力：**严重案件中，该框架允许安全、责任和被害人利益进入比较，但不准以严重性跳过权限和程序；低风险案件中，该框架必须识别“帮助”“教育”名义造成的控制网扩大。
- **D/T/R 去向：**D 用于区分规范目的、权限依据和法律效果；T 作为“功能—模式—实施”三层建模入口；R 用于并列理论谱系与制度模式，不把不同层级观点拼成共识。

### Q09-2 支持、矫正、分流三支柱可以作为作者的功能重构

- **裁决：**`修正`
- **原文依据：**`UBBSPRAD`第734—736页分别论述支持、矫正与分流，第741—743页将三者概括为相互连接的三支柱；但第729—730页已承认制度功能受本国法制结构影响，第734页还警告帮助名义可能扩大法网。因此只能写成该文的分析性重构，并承认三类之间重叠、转换和内部强制差异，不能写成穷尽分类或现行法的自我宣告。
- **八项迁移闸门：**G1每一支柱须证明实际保护效果；G2矫正不能以固定化儿童能力为前提；G3支持与分流均须有真实参与；G4服从机构安排不等于关系自主；G5三类均须计算净控制而非仅看名称；G6内部措施逐项比例审查；G7支持支柱首先形成机构任务；G8矫正和附条件分流的不利后果均须可审查救济。
- **双向压力：**严重案件中，三支柱不能遮蔽限制自由、恢复追诉和公共安全负担；低风险案件中，分流与支持不得因名称温和而自动启动监督、测评和长期记录。
- **D/T/R 去向：**D 不把三支柱当法定分类，只用来提示实质负担审查；T 可用作经修正的功能地图；R 以“作者三支柱模型”具名呈现，并列其网络扩大自我警告和未尽边界。

### Q09-3 三支柱是少年司法唯一、完整且当然正确的制度体系

- **裁决：**`删除`
- **原文依据：**`UBBSPRAD`第729—730页明确强调不同国家法律系统和功能配置差异，第734页承认帮助可能扩大法网；第741—743页提出的是作者的体系化主张，不是对所有竞争模式的经验排除，也不是现行法的明确唯一选择。指定页没有比较所有替代分类、证明穷尽性或给出唯一性规范来源。
- **八项迁移闸门：**G1唯一性会让保护口号替代结果核验；G2抹平儿童差异；G3压缩对模式的异议和选择；G4容易把机构服从当正当性；G5阻断不介入方案；G6取消逐项比例审查；G7可能以体系完整为由忽略资源缺口；G8也无法容纳模式错误的纠正。
- **双向压力：**严重案件不能靠唯一体系预先排除更严格的程序保障；低风险案件不能因三支柱“完整”而必须进入其中一个正式支柱。
- **D/T/R 去向：**D、T 均删除唯一性规则；R 仅保留为该文的理论抱负及其可争议性，不表述为学界共识或现行规范。

### Q09-4 制度名称不能替代对实际强制负担的审查

- **裁决：**`保留`
- **原文依据：**`UBBSPRAD`第734页警告帮助名义可能拓宽法网，第735—736页所述专门教育具有强制、期限不确定和限制自由属性；`XDVR96NW`第1218—1223页提出的保护处分、专门矫治教育及例外移送也会产生显著身份、自由与程序后果。因此“支持”“矫正”“分流”“保护处分”都只是起始标签，法律性质必须由进入、期限、活动、退出、违约和后续效果决定。
- **八项迁移闸门：**G1核算真实净伤害；G2审查措施是否适应个别发展能力；G3保障进入、执行、变更和退出各阶段参与；G4识别家庭和机构同意中的压力；G5选择最低强度和最短期限；G6对每项负担独立论证；G7服务可达不得以附带控制为代价；G8所有重大不利效果均须理由、复核和救济。
- **双向压力：**严重案件可依法采用较强措施，但不能用“保护”降低法定授权和审查标准；低风险案件尤其须防止温和名称下的长期监督、强制教育和信息留存。
- **D/T/R 去向：**D 进入“名称—实际负担—法律效果”审计；T 进入制度负担矩阵；R 作为比较不同模式时的共同评价规则。

### Q09-5 专门教育或保护处分因其教育、保护目的而当然属于非惩罚、非限制自由措施

- **裁决：**`删除`
- **原文依据：**`UBBSPRAD`第735—736页明确记载专门教育的强制性、不定期性和人身自由限制，并由行政教育部门或与公安机关共同决定；`XDVR96NW`第1218—1223页将保护处分和专门矫治教育作为不追诉后的制度方案，却没有把教育目的转换成免除程序保障的法规范。目的不能推翻原文已揭示的实际负担。
- **八项迁移闸门：**G1保护目的不能自动证明净利益；G2不能以矫正需要替代能力评估；G3强制进入须有儿童和辩护人参与；G4家长或学校同意不能消除强制；G5不定期限制违反最低干预；G6自由负担须严格比例审查；G7资源不足不得延长处遇；G8决定、继续和退出均须独立审查与救济。
- **双向压力：**严重案件中也须正面承认自由负担并依法授权；低风险案件中，以教育目的免除保障会最直接造成低门槛、长周期的网络扩大。
- **D/T/R 去向：**D、T 的正面命题删除，并转为“目的不改变实质负担”的禁止规则；R 保留作者方案和保护处分争议，但明确不得将其描述为天然非强制。

### Q09-6 绝对最低责任年龄是优于相对年龄补足的唯一答案

- **裁决：**`保留争议`
- **原文依据：**`XDVR96NW`第1217—1220页系统列出责任能力、刑事政策、教育矫治与折衷理论，并比较个别化能力、罪名补充、恶意补足等路径；作者主张绝对最低年龄，但指定页没有提供足以排除所有替代方案的跨制度效果证据，也没有从上位规范推出唯一精确年龄线。可确认的是年龄例外必须连同能力理论、程序保障和替代处遇一起论证。
- **八项迁移闸门：**G1比较不同年龄规则的净保护与伤害；G2不得把发展能力化约为单一标签，但也不能以个别评估任意击穿底线；G3任何例外判断须适龄说明和辩护；G4家庭顺从不得替代儿童能力；G5刑事介入须最后手段；G6严重案件仍需个案和制度比例论证；G7不追诉后的支持责任不能落空；G8年龄、能力和移送决定须可独立审查。
- **双向压力：**严重案件会检验绝对底线承受公共安全压力的能力，但不能据此自动创设例外；低风险案件会检验相对补足是否把大量儿童推入高强度程序。
- **D/T/R 去向：**D 不冻结具体唯一年龄方案，只保留底线、法定性和禁止任意例外；T 将绝对年龄与相对补足列为竞争模式；R 按理论前提、制度后果和未决证据组织争议。

### Q09-7 独立少年司法优先管辖和成人司法例外移送构成唯一制度结构

- **裁决：**`保留争议`
- **原文依据：**`XDVR96NW`第1220—1223页指出部分域外移送规则以少年司法优先和少年／成人二元结构为前提，并主张中国建立独立少年司法；同时原文承认中国尚无该完整结构，专门矫治教育决定的司法化和保护处分体系亦未完成。指定页没有闭合组织法、案件入口、调查决定分离、预算、人力、地区可达、期限、退出和救济，故只能作为竞争制度模型。
- **八项迁移闸门：**G1须证明独立结构改善儿童净利益；G2须配套发展适配的专业能力；G3须保证儿童在移送前充分参与；G4防止专业关系演变为封闭控制；G5独立机构不能以专业化为由扩大收案；G6移送的严重后果须严格比例审查；G7国家须承担地区可达和服务供给；G8少年管辖、例外移送和保护处分均须书面理由与外部救济。
- **双向压力：**严重案件会检验例外移送标准、证明负担和被害人支持；低风险案件会检验独立体系是否反而制造更多专业调查、处遇和长期控制。
- **D/T/R 去向：**D 仅保留“比较法规则须连同管辖前提解释”；T 将其作为待闭合的竞争制度模型；R 展示其理论理由、组织缺口和与其他模式的张力。

### Q09-8 可以脱离少年司法优先、双重管辖和程序保障而直接移植域外例外移送

- **裁决：**`删除`
- **原文依据：**`XDVR96NW`第1220页明确把部分域外年龄补足和移送规则置于少年司法优先及少年／成人二元结构中，第1221—1223页又以中国缺少独立少年司法和完整保护处分体系作为制度诊断。只移植“例外移送”结论会切断原文自己强调的结构前提。
- **八项迁移闸门：**G1脱嵌移植无法证明儿童净利益；G2会以严重性替代发展能力；G3缺少移送前适龄听证；G4家庭和机构压力无处审查；G5成人司法介入不再是最后手段；G6缺少替代方案和后果比较；G7没有少年支持体系承接；G8缺少独立移送审查和救济。
- **双向压力：**严重案件最容易诱发只取例外、不取保障的选择性移植；低风险案件虽通常不触发移送，但同一逻辑会降低其他年龄例外的门槛。
- **D/T/R 去向：**D、T 的正面移植规则删除；R 可作为比较法方法错误和制度前提脱嵌的反例保留。

### Q09-9 候选制度必须闭合“机构—权限—程序—法律效果—救济—实施资源”

- **裁决：**`保留`
- **原文依据：**`UBBSPRAD`第735—736页显示专门教育存在行政／公安决定、学期评价和自由限制，第741—743页则提出更广的体系和政策安排；`XDVR96NW`第1221—1223页同时暴露独立少年司法、保护处分和专门矫治教育在组织及司法化上的缺口。两文的方案与缺口合读，足以证明仅有功能美德和制度名称不能构成可运行规则，必须补齐决定者、授权、入口、期限、退出、效果、资源与救济。
- **八项迁移闸门：**G1用全链条验证净利益；G2把发展能力嵌入入口和复核；G3把支持性参与嵌入每个决定节点；G4分离支持、评估和不利决定角色；G5规定最低介入和退出；G6逐项对应目的与后果；G7落实预算、人力、服务和合理调整；G8配置独立审查、理由和救济。
- **双向压力：**严重案件要求安全措施有明确权限、短期边界和迅速复核；低风险案件要求无正式介入、自愿支持和记录删除成为真实可选路径。
- **D/T/R 去向：**D 作为制度合法性和法律效果检查表；T 作为方案能否进入候选规则的硬门槛；R 用于区分完整制度模型、作者倡议和未闭合构想。

### Q09-10 统一立法、独立机构或行政／司法归属可以从“保护、支持、矫正有益”直接推出

- **裁决：**`删除`
- **原文依据：**`UBBSPRAD`第726—730页说明功能选择受具体法制和社会系统影响，第735—736页呈现专门教育中教育行政、公安和指导委员会的现有安排，第741—743页才进一步提出体系化政策建议；`XDVR96NW`第1221—1223页关于独立少年司法亦属作者方案。指定页没有把功能价值转化为唯一组织法结论，也未完成不同机构方案的权限、偏差、成本和可达性比较。

- **双向压力：**严重案件中办案者可能因安全压力选择某项原因，不能证明该原因具有一般因果力；低风险案件中须警惕机关认知把贫困、流动或家庭条件转换成羁押理由。
- **D/T/R 去向：**D 作为需要另证的制度认知；T 用于生成实施假说和访谈问题；R 统一使用“受访者认为／选择”，不使用“实际原因占比”。

### Q10-14 问卷原因百分比等于现实高羁押的因果贡献份额

- **裁决：**`删除`
- **原文依据：**`SVNSFFZ3`第133—136页没有测量各因素实际发生、时间顺序、反事实或相互作用，只呈现受访者选择和组间回答差异。百分比不是归因份额，多个选项的选择率也不能解释羁押结果中各因素分别造成多少变化。

- **D/T/R 去向：**D、T 删除因果份额命题；R 仅保留问卷认知分布，不再使用“贡献率”“导致了多少”等词。

## 四、Q09—Q10 冻结后的三套规则去向

### 1. 教义学路线（D）

1. 功能、理论或保护目的不能直接生成机构、权限和法律效果；每一项制度命题须回到法定依据、适用条件、决定主体、程序、期限、退出和救济。
2. “支持”“矫正”“分流”“保护处分”“专门教育”等名称不决定法律性质；以实际自由、身份、活动、信息、违约及追诉后果为准。
3. 比较法规则必须连同其管辖、组织和程序前提解释；禁止只移植例外移送或其他扩权结论。
4. 经验材料进入规范论证前必须标明样本、年代、地区、口径、缺失和证据层级；描述、受访者认知、关联和因果不得互换。
5. 严重个案、公众情绪、同期数字、低撤销率、程序完成和正向自报均不能单独证明普遍规范的必要性或制度效果。

### 2. 理论—制度建构路线（T）

1. 采用“功能—竞争模式—实施闭环”三层结构，不把三支柱、绝对最低年龄、独立少年司法或例外移送冻结为唯一答案。
2. 每个候选模型须完成“机构—权限—程序—法律效果—救济—实施资源”矩阵，并经严重案件与低风险案件双向压力。
3. 专业化、统一化、独立化或司法化均属待比较的组织变量，不能从功能美德直接推出；同时检验角色冲突、地区可达、成本和网络扩大。
4. 试点、问卷和地方调研先生成机制假说；只有具备合适反事实、可比组、统一口径和长期结果时，才升级为因果或普遍化依据。
5. 任何制度效果须同时计算正式控制、自由负担、信息留存、技术性违约、资源排除和退出成本，而非只看轻缓处理或程序完成。

### 3. 综述工作流（R）

1. 以功能轴和模式轴组织支持、矫正、分流、保护处分、年龄规则和少年／成人管辖，明确区分作者模型、现行规范和竞争方案。
2. 对三支柱、绝对最低年龄、独立少年司法等主张，分别呈现理论前提、制度条件、作者自我限制、反方和未决证据。
3. 实证材料统一按“研究设计—样本—测量—描述—关联—因果—外推—限制”书写；问卷比例统一表述为受访者认知或选择。
4. 地方、异年、成人／一般案件和少年材料不得静默合并；无法统一口径时并列展示，不计算虚假的全国当期指标。
5. 被删除的强因果或唯一性命题仍可作为作者观点、方法争议或反例进入综述，但必须显式标注“不得迁入运行时正面规则”。

## 五、严重案件与低风险案件的汇总压力结论

| 争点 | 严重案件压力 | 低风险案件压力 | 冻结结果 |
|---|---|---|---|
| 功能与模式 | 安全、责任和被害人利益可以进入论证，但不能跳过法定权限、儿童能力和程序保障 | 支持、教育和专业化不得成为启动正式介入的充分理由 | 功能轴／模式轴保留，唯一模式删除 |
| 绝对年龄与例外移送 | 极端个案不能自动创设年龄例外；任何例外须证明制度前提和严格程序 | 相对补足和个别评估不得把大量低风险儿童推入高强度刑事程序 | 竞争模式保留争议，脱嵌移植删除 |
| 保护处分与专门教育 | 保护目的不能掩盖自由限制；强措施须有明确授权、短期边界和迅速复核 | 防止教育、分流名义下的长期监督、强制活动和信息留存 | 名称免责删除，实质负担审查保留 |
