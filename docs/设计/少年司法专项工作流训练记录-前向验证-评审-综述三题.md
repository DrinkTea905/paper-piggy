## 七、三题共同模式

### 7.1 已稳定复现的优点

1. **先定范围，再综合。** 三题都固定年龄、阶段、法域、时点和材料用途，支持保留`JJ-R-01`。
2. **按问题而非作者排队。** W04按理论—制度—实施—效果，N05按概念—撤销—响应—救济，C06按规范—机制—结果组织，支持保留`JJ-R-03`、`JJ-R-04`、`JJ-R-05`和`JJ-R-18`。
3. **证据类型决定论断强度。** 三题均能把规范、描述、关联、因果、比较和训练综合分开，支持保留`JJ-R-06`、`JJ-R-10`、`JJ-R-11`。
4. **归属三分法可操作。** 作者原说、作者纵向和训练综合没有发生混同；无同作者证据时敢于不做纵向，支持保留`JJ-R-07`与条件规则`JJ-R-08`。
5. **争议和双向反例没有被抹平。** 严重案件不降低保障，低风险案件不因支持名义扩大控制，支持保留`JJ-R-09`、`JJ-R-14`、`JJ-R-16`、`JJ-R-17`。
6. **窄争点专门规则确有增益。** N05证明`JJ-R-15`能把签字、理解、可履行性、机构失责和不利后果拆开；应保留其条件规则地位。
7. **五项拒绝规则均被正面验证。** 三题没有制造首创/共识/转向，没有把作者模型写成唯一答案，没有把描述升级为因果，没有把成人材料直接迁入，也没有以保护、风险或服务名义自动扩张控制。`JJ-R-X01`—`JJ-R-X05`均应保留。

### 7.2 共同缺口

三题唯一稳定复现的流程缺口是：都有检索词族和检索范围，却都没有完整记录每一轮检索式、命中数、去重后新增候选、由哪篇原文产生了什么新词，以及下一轮为何启动。现有文本足以判断“检索并非单词单轮”，但不足以由独立评审者完全复演。

这个缺口已经被`JJ-R-02`第71—75行原则性要求覆盖，因此不是缺少一个新方法概念，而是现有规则的输出约束不够机械、未形成验收闸门。
