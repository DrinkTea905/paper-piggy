可迁移的最窄链条是：

1. 明确现实问题和材料范围；
2. 划分最小分析单元；
3. 追踪原始来源、接触节点、派生材料和回流路径；
4. 构造材料/机制类型；
5. 另行构造规范目的/法律效果类型；
6. 检查认知偏差、竞争解释和程序资格；
7. 形成可废止结论并保留复审接口。

## 七、对“论文初稿（少年司法版）”可迁移的方法

### 1. 路线定位

三篇的主训练路线均为 **理论—制度建构**。其材料拆分、来源审计、规范资格和救济问题可作为教义学路线的辅助模块，但不据此增设第三条顶层路线。

### 2. 可迁移动作

1. **问题化。** 从高频实践、概念移植失灵或宏观二元争论中抽出可检验问题，分别写明规范缺口、材料结构和实施机制。
2. **来源谱系先于表面一致。** 记录“原始来源—接触节点—转写/派生材料—信息回流—最终使用”；不同文件、人员或机构不自动表示实质隔离。
3. **完美吻合反转测试。** 材料越整齐，越要检查共同来源、提问污染、选择性比较和组织性复制；该动作有 `TMF76MJS` 的原文基础。[268—275]
4. **双版本但不转移责任。** 同时构造主张版本和最强反方版本；未成年人无法形成完整替代故事时，不得据此减轻控方证明责任。
5. **可废止判断。** 将 H 卡的“二次检测”修正为“临时判断—显式偏差攻击—异质材料与竞争假说检验—可废止结论”。异质性、独立检测和竞争假说是复核补强，不冒充作者原文明示。
6. **两步类型化。** 先形成材料/机制类型，再形成规范目的/法律效果类型；两张表相互校验，但任何一张都不能直接推出另一张。
7. **数字系统逐节点审计。** 至少检查输入来源、结构化损失、变量选择、依赖与因果假设、输出解释、机构责任、信息更正和法律救济。
8. **微结构试验。** 将宏大改革缩成有限节点试验，预先写明适用对象、资源、失败标准、退出条件和不利影响；“小数据”不等于代表性或公平性已经成立。
9. **双向压力。** 严重案件中不得降低证明、参与和救济；低风险案件中不得为追求“更准确”而扩大讯问、评估、数据和监督。

### 3. 交叉对抗后必须增加的否决点

- 认识上可靠不能证明程序上合法；程序上合格也不能证明材料独立可靠。
- 信息独立不能证明机构和角色独立；机构分开也不能证明信息没有回流。
- 材料类型不能直接产生规范类型。
- 数据或认知错误能够说明失败原因，但其法律效果、责任和救济必须另由规范来源证明。
- 栗峥方法对合意性安排只提供“同源确认”和“语义损失”辅助审计，不能决定同意的规范效力或真实能力。

## 八、对“综述（少年司法版）”可迁移的方法

1. 用“实践材料—概念单元—关系—类型—结构—理论—回测”组织理论谱系，但逐层标明证据强度。

## 十、迁入少年司法必须增加的八项保护条件

| 保护条件 | 强制检查 |
|---|---|
| 1. 最有利于未成年人原则 | 说明候选方法减少何种错误与伤害；不得只以定罪效率、结案率、履约率或预测准确率为目标；证明责任和错误风险不得转移给未成年人 |
| 2. 发展中能力 | 结合年龄、成熟度、语言、记忆、创伤、残障和具体任务解释一致、不一致、沉默、碎片化表达及决定能力；能力须随时间和决定重新判断 |
| 3. 支持性参与 | 以适龄语言说明材料、选项、后果和救济；律师、适当成年人、社工或独立专家帮助理解与表达，不替代本人；参与须持续、知情并保留改变意见的空间 |
| 4. 关系自主 | 绘制家庭、学校、同伴、社工和办案机构的支持与压力关系；区分原始表达、关系影响和机构转写；签字或多人确认不自动等于真实自主 |
| 5. 最小干预 | 不为增加“印证”、完善类型或训练工具而反复访谈、扩张数据、追加评估、延长监督；低风险案件优先更轻或不介入方案 |
| 6. 比例原则 | 取证、数据范围、条件、期限、共享、监控和不利后果须与案件严重性、个别需要和规则目的相称；技术故障、资源不足和表达误差不得直接升级为危险或不合作 |
| 7. 机构支持义务 | 机构承担说明、原始材料保存、提问记录、资源核验、服务供给、合理调整、履行能力核验、条件变更、错误更正和理由说明，不得把支持缺位转成个人失败 |
| 8. 有效审查与救济 | 允许质疑来源污染、实际隔离、程序资格、类型套用、算法假设、用途越界和遗漏变量；对条件设置、变更、技术性违约、撤销、重新起诉、记录使用和退出后果提供独立、理由化审查 |

### 合意性安排的专门落点

对附条件不起诉、监督考察协议等安排，必须把下列三层分开：

1. **同意事实的可靠性**：是否真实表达、记录是否同源、文本是否失真；
2. **同意的规范效力**：谁有权同意、哪些权利可以放弃、是否需要额外批准；
3. **形成同意的真实能力**：是否持续、知情、可撤回且受到支持，能否履行条件。

一次签字不能补足说明、资源核验、合理调整、履行能力、条件变更、技术性违约区分、撤销和救济。栗峥组只能辅助审计前述第一层中的来源和语义问题，不能替代第二、第三层。

## 十二、交叉对抗后的栗峥组收缩结论

陈瑞华—栗峥交叉对抗不是最终裁决。本卡只吸收能够由三篇栗峥原文和独立复核 09 支持的收缩：

1. **程序价值/证明结构**：栗峥方法可以审计剩余材料是否仍有独立支持及替代版本，但不能用结构可靠取代证据资格、权利保障、证明责任和救济。
2. **国家权力/认知关系**：信息谱系可以把宏观“卷宗依赖”变成可核验节点；但信息不同源不等于机构独立，也不能决定谁有权限设置条件、判断违约或提供审查。
3. **经验/类型**：经验材料先形成解释型的材料/机制类型，再由规范来源形成规范型的目的/效果类型；两步之间禁止直接跳跃。
4. **形式合意/真实能力**：栗峥组只帮助检查“多份确认是否同源”和“结构化标签是否损失语义”，不能证明持续、知情、可撤回且受支持的参与。
5. **规范效果/实施解释**：栗峥组能发现材料生成、转写、共享、聚合和输出中的损失，但数据错误对应何种法律效果和救济必须另由规范链证成。
6. **严重/低风险压力**：严重案件不能要求更完整的儿童反方叙事或降低程序保障；低风险案件不能为追求更完整的证明、评估或数据而扩大干预。

三组固定删除或降级项：

- `非同源 → 统计独立 → 概率相乘`：删除公式化推论；只保留来源审计；
- `完整疑点版本 → 辩方承担替代事实证明`：修正；证明责任不转移并增加支持性参与；
- `材料可靠/多份确认 → 合意有效且能力充分`：删除；只保留辅助来源与语义审计。
