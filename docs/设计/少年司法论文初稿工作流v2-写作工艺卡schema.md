# 少年司法论文初稿工作流 v2：写作工艺卡 schema

> schema：`jj-writing-craft-card-v2-calibration-2`
> 用途：在 v1 研究可靠性卡之上，逐篇保存真实文章的结构、论证动作与功能性表达
> 核心原则：所有字段必须出现；原文没有时填写 `not_present`；不以空白、删栏或“略”代替
> 证据原则：分析性判断必须同时记录印刷页码与判断性质；检索片段、题录摘要和既有卡不能替代重新逐页阅读
> 语言原则：只保存最短定位，不复制长段落，不建立作者句子库，不把近似改写写入运行时材料
> 篇幅原则：原文结构仍以印刷页和正文占比为准；另按“正文 20000 字 × 占比”给出粗略写作预算，不把换算值冒充原文字数实测

## 一、判断性质与缺失值

每个分析性字段只允许使用四种标记：

| 标记 | 含义 | 使用边界 |
|---|---|---|
| `作者明示` | 作者在正文、摘要、引言、结论或注释中直接说明 | 必须能定位到印刷页；不能把训练者概括冒充作者原话 |
| `结构推断` | 由真实标题、篇幅、段落顺序、承上启下或论证结果推断 | 必须说明推断所依据的页段；不得仅凭标题猜测 |
| `训练综合` | 训练者基于同篇多个页段形成的功能性归纳 | 必须列出支撑页段；不得归给作者，也不得在单篇阶段升级为跨文规则 |
| `not_present` | 原文确实没有该内容，或当前全文无法可靠识别 | “没有”本身须说明原因；页码同样填写 `not_present` 或可证明缺失的检查范围 |

推荐的字段书写格式：

> `内容〔判断性质；印刷第 x—y 页〕`

同一字段中若含两个性质不同的判断，应拆成两个子项，不得给整段笼统贴一个标签。

## 二、记录元数据

每篇卡片开头固定包含：

- 样本编号；
- PaperPiggy key；
- 作者；
- 题名；
- 年份；
- 期刊、卷期与印刷页范围；
- 当前期刊等级；
- 全文与深索状态；
- 主路线；
- 可叠加模块；
- 文章类型；
- 可能的结构原型；
- 页码口径与已知异常；
- 篇幅换算口径；
- 原文提取代理；
- 结构对抗代理；
- 论证对抗代理；
- 语言与原创性代理；
- 是否独立重读及独立重读代理；
- 最终裁决者；
- 卡片状态：只使用一个枚举值：`原始提取／对抗中／已裁决／待用户确认`。裁决已经完成但正在等待用户通过校准闸门时，状态写 `待用户确认`，另设“裁决进度：已完成”，不得把两个状态值并写。

“文章类型”和“可能的结构原型”在单篇卡阶段只能作为工作标签，不得写成已经跨文稳定的模板。

## 三、第一层：成文总卡

成文总卡使用下列固定字段表。每一行都必须有内容、判断性质和印刷页码。

| 编号 | 必填字段 | 填写要求 |
|---:|---|---|
| G01 | 论文路线 | 教义学或理论—制度建构；混合、实证、比较、制度史只作模块 |
| G02 | 文章类型 | 如窄争点教义学、原则操作化、经验—制度诊断、理论竞争、类型建构等；保持可反驳 |
| G03 | 可能的结构原型 | 单篇工作标签；不得因一篇文章而创建运行时原型 |
| G04 | 标题限定：对象 | 标题把研究对象限定到何种制度、概念、阶段或材料 |
| G05 | 标题限定：冲突 | 标题显露何种异常、分歧、失败或重构任务；没有则 `not_present` |
| G06 | 标题限定：方法 | 标题是否明示解释、反思、实证、比较、功能、类型或建构方法 |
| G07 | 标题限定：范围 | 年龄、法域、程序阶段、时点、材料或制度范围如何被收窄 |
| G08 | 问题切入类型 | 只从事实异常、规范张力、学说分歧、概念混乱、理论解释失败中选择实际成立者，可多选但须排序 |
| G09 | 引言进入问题的动作链 | 记录从背景到异常、既有答案、失败点和研究问题的真实顺序 |
| G10 | 既有研究的精确答案 | 不写“研究不足”；说明既有研究已经给出了什么具体答案 |
| G11 | 既有答案的具体失败点 | 说明哪一个前提、对象、法源、概念、证据、机制、效果或边界失败 |
| G12 | 核心问题 | 写成可回答的疑问，而非宽泛主题 |
| G13 | 一句话中心命题 | 可被反驳，且能够由正文各部分共同证明 |
| G14 | 作者自述创新 | 只记录作者明示；没有自述即 `not_present` |
| G15 | 原文检验后成立的创新 | 由全文而非自述判断；必须指出兑现在哪些章节 |
| G16 | 创新类型 | 限定为新对象、新区分、新解释链、新类型、新机制、新材料、制度转译，可多选并说明主次 |
| G17 | 使用的理论 | 写明理论对象和具体命题，不能只列理论名称 |
| G18 | 为什么需要该理论 | 与最强替代理论比较；说明不用该理论会留下什么解释或设计断点 |
| G19 | 理论到中层命题 | 记录抽象理论如何转成可检验的中层命题 |
| G20 | 中层命题到评价标准 | 记录中层命题如何生成对象、时点、主体、标准或证明任务 |
| G21 | 评价标准到制度动作 | 记录标准如何生成机构、权限、程序、措施、效果、资源或救济动作 |
| G22 | 摘要—引言—正文—结论兑现 | 分别记录前置承诺、正文证明与结论回收；任何一环缺失均显式标记 |
| G23 | 可迁移技艺 | 只写跨题可复用的结构或论证动作候选，不写来源句式 |
| G24 | 不可迁移实体结论 | 特别标出成年刑诉、域外制度、特定时点或单地样本结论 |
| G25 | 作者个人化写法 | 识别独特比喻、标题习惯、连续句式、标志性术语；默认拒绝迁移 |
| G26 | 论证缺陷 | 记录跳步、证据越级、稻草人、理论标签化、结构冗余、解释论／立法论混同等 |
| G27 | 证据身份阶梯 | 至少区分法源／作者命题、样本描述、无控制关联、机制假说、规范评价与未来制度建议；没有使用的层级写 `not_present` |
| G28 | 规范输出来源 | 将标准或制度动作分别标为“前文直接推出／有限经验支持／额外规范论证／待验证政策候选”，不得用表面顺接代替来源判断 |
| G29 | 理论使用模式 | 在“单一命名理论竞争／多理论组合／规范评价前提／分析框架／not_present”中选择实际模式，并说明为何不按另一模式要求 |
| G30 | 理论选择压力测试 | 记录替代理论、选择标准、新增解释力，以及可能制造的权力扩张、对象错置或适用风险；原文未比较时显式标记 |
| G31 | 结尾形态 | 区分独立结论、正文末尾短回收、无集中回收；只审计功能，不强制标题 |
| G32 | 附件与版面边界 | 记录栏目主持语、英文摘要、拼接附件、续页、参考文献或另一文章的边界；无异常则写明核查范围 |
| G33 | 原型证据等级 | 只允许“单篇工作标签／同作者重复／跨作者设计记录／一般候选／盲测后冻结”；单篇卡通常不得高于单篇工作标签 |
| G34 | 原创性归属锁 | 登记作者的固定分类、原则组、阶段链、符号、比喻、高识别度标题和组合；说明可迁移动作与必须保留归属的内容 |
| G35 | 全文篇幅分配与 2 万字换算 | 汇总各一级部分的原文比例，并按正文 20000 字粗略换算写作预算；明确其不是原文字数实测，也不是固定模板 |

## 四、第二层：章节功能图

### 1. 真实标题树

先逐字记录原文全部一级、二级标题及其顺序，不改写、不补造。无标题引言、结论或过渡段可另设“无标题单元”，但“原文真实标题”必须填写 `not_present（无标题）`。

标题树表固定包含：

| 单元号 | 层级 | 原文真实标题 | 起止印刷页 | 约占全文比例 | 约合 2 万字稿字数 | 上位单元 |
|---|---|---|---|---|---|---|
| S00…Sn | 一级／二级／三级／无标题 | 逐字记录或 `not_present（无标题）` | 必填 | 以正文页近似估计并说明口径 | 以比例 × 20000 粗略换算；内部再分配或不计正文时写明 `not_applicable` | 必填 |

### 2. 逐单元功能记录

标题树中的每个一级、二级或无标题功能单元，都建立一条以 `Sxx` 为主键的完整功能记录。允许三种等价物理形态：

1. 每个 `Sxx` 建立完全自足的小节，重复标题、层级、页码和比例并完整填写下列字段；
2. 使用规范化联表：标题树保存“标题、层级、页码、比例、上位单元”；其余功能与依赖字段既可放在一张合并表，也可拆成“局部问题至论证方法”与“最强竞说至调换断裂”两张表。所有表都以唯一 `Sxx` 外键一一对应。
3. 使用“标题树＋逐 `Sxx` 小节”的键控联结：标题树保存“标题、层级、页码、比例、上位单元”，逐 `Sxx` 小节保存其余功能与依赖字段。两处必须用同一唯一 `Sxx` 一一对应；不得把多个单元合并进同一小节。

采用后两种键控联结形态时，完整性按标题树与功能记录的同一 `Sxx` 联结后判断，不要求重复抄写标题、层级、页码和比例。每张功能表的每一行或每个小节的每条分析记录仍须有判断性质和印刷页码；只有同一行或同一条记录中的所有分析字段确实共享同一证据基础和判断性质时，才允许在行末合并标注一次，否则必须拆行或在格内分别标注。

联结后的完整记录必须包含：

- 原文真实标题；
- 标题层级；
- 起止页；
- 大致篇幅比例；
- 约合 2 万字稿字数；
- 本部分的局部问题；
- 局部结论；
- 在全文中的功能；
- 输入前提；
- 规范、理论或事实依据；
- 使用的论证方法；
- 要回应的最强竞说；
- 输出到下一部分的命题；
- 与前一部分的依赖关系；
- 与后一部分的依赖关系；
- 印刷结构与真实推理结构是否一致；
- 章节关系类型：并列分类／累积支撑／步骤依赖／镜像转译／可选增厚／可压缩背景／入口问题化／结尾回收／附件边界，可多选但须解释；
- 如果删除本部分会造成什么论证断裂；
- 如果与相邻部分调换会造成什么论证断裂；
- 判断性质；
- 印刷页码。

不得把“介绍背景”“分析问题”“提出建议”当作充分的章节功能。功能必须说明该部分为中心命题增加了哪一个必要前提、区分、证明、反驳、制度接口或边界。

### 3. 全文推理链

在章节功能图末尾，以单向链或有向图形式记录：

> `输入问题 → 必要区分 → 核心证明 → 反方处理 → 制度或规范结论 → 边界`

若印刷章节顺序与真实推理依赖不一致，必须同时画出两条链并说明差异。

## 五、第三层：论证动作卡

### 1. 数量与覆盖

每篇选择 6—10 个关键段落组。覆盖台账固定检查：

1. 引言的问题转折；
2. 研究缺口；
3. 中心命题或创新限定；
4. 一个核心证明；
5. 一个概念界定或类型划分；
6. 一个最强反驳；
7. 一个章节过渡；
8. 一个结论回收。

同一段落组可以承担两个相邻功能，但不得为了凑数把同一段重复登记。原文确实没有某类动作时，覆盖台账写 `not_present` 及检查页段；不得虚构一张卡。

### 2. 单张动作卡字段

每张 `Axx` 卡必须完整包含：

- 所处位置；
- 主要功能；
- 主张；
- 理由；
- 材料；
- 从材料到结论的推理桥梁；
- 反方如何被呈现；
- 反方如何被限缩或回应；
- 段落内部动作顺序；
- 怎样进入；
- 怎样退出；
- 主张强度；
- 限定语；
- 转折方式；
- 引注如何嵌入；
- 段落组粗略字数、粗略句数与引注位置；
- 印刷页码；
- 最短必要原文定位；
- 训练者重新表述后的通用动作；
- 判断性质；
- 不可迁移内容。

相邻字段可以在一行中用“／”合并，但字段名必须全部显式出现；该行末尾必须有一个单一允许的判断性质和印刷页码。只有该行各字段共享同一证据基础和判断性质时才可合并，否则拆成多行分别标注。不得用卡内其他行的标签笼统覆盖未标注的分析字段。

“通用动作”须改写成功能指令，例如：

> 先把对方命题恢复到最强版本，再指出其成立所依赖的隐藏前提，最后用本题材料证明该前提不成立。

不得写成接近来源句子的替换词版本。

“段落组粗略字数、粗略句数与引注位置”只用于控制论证密度，不要求 OCR 精确计数。允许使用区间，例如：

> `约 250—450 字／约 4—7 句／法源引注位于规范命题后，理论引注位于推理桥梁后〔结构推断；印刷第 x 页〕`

不得从粗略句长、连接词频率或作者惯用词反推出可模仿的个人文风。

### 3. 原文定位长度

- 只保留能让复核者在原页找到段落的最短词组；
- 原则上不超过 25 个汉字或 25 个英文词；
- 能用“标题＋页码＋首个特征词”定位时，不复制完整句；
- 不保存连续长句、整段、作者句式模板或可供模仿的句子库。

## 六、对抗、独立重读与原文裁决

每篇卡片在三层记录之后固定增加：

### 1. 结构对抗

逐项回答：

- 是否只是“现状—问题—完善”；
- 各部分是否真的推进中心命题；
- 是否把印刷顺序误当推理顺序；
- 结构原型是否只是作者个人习惯；
- 删除或调换测试是否支持原判断。

### 2. 论证对抗

逐项回答：

- 创新是否只是换概念或标题；
- 理论是否只是标签；
- 证据与结论之间是否缺少桥梁；
- 最强反方是否被稻草人化；
- 规范解释与未来立法是否混在一起；
- 描述、关联、因果与外推是否越级。

### 3. 语言与原创性

逐项回答：

- 是否有宏大空话或无功能模板句；
- 是否依赖引文串联代替作者推理；
- 主张强度是否超过证据；
- 是否出现单一作者标志性表达；
- 通用动作是否构成近似改写；
- 框架、概念和材料归属是否清楚。

### 4. 独立重读

适用时记录：

- 独立重读范围；
- 独立形成的标题树与核心推理链；
- 与主卡一致项；
- 分歧项；
- 指定回查页；
- 是否涉及字段缺失或页码问题。

### 5. 原文裁决

每个争议字段只允许：

- `保留`；
- `修正`；
- `降级`；
- `保留争议`；
- `删除`。

每条裁决固定包含八个字段：状态、裁决分层、争议、支持理由、反对理由、重新打开原文页、最终内容、候选规则影响。“状态”仍只取上述五个主枚举；“裁决分层”可分别说明主命题、子命题、证据强度、表达迁移或运行时去向，避免把复杂裁决压成一个结果。代理多数票、作者声望和期刊等级均不是裁决理由。

## 七、候选规则登记 schema

跨文总结代理只能读取“已裁决”卡片。每条候选规则建立独立记录：

| 字段 | 要求 |
|---|---|
| 规则 ID | 稳定、可追踪 |
| 候选规则 | 写成跨题方法动作，不写某一篇答案 |
| 支持论文 | 列 key、作者与具体卡片字段 |
| 反例 | 至少记录真实反例；没有反例只可保持候选，不得直接进入手册 |
| 作者分布 | 计算独立作者数，合著论文按文章作者组说明 |
| 适用路线 | 教义学／理论—制度建构／两者 |
| 适用题型 | 明确触发条件 |
| 不适用边界 | 明确失败条件 |
| 来源性质 | 作者明示／结构推断／训练综合 |
| 原创性检查 | 是否来自单一作者表达、独特比喻、连续句式或单篇结构 |
| 原型证据等级 | 单篇标签／同作者重复／跨作者设计记录／一般候选／盲测后冻结 |
| 规则去向 | 核心工作流／伴随手册／仅留设计记录／拒绝 |
| 裁决理由 | 说明为何承受反例后仍成立或为何拒绝 |

一般规则进入运行时手册前，至少满足：

- 跨 3 篇；
- 跨 2 名作者；
- 有反例或压力测试；
- 不依赖单一作者的句式、比喻、标题或结构；
- 能说明路线、题型和不适用边界；
- 不削弱 v1 的原文、法源、领域与少年司法专门闸门。

## 八、schema 完整性检查

### 1. 单篇硬检查

每篇必须同时满足：

- 记录元数据字段全部出现；
- G01—G35 全部出现；
- 标题树覆盖原文全部一级、二级标题；
- 每个标题树单元都有完整功能记录；
- 每个标题树单元都有正文占比和 2 万字粗略换算，内部再分配或附件边界有合规的 `not_applicable`；
- 每个一级、二级或无标题功能单元都有章节关系类型；
- 每篇有 6—10 张真实论证动作卡；
- 每张动作卡都有粗略字数、句数和引注位置；
- 八类动作覆盖项逐项有卡号或 `not_present`；
- 所有分析性字段有允许的判断性质；
- 所有分析性字段有印刷页码或合规的 `not_present`；
- 无空值、`略`、`同上`、`待补`、裸检索片段；
- 最短原文定位不超过长度上限；
- 对抗三组字段齐全；
- 争议均有原文裁决状态。

### 2. 批次报告

校准集和深读集分别报告：

- 卡片完成数；
- 字段完整卡数；
- 缺字段总数；
- `not_present` 数量及原因分布；
- 章节单元数；
- 论证动作卡总数与每篇分布；
- 独立完整重读数及比例；
- 争议字段数与五类裁决分布；
- OCR、印刷页码、附件边界或标题识别问题；
- 近似改写与单一作者风格拦截数。

只有真实达到 8/8 或 24/24 字段完整，才可这样报告；旧 v1 卡片的字段完整率不得替代 v2。

### 3. 闸门

- 不处理其余 16 篇；
- 不打开盲测写作工艺；
- 不冻结候选规则；
- 不生成运行时手册；
- 不修改 `src/agent_ws.py` 或产品读取逻辑。

本项目的 8 篇校准闸门已于 2026-07-29 经用户明确确认。此后允许：
