# 少年司法专项工作流训练记录：候选规则——综述

> 形成日期：2026-07-28  
> 适用工作流：`综述（少年司法版）`  
> 规则性质：裁决后、去重后的候选根规则；尚待前向验证，不是产品实现稿，也不是实体法结论。  
> 证据范围：六份原文裁决（A-P0、B-P0、A-P1、B-P2、C-P2、C-作者组）、陈瑞华与栗峥作者纵向卡、陈瑞华—栗峥交叉对抗、素材总索引与饱和判断。  
> 素材基线：40篇完成逐页精读、双卡和训练角色，其中少年司法共享核心24篇、陈瑞华13篇、栗峥3篇；14篇由另一代理独立全文复核，占35%。`KCM4JYNW`排除；`Z3GBTTSC`仍为`deep=false`且0角色、0规则；第二篇新增栗峥论文尚未进入元数据，不猜题名或key。  
> 饱和口径：根动作词汇趋稳，但A—H没有连续两批同时满足“无新增方法动作、无实质修订”，严格饱和未获证明；当前亦没有足以触发额外1—6篇补文献的明确方法缺口。  
> 状态词表：`候选-必需（待前向验证）`、`候选-条件（待前向验证）`、`保留争议`、`拒绝`。`保留争议`只能显式呈现分歧，不能变成折中结论；`拒绝`不得进入正面规则。

## 五、进入前向验证的边界

1. 正面候选规则已合并同义根动作；相同方法被多篇重复支持时，不按文章数生成重复规则。
2. `保留争议`只用于综述中显式组织双方论证，不能成为路由器自动选定的中心结论。
3. `拒绝`项可以作为具名观点史、方法反例或证据边界出现，但必须紧邻说明“不得进入正面规则”。
4. 前向验证若出现路由混同、范围失控、作者流水账、证据越级、虚假因果、争议被抹平或八闸门空转，应先回到对应原文页与裁决修正规则；只有出现现有动作无法处理的结构性失败，才重新评估是否触发额外1—6篇正式训练素材。
