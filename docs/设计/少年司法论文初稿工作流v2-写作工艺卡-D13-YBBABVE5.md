### 3. 全文推理链

印刷链为：

`法定混合类型异常 → 概念与外延限定 → 法律性质区分 → 独立分级 → 竞合与处分效果 → 保护主义校验 → 先议机关比较 → 法院统一先议 → 少年法化边界`

真实推理依赖由两条支撑链汇合：

- `违警／触刑性质区分 → 独立分级 → 特别法、一事不再罚与比例审查 → 排除保护处分与治安处罚并合`〔训练综合；第270—274页〕；
- `保护主义的程序再造 → 先议机关须承担诊断与处方 → 福利／司法模式比较 → 作者选择法院统一先议`〔训练综合；第274—281页〕。

两链在“未成年人违警行为应脱离成人治安法并进入独立少年司法”处汇合。故一级部分的印刷顺序大体合理，但不能把“法院先议”写成由竞合规则直接推出；概念史理由也只是命名正当性的累积增厚，不是后续全部结论的硬前提〔训练综合；第267—282页〕。
