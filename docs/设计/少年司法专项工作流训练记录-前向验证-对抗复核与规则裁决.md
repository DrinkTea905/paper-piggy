## 二、R-C06 计数错误与定向回归

### 1. 原始错误

R-C06 原始输出的证据矩阵写道，Lawson、Narkewicz、Vincent（2024）系统综述包含“21项美国研究、13种工具、5项少年司法样本”。

### 2. 原文正确口径

指定原文页表显示：

- 纳入 21 篇美国研究；
- 其中只有 5 个少年司法样本；
- 涉及 **8 种经验证的风险评估工具**；
- 另有 **2 种研究者自制工具**；
- 3 篇 JDAI 研究评价的是更广泛的 Juvenile Detention Alternatives Initiative，工具只是项目组成部分，**不能再计作 3 种额外工具**。

正确替换句应为：

> “该系统综述纳入21篇美国研究，涉及8种经验证的风险评估工具和2种研究者自制工具；另有3篇研究评价JDAI这一更广泛项目，不能把它们再计成3种工具。21篇中只有5个少年司法样本。”

### 3. 错误性质

这是一个孤立、可定位的类别计数错误：

- 没有伪造作者、来源、页码或阅读状态；
- 没有改变“21篇均来自美国、只有5个少年样本、证据质量有限、不能外推中国”的中心判断；
- 没有扩散到规范结论、因果判断或制度推荐。

因此保留原始输出和首轮 95 分，不将其改写成“从未出错”；同时按正确口径完成定向回归。

### 4. 回归结果

按正确口径重查 R-C06 的“证据地图与证据能力”“来源忠实与页证可追溯”两项：

- 证据地图恢复为 10/10；
- 页证忠实度恢复为 10/10；
- 其他七维不变；
- 定向回归分为 **97/100**，仍为 0 项硬失败。

更正后的六题平均分为 **97.33/100**。原始错误、正确口径和回归过程均已显式留痕，满足“发现失败后定位、裁决和复核”的要求。

## 三、JJ-R-02 争议裁决

综述评审建议把 `JJ-R-02` 改成强制结构化检索台账，因为三份输出虽记录词族、范围和补检目的，却没有完整列出每轮命中数、去重新增数和候选流转。

对候选规则原文复查后，裁决为：**规则保留，不作修改**。

理由：

1. `JJ-R-02` 的 operation 已明确要求“保存每轮检索词、命中范围与新增词来源”；
2. expected_output 已要求“分词族检索表及迭代记录”；
3. 三题的共同扣分来自生成侧没有完全执行既有要求，不是候选规则缺少方法动作；
4. 再增加一条同义根规则或把同一动作换句话重复，不会解决执行验收问题，反而制造重复规则。

处理去向：

- 候选规则：`JJ-R-02` **保留**；
- 运行时工作流：在“完成标准”中把既有要求操作化为必检台账，至少含轮次、精确检索式、范围/排序/Top-k、命中数、去重后新增数、纳入/排除/待核数、新词及来源、下一轮理由；
- 这属于完成标准与验收映射，不改变候选根规则，不触发 R-W04、R-N05、R-C06 全套回归。
