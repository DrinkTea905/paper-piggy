## 六、由 Q01—Q03 形成的三套候选规则

### 1. 教义学候选规则 D

1. 任何社会调查、心理评估和观护信息均按“字段—阶段—效果—主体—数据—救济”审查，不对整份报告作一劳永逸的证据定性。
2. 犯罪事实必须脱离处遇、支持和服务报告，依定罪证据程序收集、披露、质证并达到相应证明标准；成长背景、品格、贫困、支持缺口、服从和观护表现不得填补犯罪或责任事实。
3. 行为时责任能力、当前受审能力、具体决定理解、参与偏好、处遇需要和国家支持义务分别确定对象、主体、标准和法律效果。
4. 国家支持可以消除可补救的参与障碍，不能创造行为时责任、改变年龄门槛或以机构不足降低儿童程序门槛。
5. 一次签字仅是时点性程序记录；重大条件和阶段变化须重新说明、核验理解、听取意见并允许申请变更。
6. 对非必要服务、心理测评和教育活动可拒绝或撤回且不得作不利推论；整个附条件不起诉处分撤回后的实体效果保留争议，但必须有正式申请、律师帮助、书面理由和独立复核。
7. 一般履行事件先核验原因、能力、资源和机构支持；技术性违约不得自动触发延长期限、羁押、撤销或起诉。

### 2. 理论—制度建构候选规则 T

1. 将调查、评估、支持、监督、追诉和最终决定角色分开；无法完全分离时，至少建立信息防火墙、利益冲突披露、辩护参与和外部复核。
2. 把住所、保证、交通、学习、照护、治疗和服务缺口列入机构支持清单，不得编码为儿童危险、恶意或不配合。
3. 建立持续参与链：初始说明—理解核验—本人表达—意见回应—条件形成—履行支持—定期复核—变更／撤回—救济。
4. 建立报告用途链：收集授权—最少字段—来源和方法—适龄查阅—更正／补充—阶段开放—禁止反向不利使用—保存与删除—独立救济。
5. 建立履行事件链：事实记录—儿童解释—资源与能力核验—机构失责核验—合理调整—比例回应—重大不利决定的独立审查。
6. 严重案件增加证据、支持和被害人安全保障，不降低能力、参与和审查标准；无风险或低风险案件优先不调查、无条件分流或自愿支持，防止控制网络扩大。

### 3. 综述候选规则 R

1. 以“社会调查的非证据处遇说—酌定量刑证据说—恶意／责任能力材料说—追诉与观护表现使用”组织竞争模式，不把它们压成报告整体定性的单一争论。
2. 分别梳理责任能力、受审能力、参与状态和国家支持的概念演进；`UVE565B9`的“双重受审能力”按作者原词呈现，同时说明运行时已修正为“儿童能力—国家支持义务关系审查”。
3. 对参与研究区分直接作者主张与训练迁移：`F2EI6QQ8`直接支持五要素、持续说明和反馈，`I94VN74H`直接支持理解、选择和条件变化事实，`WMMXTGHA`直接支持一次申请／监护同意的地方实践；撤回权、技术性违约和完整救济属于跨文献规范提炼。
4. 固定保留三组未决争议：社会调查在独立量刑阶段的不利用途及证明强度；充分支持后仍无最低受审能力的程序效果；撤回整个附条件不起诉安排后的实体法律效果。
