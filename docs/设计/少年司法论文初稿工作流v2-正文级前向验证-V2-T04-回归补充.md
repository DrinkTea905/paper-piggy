## 二、法源与证据边界

1. 联合国原则、加拿大法和项目规则在原始材料中主要经学术论文转述；正式面向中国制度输出前应直接核对原始规范及其现行效力。
2. “责任裁判—修复参与—有利后果三项分离”“四级方式”是本文的中层模型。来源能够支持其风险前提和若干保护要素，不能证明该分类已是通说、唯一方案或经验最优。
3. 现有材料不能证明严重未成年人犯罪中恢复性司法普遍降低再犯，也不能证明某一种直接接触形式优于间接修复。
4. 原始中国材料足以揭示未成年人发展、贫困赔偿和过度责任化风险，不足以代替中国严重案件、被害人体验和长期项目数据。
