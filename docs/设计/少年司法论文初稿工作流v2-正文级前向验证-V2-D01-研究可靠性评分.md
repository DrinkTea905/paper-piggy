## 二、六维评分

### 1. 来源真实性、全文阅读与页码准确：23/25

**得分依据**

- 法源 `SAKBMYLE` 确为《中华人民共和国刑事诉讼法》转存全文。PDF第12—13页可核对第56—60条，PDF第47页可核对第238条，PDF第55页可核对第277—281条。原稿没有把工具推算的“印刷页8”当成真实印刷页，而是以法条号与 PDF 顺序页定位。
- `F2EI6QQ8` 第128页确有首次讯问未及时到场、交流时空有限、隔离设备影响听见等材料；第131—133页确有知情、理解、表达、考虑、反馈五环节，以及签名效力、重新讯问、沟通抚慰教育和值班制度等改革建议。
- `9TA7JQQS` 第51页明确称律师在场不能替代合适成年人到场，两者功能不同。
- `7QX3VRSK` 第24—27页确实区分强制程序与操作性方法，并主张违反后果须结合场景；原稿正确把该文限定为未成年被害人、证人询问的方法论旁证。
- `6Z8PCVBF` 第158—164、170—174页确有成年人支持、适龄解释、沟通、参与环境与未成年人理解表达之间的论述。该来源在正文中没有承担关键独立结论，但来源表中的概括与原文相符。

**扣分**

- 引言写道“该条同时要求由熟悉未成年人身心特点的人员办案、保障法律帮助”，紧邻的“该条”在语法上指第281条；逐页核对显示该内容实在第277条，指定法律援助在第278条，第281条规定的是讯问、审判到场及到场者权能。原稿引用范围写成“第277—281条”，没有虚构法源，但具体条文归属不够精确，扣1分。
- 关键规范结论“严重且无法核验的原笔录不得作为定案根据”没有对应现行统一司法解释或指导性案例原文。原稿已承认这是教义方案，故不构成来源虚构，但来源覆盖仍少一层裁判或解释验证，扣1分。

### 2. 法源层级、时点和解释论／立法论：13/15

**得分依据**

- 以《刑事诉讼法》第56—60、238、277—281条为法源起点，学术文献仅用于解释功能、实践问题和改革方案，没有倒置法源层级。
- 明确指出第281条没有“一切违反自动排除”的明文后果，也没有把尹泠然的签名排除方案写成现行法。
- 对第59条证明责任能否扩张到纯粹第281条争议、紧急讯问能否构成例外、二审是否发回，均使用“本文主张”“解释方案”“仍为 unknown”等标记区分解释论与立法论。
- 法源转存件下载于2023年，原稿没有宣称存在更晚修法状态，也没有用散文页码替代条文号。

**扣分**

- 未直接取得和核对与未成年人讯问、非法证据排除相衔接的现行司法解释、排非规程及可代表裁判，导致五类后果中除第56条排除与第238条发回外，其他后果的现行法地位主要依赖体系解释，扣1分。
- “紧急询问可用于救援和线索、定罪使用严格限制”的边界具有合理性，但缺乏一手规范或案例作为现行解释锚点，只能作为立法／解释建议，扣1分。

### 3. 规范、理论、事实及证据能力：18/20

**得分依据**

- 清楚区分到场义务是否履行、未成年人是否有效参与、供述是否自愿、内容是否可靠、证据能否使用和证明力大小，避免以“真实”吸收程序合法性。
- 能把无理由缺席、对象不适格、形式到场、紧急讯问和记录缺陷分别连接至不同后果，不从单一事实直接跳到排除。
- 对尹泠然实证材料保持样本与议题边界，没有把局部实践描述扩张为全国发生率。
- 将被害人、证人询问文献降格为方法迁移，并显著写明对象不同，迁移路径可见。

**扣分**

- “严重且无法核验即不得作为定案根据”仍需要更精确说明它究竟来自证据真实性门槛、程序性制裁还是公平审判要求；目前三种根据有所并列，规范基础尚未完全收束，扣1分。
- 重复讯问“五因素”的经验基础主要来自规范推理，未有本土案例或供述变化研究验证；原稿虽列为不足，但该核心工具的证据能力仍有限，扣1分。

### 4. 少年司法专门性和迁移闸门：19/20

**得分依据**

- 全文围绕未成年人的理解、顺从、情绪支持、适龄沟通、首次讯问保护时机和合适成年人的独立功能展开，没有把一般非法证据规则直接覆盖少年司法。

**扣分**
