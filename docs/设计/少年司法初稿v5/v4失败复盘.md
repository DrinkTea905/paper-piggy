# v4 失败复盘（2026-08-14）

> **v4 已由用户判为废稿，永不发布**：禁止安装、执行、随应用发布、作为改造基础。
> 三份文件保留在 `docs/设计/少年司法初稿v4/`（均已加⛔废稿戳），**只作失败样本**；
> 全仓 grep 确认 v4 在 `docs/设计/` 之外零引用，从未进入 `src/`、技能目录或发布链路。
> 连带处置：`0_Agent交付物/核准追诉新稿C_v4/` 是 v4 的产物，**不得当作有效前稿引用**。
>
> 本文只记**为什么失败**，供 v5 重训时不再踩。

## 1. 决定性的事实：指标全绿，稿子仍烂

用 v4 自带的 `check_style.py` 测丙稿（`0_Agent交付物/核准追诉新稿C_v4/`，正文 27,639 汉字）：

| 档 | 结果 |
|---|---|
| §5.1 统计型上限 5 项 | **全过**（有论述 0、本节本章 0、这一X 6.15、凑三 2.53、本文 6.87） |
| §5.2 体例型禁区 6 项 | **全过**（「」引号 0、半角空格 0、术语泄漏 0、开篇三件套 0） |
| §5.4 下限 2 项 | **全过**（例如 1.09、转折 6.87） |
| §5.6 讲解腔 | **0 处** |

**指标体系宣告通过，用户判定很烂。** 这一条比任何分析都重要：

> **可数指标可以被优化到全绿，而文章质量不随之改善。**
> v3 的病是"下限配额诱发凑数"，v4 换成"上限"以为解决了——实际只是把优化目标换了个方向，模型照样只优化那个目标。

## 2. 三个根因（全部是本轮自己造成的）

### 根因一 ★ 诊断对了，药没开对：句子层依然是空的

v4 诊断报告 §2 根因一写得很清楚：

> 训练管线在数据层把「句子」删干净了……模型拿到「结构规则＋零句子样本＋禁止修辞」，句子层没有任何目标，只能回落到默认分布。

**然后 v4 自己一句真刊句子都没有给。** §3 给的是"论证动作"（起手式六型、反驳七断点、立法论七支点），全是**做什么**；关于**怎么说**，v4 只有三档词表——而词表只能否定，不能生成。

v3 至少还有一本 56 条模板的句型库（虽然被配额用坏了）。v4 把它整个删掉，**没有替代物**。等于诊断出"病人缺营养"，然后把他的饭也端走了。

### 根因二 ★ 零前向验证就交付

v2 的管线有 6 道未见题的正文级前向验证并分维打分。v4 **一次都没跑**：
- 工作流文件 §7 自己写着「本节是新装置，**尚无实测记录**」；
- 全部质量保证来自"对文档做对抗审查"——审的是**规则文本**，不是**用规则写出来的稿子**。

对抗审查确实抓出了很多真问题（阈值校准粒度、手册注册空转、四处 P0 缺口），但它**测不出"照这套规则写出来的文章好不好"**。这一步只能靠真写一篇。

### 根因三 ★ 一次成型，没有迭代

v4 是"一份文档写成 → 审一遍 → 交付"。真正的训练必须是**写 → 试跑 → 看成品 → 改规则 → 再试跑**，至少 2—3 轮。
v3 的失败原因之一（"清单化"6 题复现却每次只扣 1 分、从未回写规则）是**回写机制不触发**；v4 更彻底——**根本没有回写环节**。

## 3. v4 里仍然成立、v5 可以直接用的东西

这些经过独立复算或对抗审查，**不必重做，但要复核**：

- 语料与工具：`docs/设计/少年司法初稿v5/工具/` 14 个脚本（建语料、句首句末榜、定点词表、结构统计、逐篇校准、误伤率回测）。
  ⚠️ `check_style.py` 复用前先修三个已知缺陷（C 稿实跑暴露，未修）：**.md 分支脚注剥离失效**（先删 `[^n]` 使第二条正则失配，脚注被全算进正文；同一稿 md 报 35,733 汉字、docx 报 27,170，冒号密度 43→96，**只能跑 .docx**）；「正文具名指称他人研究」正则过宽（C 稿报 90 处，真值 1 处）；「凑三」正则命中法条的「第三项」「第三款」。
- **逐篇校准原则**：阈值必须在单篇真刊上校准并报误伤率，>10% 即错。（合计校准会把方差洗掉，v4 初版 106 篇真刊只有 1 篇能全过。）
- **结构基准**（86 篇实测，已反向校验）：一级单元中位 5；64% 无独立结论章；首章 66% 是实质章；三级标题 40% 用；末章双峰（2%—4.5% 或 18%—24%，5%—15% 是空档）。
- **v3 的病灶诊断**（60:1 的条款配比、评分量表把"不像真人"当加分、配额的边际产物＝B 稿多出来的那些句子）——三处均经复算，数字与原文吻合。
- **真刊论证动作的归纳**（起手式六型、反驳七断点、解释链允许失败、立法论支点谱系、让步规矩）——素材真实，但**作为"动作清单"投放的方式失败了**，v5 要换投放方式（见下）。

## 4. 给 v5 的三条硬约束

1. **必须给句子**：训练产物里必须包含**成段的真刊原文**作为阅读对象（不是 25 字碎片，也不是填空模板）。防抄袭交给 8 连汉字比对，不靠"删掉所有句子"。
2. **前向验证是唯一验收**：跑完真写的稿子并通过盲读之前，不许交付工作流、不许宣布完成。指标只是体检，永远不是验收。
3. **必须迭代**：至少两轮"试跑 → 改规则 → 再试跑"，每轮都要留下成品与判定记录。一次成型的工作流不予采信。
