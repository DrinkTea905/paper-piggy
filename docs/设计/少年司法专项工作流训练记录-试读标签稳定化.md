## 二、冻结后的分类词表

### 2.1 字段之间不得再混用

后续 6 篇领域核心和陈瑞华、栗峥作者组均使用以下五个独立字段：

| 字段 | 用途 | 允许值 |
|---|---|---|
| `主路线` | 说明初稿方法的主导结构 | `教义学`、`理论—制度建构`，二选一 |
| `辅助模块` | 说明可叠加的方法模块 | `实证诊断`、`比较法/制度史`，可多选或写“无” |
| `素材池` | 说明材料为什么被纳入训练 | `领域核心`、`方法补强`、`对抗样本`、`文体样本` |
| `证据层` | 说明文章实际使用的证据类型 | `规范`、`理论`、`事实/实证`、`比较法/制度史`、`跨学科机制`、`实施条件`，可多选 |
| `训练角色` | 说明本篇在规则提炼中的实际作用 | `核心规则依据`、`方法补强`、`历史演变`、`对抗`、`边界`、`重复例证` |

另设 `重要作者纵向组` 布尔字段。陈瑞华、栗峥论文进入纵向组时，该字段为“是”；它不是第三种素材池，也不因作者身份自动改变准入或训练角色。

### 2.2 两条主路线

#### 教义学

适用于以法源、规范关系、概念、要件、类型、权限、程序、证明、法律效果和救济为主导的问题。判定依据是文章的主推理链，不是题名中是否出现“制度”“理论”。

#### 理论—制度建构

适用于以理论前提、模式选择、宏观立法批判、制度体系、功能分工、组织结构、资源条件和实施边界为主导的问题。理论重构、宏观立法批判和制度体系设计全部归入本路线。

固定规则：

1. 每篇文章只标一个主路线。
2. “教义学为主、制度建构为辅”等原始表述在冻结值中只保留主路线；跨路线贡献写入“可迁移方法”，不得把“辅路线”伪装成第三条路线。
3. `混合型`、`教义学＋制度构造`、`功能—结构路线`、`宏观制度路线`、`实证路线`、`比较法路线`均不得成为新主路线。

### 2.3 两个辅助模块

#### 实证诊断

只有文章实际用统计、案卷、问卷、访谈、观察、试点或可观察指标诊断规范与运行落差时才标注。仅引用一项数字、案例或发展科学文献，不足以自动标注。

#### 比较法/制度史

比较法、法律史、立法史和制度史统一并入本模块。是否使用域外或历史材料，不改变文章主路线。

下列原 A 批“辅助模块”不再独立成标签：

- 犯罪学、发展心理学、刑罚理论、社会系统论：移入 `证据层` 的“理论”或“跨学科机制”。
- 规范竞合、组织法：属于教义学卡的必填分析动作。
- 组织与实施条件：属于两条主路线都必须完成的卡片字段。
- 严重案件压力测试、低风险案件压力测试：属于统一质量检查。
- 恢复性司法：属于理论或制度内容，不是辅助模块。

### 2.4 素材池、证据层和训练角色

1. **素材池以一项主值为原则**。本次 18 篇均来自已经核验的少年司法共享核心，故主素材池统一为 `领域核心`。它们同时承担对抗、历史或边界作用时，写入训练角色，不把素材池改成逗号连接的混合标签。
2. **证据层可多选**。A 批原“规范层、理论层、事实层、制度条件层”整体迁入此字段；“历史层”改为“比较法/制度史”；“对抗层”不是证据类型，改入训练角色。
3. **训练角色可一主多辅**。每篇必须有一个主角色；确有原文依据时可添加辅角色。
4. `重复例证` 只说明该篇没有带来新方法动作但可重复支持既有动作，不等于可以跳过精读，也不等于从正式素材集中删除。
5. 期刊等级、作者声望、观点方向和是否赞成拟议改革，均不得充当训练角色。

- `跨法律年龄一致性反证`：属于年龄规则审查的场景化论证工具。
- `干预主义/转处主义鸿沟`、`保护区/试验田/连通器`：属于特定作者的理论概念和修辞。
- `动态最有利复核`：作为原则操作化的时间维度保留，不另立根规则。
- `个人—法院双重受审能力`：降为“能力—支持关系审查”的场景子动作，且“法院可以补足能力”仍属强制复核字段。
- `入罪—出罪非对称证明`、`加重—减轻非对称量刑证明`：降为证明规则的具体应用，不外推到所有少年司法决定。
- `不起诉方式最小负担阶梯`：降为附条件不起诉场景中的比例检查。
- `评估—决定—执行—转出链`：降为完整制度链的处遇场景模板。
- `支持条件不得转化为个体风险`、`支持体系的准羁押审计`：保留为强制复核子动作；在独立复核和指定页裁决前不得提升为最终规则。
- `大司法/综合司法`：只可描述研究范围或制度构想，不得成为第三条主路线。

### 4.3 禁止生成的标签

1. **禁止新增顶层路线**：`混合型`、`功能—结构路线`、`实证路线`、`比较法路线`、`宏观批判路线`、`理论重构路线`、`制度体系设计路线`。
2. **禁止新增辅助模块**：`规范竞合`、`组织法`、`发展心理学`、`犯罪学`、`刑罚理论`、`恢复性司法`、`社会系统论`、`严重案件压力测试`、`机构实施`。
3. **禁止把证据层写成素材池**：`规范层`、`理论层`、`事实层`、`历史层`、`制度条件层`不得与 `领域核心` 并列。
4. **禁止把训练角色写成素材池**：`对抗`、`边界`、`历史演变`、`重复例证`不得与 `领域核心` 用加号连接。
5. **禁止把作者实体结论写成标签或规则**：包括但不限于具体责任年龄、具体罪名/刑期门槛、某类报告一律属于某种证据、某机关当然拥有最终决定权、某类儿童自动排除、具体处分期限、特定试点效果、某种比较法制度可直接移植。
6. **禁止以作者或刊物代替方法证据**：`陈瑞华式`、`栗峥式`、`三大刊观点`、`CLSCI 共识`均不是标签。
7. **禁止把未裁决争议伪装成共识**：凡写有低置信度、强制复核、内部张力或待裁决的字段，只能标为“候选”“争议”或“待核”。

## 五、跨批方法动作与重复判断

### 5.1 根动作的跨批状态

| 根动作 | A 批 | B 批 | C 批 | 当前状态 |
|---|---|---|---|---|
| 功能/概念分层后定性 | 社会调查功能层级、概念五步链 | 证明对象重置、处遇矩阵 | 原则和支持体系的流程分层 | 跨批稳定 |
| 原则操作化 | 原则功能化三检 | 形式—实质双层审查 | 原则三段桥、相反决定说理 | 跨批稳定 |
| 解释论—立法论分层 | 例外规则前提审查 | 实然激活—应然创建 | 宏观方案权限与救济审查 | 跨批稳定 |
| 理论/模式组件化 | 理论前提—支柱—接口 | 多维处遇矩阵 | 模式—原则—组件、理念—实践落差 | 跨批稳定 |
| 机构—权限—程序—效果—救济全链 | 功能链反推程序链 | 法律效果全周期链 | 非羁押支持全流程 | 跨批稳定 |
| 名义—实质负担审查 | 教育/保护措施的实质制裁审查 | 保护异化、附条件负担 | 准羁押、提前矫正审计 | 跨批稳定 |
| 支持性参与闭环 | 形式同意与真实参与分离 | 最有利原则和不起诉参与缺口 | 五要素连续参与 | 跨批稳定；C 批增加操作粒度 |
| 能力—支持关系审查 | 资源公平、支持缺位反向审查 | 关系型受审能力、机构支持 | 风险—支持分离、程序与资源双控 | 根动作稳定；两个子标签待复核 |
| 证据用途防火墙 | 社会调查影响追诉的张力 | 社会调查入罪/量刑直接冲突 | 风险评估、表现证明的用途风险 | 重要但未裁决，不得写最终实体规则 |
| 规范—实证双向校验 | 混合资料与样本边界 | 功能指标、绩效反诊断 | 试点四层效果、选择偏差 | 跨批稳定 |
| 制度移植前提审查 | 例外规则和比较制度前提 | 相邻制度差异化移植 | 模式功能与中国权限校验 | 跨批稳定 |
| 多轴制度矩阵 | 违警/处遇/三支柱分类 | 对象—措施—机构—阶段 | 模式—原则—组件、支持流程 | 跨批稳定 |
| 技术性违约支持优先 | 首次完整提出 | 不起诉和处遇材料补强 | 参与、资源和退出材料补强 | 规则动作得到补强；具体后果未裁决 |
| 共同前提重置与最强反方 | 严重/低风险、名义/实质反例 | 共同错误前提重置 | 国家责任/儿童主体、支持/强制对抗 | 跨批稳定 |

### 5.2 各批真实增量

- **A 批**建立基础动作库：功能分层、规范链、原则功能化、制度前提、名义/实质、规范—实证、真实参与、资源公平、技术性违约、理论支柱与支持缺位反查。
- **B 批**不是简单重复，新增或显著细化：法律效果全周期、相邻制度差异化移植、解释论/立法论双层、关系型受审能力、证据用途防火墙、共同错误前提重置、绩效反诊断和四维处遇矩阵。
- **C 批**仍有实质增量：参与权五要素连续闭环、程序控制与物质支持双层设计、试点证据四层效果表、风险变量与支持缺口分离、准羁押审计。它们虽可并入既有根动作，但实质修订了动作内容和适用边界。

### 5.3 重复动作的处理

下列内容已经跨篇或跨批重复，不再按论文数量生成同义规则：

1. 抽象原则必须落到机构、权限、程序、效果和救济。
2. 比较法必须连同原法域制度前提、资源、程序和权利保障一起迁移。
3. 教育、保护、福利和支持名称不能免除对强制性、期限、负担、比例和救济的实质审查。
4. 发展科学和环境因素可以支持个别化与最低干预，不能直接证明个案危险或责任。
5. 专业人员、经费、组织、服务可达性和跨部门协作是规范方案的一部分。
6. 统计、问卷、个案、试点和域外研究必须分层，相关性、观察和规范推演不得写成因果效果。
7. 低风险案件和严重案件必须分别压力测试。
8. 儿童签字、口头表示或监护人同意不等于理解、能力、公平和持续参与。
9. 支持、矫治、惩罚之间必须有入口、期限、转介、退出和责任边界。
10. 同一材料用于定罪、量刑、处分、风险、服务和支持时，证明对象与法律效果必须重新审查。

### 5.4 不能判定饱和

当前不仅不能宣布饱和，而且仍存在明确的“未饱和”信号：

1. B、C 两批相对前批仍产生新方法动作或实质修订，没有出现“连续两批不再产生新动作或实质修订”。
2. 目前只完成 18 篇试读标签稳定化，尚有其余 6 篇少年司法共享核心未进入本次跨批验收。
3. 陈瑞华、栗峥重要作者纵向组尚未在本次文件中完成逐篇精读、纵向继承/修正/转向分析和交叉对抗。
4. 三批建议的 2/6 独立复核及强制页级复核尚未被记录为实际完成。
5. 社会调查用途、受审能力中的制度支持、风险与资源、准羁押、保护处分实质负担、严重案件边界等核心争议仍待原文裁决。
6. 前向验证尚未使用未参与规则总结的新题检验路由、双卡差异、用户选择闸门和综述证据组织。

因此，本文件只能冻结词表和卡片字段，不能冻结最终运行时规则，更不能把“18 篇已验收”写成“训练已饱和”。

## 六、后续统一文章卡字段

以下字段对其余 6 篇领域核心和陈瑞华、栗峥全部合格论文强制适用。字段缺失时不得用空泛概括补齐；原文没有回答的，应明确写“原文未展开”。

### 6.1 准入与阅读审计

| 字段 | 必填内容 |
|---|---|
| `key` | PaperPiggy 文献 key |
| `完整题录` | 作者、题名、期刊、年份、卷期、页码 |
| `作者精确匹配` | 是否属于陈瑞华/栗峥纵向组；同名作者须核身份 |
| `中文正文` | 是/否及核验依据 |
| `中国大陆期刊` | 是/否；台湾期刊或以台湾制度为主要对象须排除 |
| `完整全文` | 附件类型、总页数、原生/OCR 情况 |
| `deep` | `true`/`false`；`false` 只能进入具名待核清单 |
| `三大刊或 CLSCI` | 客观标签及来源 |
| `方法作业` | 文章实际完成了哪一项初稿或综述方法作业 |
| `准入结论` | 准入、排除或待核；排除/待核必须写具体理由 |
| `连续阅读记录` | 顺序页 1→末页、补读页窗、是否到达本篇文末 |
| `页码映射` | 顺序页与印刷页；推算、异常和人工纠正须标明 |
| `他文/附录边界` | 合订页、附录、参考文献、他文起止，防止串读 |

### 6.2 共用分类头

每篇初稿卡和综述卡之前先填：

1. `主路线`：教义学或理论—制度建构，二选一。
2. `辅助模块`：实证诊断、比较法/制度史，可多选或无。
3. `素材池`：领域核心、方法补强、对抗样本、文体样本。
4. `证据层`：规范、理论、事实/实证、比较法/制度史、跨学科机制、实施条件。
5. `重要作者纵向组`：是/否；如是，注明陈瑞华或栗峥。
6. `主训练角色`：六个允许值中选择一个。
7. `辅训练角色`：可多选。
8. `总体置信度`：高、中高、中、中低、低；须说明置信度针对哪些字段。
9. `独立复核状态`：未抽中、抽中待复核、已独立复核、待裁决、已裁决。

### 6.3 初稿卡

| 字段 | 强制内容 |
|---|---|
| `问题如何提出` | 现实冲突、规范缺口、理论矛盾或证据异常怎样被改写成可回答问题 |
| `概念如何拆分和界定` | 上位/下位概念、相邻概念、要素、外延、反例和边界 |
| `法源与规范关系` | 规范来源、位阶、时效、权限来源、一般法/特别法、实体/程序关系 |
| `规范/类型/模式/理论如何建构` | 推理步骤和每一步的证据，不只记录最终方案 |
| `竞争观点与最强反驳` | 对手观点的最强版本、作者回应、尚未解决的外部反驳 |
| `机构、权限、程序、法律效果和救济` | 五项逐一回答；“原文未展开”也必须显式记录 |
| `实施条件与边界` | 人员、经费、资源、数据、地域、样本、期限、跨部门协同及不可实施场景 |
| `严重案件压力测试` | 公共安全、被害人、责任、比例、高证明标准与专门程序是否仍成立 |
| `低风险案件压力测试` | 是否因保护、评估、帮教或绩效产生过度干预、网络扩大或技术性违约 |
| `少年司法迁移闸门` | 最有利原则、发展中能力、支持性参与、关系自主、最小干预、比例、机构支持义务、有效审查与救济，八项逐项核验 |
| `合意性安排专项检查` | 涉附条件不起诉、监督考察协议等时，核验适龄说明、持续知情、支持表达、资源核验、合理调整、履行能力、可撤回、条件变更、技术性违约、撤销和救济 |
| `可迁移方法` | 只写问题化、概念、推理、规范链、组织程序、反例和边界方法 |
| `不可迁移实体结论` | 逐项列出具体年龄、罪名、期限、机关、证明规则、统计结果和作者方案 |
| `精确页码` | 每个关键动作对应顺序页和印刷页；异常页码保留说明 |
| `低置信/新动作/复核字段` | 分开记录，不用“总体可信”覆盖局部争议 |

### 6.4 综述卡

| 字段 | 强制内容 |
|---|---|
| `范围边界` | 时间、地域、对象、制度阶段、法域、材料类型及明确排除项 |
| `检索与纳入方式` | 原文若未报告检索式、数据库或纳排标准，明确写“未报告”，不得补写 |
| `分类轴` | 选择最少且有解释力的轴，避免按作者逐篇流水账 |
| `理论谱系/概念演进` | 起源、继承、修正、转向与断裂 |
| `代表观点及证据基础` | 观点、作者、法源/数据/案例及证据强度相互对应 |
| `竞争模式` | 各模式的前提、制度构造、优势、代价和适用边界 |
| `真实争议` | 分歧到底发生在概念、规范位阶、理论前提、事实证据还是实施条件 |
| `证据分层` | 规范、理论、实证、比较/历史、跨学科机制、实施条件分别评价 |
| `共识/争议/缺口` | 三者分开；无证据不得写“学界一致”或“无人研究” |
| `反方与反例` | 最强反方、严重案件、低风险案件、资源不足地区和制度副作用 |
| `可迁移组织结构` | 能迁移的是组织文献的方法，不是作者的实体结论 |
| `过度概括风险` | 法域外推、样本外推、因果误写、现行法时效和观点共识风险 |
| `精确页码` | 重要谱系、观点、争议和证据判断逐项定位 |
| `低置信/复核字段` | 作者内部张力、材料缺口和需要第二读者重读的页码 |

### 6.5 陈瑞华、栗峥作者纵向卡的附加字段

每读完一篇即滚动更新，不等全部读完再凭印象总结：

1. 稳定的问题意识。
2. 反复使用的概念操作和推理链。
3. 跨年继承、修正与转向；每项须列早期/后期原文页。
4. 作者内部张力，区分真实变化、场景差异和表述差异。
5. 可迁移方法。
6. 不可迁移的成年刑诉、证据法或其他实体结论。
7. 迁入少年司法时必须增加的八项保护条件。
8. 每篇论文的主训练角色和辅训练角色。
9. 与另一作者的交叉对抗字段：程序价值/证明结构、国家权力/认知关系、经验到理论/材料到类型、形式合意/真实能力、规范效果/结构与实施解释。
10. `作者观点发生变化`属于强制复核判断，须由第二读者重读相关年份指定页；不得根据题名、摘要或时间先后推定。

### 6.6 复核与裁决钩子

每篇卡片最后必须有以下机器可检的状态字段：

- `needs_independent_review: true/false`
- `review_reason`
- `review_pages`
- `disputed_fields`
- `adjudication_status: 未提交/保留/修正/降级/保留争议/删除`
- `adjudication_reason`
- `adjudication_pages`

触发 `needs_independent_review=true` 的最低条件：

1. 新标签或新方法动作；
2. 低置信度；
3. 核心分歧；
4. 作者观点发生变化；
5. 实体结论可能扩大处罚、强制或自由限制；
6. 因果效果、全国外推或比较法移植；
7. 社会调查、心理测评、风险评估、表现证明等材料跨用途；
8. 一次签字、监护人同意或机构教育可能被当作真实能力和持续参与。

裁决只针对争议字段重读指定原文页，采用“保留、修正、降级、保留争议、删除”五种结果；不得按作者声望、刊物等级或代理票数裁决。

## 七、稳定化后的质量门槛

1. 每个实体性论断必须能回到具体原文页；题录摘要、SAC 摘要和检索片段不能补足卡片字段。
2. 每张卡区分“作者明示”“训练综合”“少年司法制度推论”，三者不得混写。
3. 原文没有法律效果、救济或实施条件时，写“原文未展开”，不得替作者补造。
4. 新方法动作先进入训练记录，经跨文献复现、独立复核、对抗和裁决后才可能进入候选规则。
