## 三、`B9TRMQUA` 初稿卡

### 1. 基本标签

- 题名：陈瑞华，《刑事诉讼基础理论研究的若干思考》。
- 年期：原文仅载网络首发日期 2023-12-27；纸刊年份、期次未载明。
- 印刷页：文章页1—17。PDF顺序页1是网络首发封面，不计为文章印刷页；PDF顺序页2—18对应文章印刷页1—17。
- 主路线：`理论—制度建构`。
- 辅助模块：`比较法/制度史`。
- 素材池：`方法补强`。
- 证据层：`规范`、`理论`、`事实/实证`、`比较法/制度史`、`跨学科机制`、`实施条件`。
- 训练角色：主角色 `方法补强`；兼具 `历史演变`、`对抗`、`边界`。
- 重要作者覆盖层：陈瑞华。

### 2. 问题如何提出

**作者明示。** 文章不是从单一法条或单一制度缺陷起步，而是先回看刑事诉讼基础理论由“诉讼主体—诉讼客体—诉讼行为”三个传统范畴，向“诉讼目的与价值—诉讼构造—程序性制裁”等新范畴扩展的过程，再追问旧范畴能否获得新解释、新范畴能否继续生成理论，以及新的刑事司法现象能否被概念化、体系化。[`B9TRMQUA`，印刷页1—3]

**训练综合。** 可迁移的问题化动作不是“先选一个宏大理论再套材料”，而是：

1. 先盘点现有概念是否遗漏了新的主体关系、权利状态、程序对象或法律效果；
2. 再把制度实践中的反复现象压缩成可区分、可检验的概念；
3. 最后检查新概念能否解释旧问题、预测新问题，并接受经验反证。

### 3. 概念如何拆分和界定

**作者明示。**

- “诉讼主体”由静态主体资格转向主体之间的互动关系；被追诉人可能兼具诉讼当事人与特殊证据来源等不同地位，被害人也可能承担多重程序角色。[印刷页4—5]
- “诉讼客体”不只包括传统的人身追诉，还可区分对物程序、程序争议及强制治疗等对象。[印刷页5—6]
- “诉讼行为”需要区分公权力机关行为与诉讼参与人行为，并分别讨论成立、有效、失效及程序性制裁。[印刷页6—7]
- “诉讼目的和价值”内部存在惩罚犯罪、保障人权、纠纷解决、恢复关系、合作治理等竞争与组合；“诉讼构造”可作横向与纵向观察；“程序性制裁”又可落到排除、无效、撤销、减轻实体后果等不同法律效果。[印刷页7—12]

**训练综合。** 本文最值得迁移的是“旧概念再问题化 + 新问题概念化”的双轨操作：一方面把旧概念拆成关系、对象、行为及效力；另一方面把新实践提炼为目的、构造和制裁。该动作可用于少年司法，但不能照搬其成年刑诉中的主体分类和程序模型。

### 4. 规范、类型、模式或理论如何建构

**作者明示。**

- 文章以“旧三论的新解释—新三论的继续创新—新司法现象的理论化”为三级推进结构。[印刷页1—3、12—17]
- 在程序模式上，区分对抗与合作，并指出合作性程序只有在自愿、有效辩护、检察裁量受限和司法审查存在时才可能具有正当性。[印刷页12—14]
- 在理论生成方法上，主张从实践经验中形成概念和命题，经归纳、演绎及证实或证伪，再回到制度效果评价，而非停留在比较法引介或抽象思辨。[印刷页16—17]

**训练综合：候选新动作。**

- `经验—概念—命题—证实/证伪—效果回测`五段链。
- `目的—构造—效果`三层模型：先辨目标竞争，再查权力和角色结构，最后落到法律效果和救济。
- `合作程序四条件检查`：自愿基础、有效帮助、裁量边界、独立审查。迁入少年司法时必须扩充为持续、知情、可撤回且受支持的参与检查，不能把成年人的形式自愿标准直接移植。

上述均只是本批候选动作，尚未成为运行时规则。

### 5. 竞争观点和最强反驳

**作者明示的竞争关系。** 文章处理了惩罚犯罪与保障权利、对抗与合作、审判中心与侦查结构、司法裁判与社会治理等张力，并提醒某些合作程序和有效犯罪治理方案需要制度条件与效果检验。[印刷页7—16]

**训练综合的最强反驳。**

1. 从经验生成概念并不自动保证因果可靠；零散案例、制度印象和比较法材料可能只能提出假说。
2. “家庭模式”“关爱、治疗、矫正”在少年司法中可能成为扩大国家干预和家长主义的语言包装。
3. 合作程序即使有一次性签字，也可能因年龄、依赖关系、辩护不足、资源不平等和撤回成本而不真实。
4. “有效犯罪治理”可能把司法机关推入其资源和权限无法承受的社会治理任务，并导致低风险未成年人被过度服务、过度评估或过度控制。

### 6. 机构、权限、程序、法律效果和救济

**作者明示。** 文章在合作性程序中强调检察裁量边界、律师有效参与和司法审查；在程序性制裁中强调程序违法应产生排除、无效、撤销或实体后果减让等可见效果；在纵向构造中讨论侦查、起诉和审判之间的权力关系。[印刷页9—14]

**少年司法迁移闸门。** 若将该链条用于附条件不起诉或监督考察协议，必须补足：

- 机构：承办机关、辩护/法律帮助、社会服务机构、家庭支持者、独立审查者的角色分离；
- 权限：条件设定、评估、变更、认定违约、撤销和救济不得由同一机构不受控制地完成；
- 程序：年龄适宜说明、资源核验、合理调整、持续表达、撤回与复议；
- 法律效果：技术性违约与实质性失败分离，避免一次不履行自动触发最重后果；
- 救济：对不理解、不可履行、不成比例、资源未提供及机构未尽支持义务，均应有有效审查路径。

### 7. 实施条件与边界

**作者明示。** 文章已经提示合作程序需要辩护、裁量约束、司法审查等条件，也质疑短期教育矫治是否真有效以及司法机关是否有能力处理犯罪深层原因。[印刷页13—16]

**训练综合。** 迁入少年司法时，最低实施条件还包括适龄沟通、独立法律帮助、服务真实可得、对残障和发展差异的合理调整、定期重新评估、数据和隐私防护。边界是：不能以“保护”“矫治”“治理”替代证据、比例和救济，也不能因家庭贫困或支持不足而提高控制强度。

### 8. 严重案件与低风险案件压力测试

- **严重案件。** 不能因罪名严重就取消发展中能力、支持性参与和有效审查；但也不能以恢复、合作或家庭模式掩盖证据标准和被害人安全问题。制度建构必须同时说明公共安全目标、严格的权力边界和可复核的事实基础。
- **低风险案件。** 最小干预优先。若教育、评估、协议和社会服务的实际负担大于不介入，所谓“帮助”就可能产生净扩大；工作流必须要求比较“不处理、轻处理、支持性服务、正式程序”各自成本。

### 9. 少年司法八闸门

| 闸门 | 对本文候选方法的迁移要求 |
|---|---|
| 最有利于未成年人 | “关爱、治疗、矫正”不得凭名称推定有利，须用可验证的短期与长期影响证明 |
| 发展中能力 | 把主体关系分析具体化为理解、表达、权衡后果和随时间变化的能力 |
| 支持性参与 | 有律师或监护人在场不等于已参与；须检查沟通方式、意见形成和实际影响 |
| 关系自主 | 识别家庭、机关、学校和服务机构既可能支持也可能施压 |
| 最小干预 | 对低风险案件先问是否需要进入任何协议、评估或控制程序 |
| 比例原则 | 目的、条件、期限、监督频率和违约后果逐项衡量 |
| 机构支持义务 | 将说明、资源供给、合理调整和条件变更作为机构义务，而非儿童个人责任 |
| 有效审查与救济 | 对条件设定、能力判断、违约、撤销和程序违法配置独立且及时的审查 |

### 10. 合意性安排专项检查

本文关于合作性程序的自愿、有效辩护、裁量约束和司法审查，只能作为最低起点。[印刷页12—14] 在少年司法中还必须区分一次性签字与持续、知情、可撤回且受支持的参与，并逐项检查说明、资源核验、合理调整、履行能力、条件变更、技术性违约、撤销和救济。“同意”不能直接等同于能力、公平或真实协商。

### 11. 可迁移方法与不可迁移结论

**可迁移方法：**

- 用旧概念再解释和新问题概念化的双轨方式发现研究问题；
- 以目的、构造、行为效力和救济组成完整规范链；
- 从经验归纳概念后要求证实、证伪和效果回测；
- 对合作程序同时检查自愿、帮助、裁量和审查；
- 把“制度是否有效”从价值口号变成待验证命题。

**不可直接迁移的实体结论：**

- 成年刑事诉讼中的主体分类、合作程序和刑事协商结论；
- 以家庭、治疗、矫正模式概括少年司法目的的结论；
- 将附条件不起诉直接纳入“有效犯罪治理”的制度判断；
- 对审判中心、程序性制裁具体法律效果的成年刑诉方案。

## 四、`B9TRMQUA` 综述卡

- **综述范围。** 刑事诉讼基础理论由传统范畴向价值、构造、制裁及新司法现象扩展的谱系，以及从实践经验生成理论的方法。
- **检索/纳入方式。** 文章是作者对领域理论史和代表性问题的选择性回顾，不是报告检索式、数据库、起止年份和排除标准的系统综述；训练时不得把它表述为穷尽性文献图谱。
- **组织轴。** 时间轴（旧三论—新三论—新现象）、概念轴（主体/客体/行为—目的/构造/制裁）、方法轴（比较与思辨—经验概念化—证实/证伪—效果评价）。
- **理论谱系与概念演进。** 传统静态范畴被关系化、类型化和效力化；新范畴又向少年司法、恢复性司法、合作程序和有效治理等对象延伸。[印刷页1—16]
- **代表观点及证据。** 以国内刑事诉讼制度、学说发展、若干改革现象和比较法概念为主要材料；对主观程序正义、矫治效果和治理能力等议题明确提出经验研究需要，但本文本身并未完成系统因果验证。[印刷页8—16]
- **竞争模式。** 惩罚/保障、对抗/合作、侦查中心/审判中心、裁判/治理、抽象思辨/经验理论化。
- **真正争议。** 不是应否使用某个漂亮概念，而是新模式是否具有可识别条件、权力约束、证据基础和可检验效果。
- **证据等级。** 概念史和规范分析较强；实践例示和比较材料用于提出命题；效果与因果判断仍待专门实证。

### 2. 问题如何提出

**作者明示。** 文章从证据理论长期以认识论为唯一或主要基础所产生的规则后果出发：若把诉讼等同于发现客观事实，程序、权利和证据规则就容易被视为妨碍真相的技术障碍，许多限制取证和裁判权的规则因而失去正当基础。[`C4D3DFJT`，印刷页21—26]

**训练综合。** 其问题化动作可概括为`理论前提—规则命运反推`：不只问一个理论在抽象上是否正确，还要列出它会使哪些规则变得不可解释、哪些权利变得可牺牲、哪些权力变得无边界，再据此审查理论前提。

### 3. 概念如何拆分和界定

**作者明示。**

- 诉讼的纠纷解决与事实认识不是同一目标；
- 程序中的认识受法定程序限制，不是无限制认识；
- 证明活动与一般认识活动具有不同的责任、标准和法律后果；
- 事实判断包含规范和价值选择，不能用“是”遮蔽“应当”。[印刷页22—24]

文章继而区分以发现事实规律为中心的“证据学”与以规范证明活动、限制权力并实现程序价值为中心的证据法学；区分客观事实与依照合法程序形成、可归责的法律事实。[印刷页26—28]

### 4. 规范、类型、模式或理论如何建构

**作者明示。** 文章不是简单否认真相价值，而是以形式理性和程序正义重构证据法基础，使证人特免权、无罪推定、沉默权、非法证据排除、对抗式证明和证明标准等规则获得不依赖“最大化发现真相”的正当说明。[印刷页24—28]

**训练综合：候选新动作。**

- `目标拆分—手段限制—规则后果`链：先区分事实准确、权利保障、纠纷终结等目标，再审查取证和证明手段，最后落实到证据能力、证明责任、证明标准和救济。
- `反事实规则检验`：假设只追求真相，逐项检验哪些保护性规则会被消解；由规则不可承受的后果反推理论必须修正。

### 5. 竞争观点和最强反驳

**作者明示的竞争关系。** 认识论中心与价值论基础、实质真相与形式理性、无限认识与程序约束之间构成全文张力。[印刷页21—28]

**训练综合的最强反驳。** 认识可靠性与程序价值未必是零和关系。若把“从认识论走向价值论”理解成放弃可靠事实判断，会反向削弱无辜保护和决策正当性。少年司法更不能因保护性目的而降低事实证明要求；正确迁移应是让可靠性、尊严、参与和权力限制共同构成证据制度目标。

### 6. 机构、权限、程序、法律效果和救济

**作者明示。** 文章通过沉默权、无罪推定、证人特免、非法证据排除和证明标准说明：侦查取证、控方证明和法院认定事实均须受规则约束，违反规则应产生证据不得使用或不利事实不得成立等法律效果。[印刷页24—28]

**少年司法迁移闸门。** 儿童陈述、认罪、社会调查、心理评估和家庭材料均须区分“信息存在”与“法律上可使用、可用于何种目的”。机构须提供适龄说明和沟通支持；法院或独立审查者须能审查取得方式、理解能力、可靠性、用途越界和救济。不得因儿童沉默、表达不完整或依赖成人而推定不利事实。

### 7. 实施条件与边界

- 价值论基础只有转化为可操作的证据资格、取得程序、证明责任、证明标准和排除/纠正机制，才不是口号。
- 迁入少年司法时必须避免另一极端：以“保护儿童”为理由绕开证明规则、弱化异议权或把专业评估当作不可质疑的真相。
- 本文对2001年前后中国证据制度的评价具有历史性，不能作为当前制度事实直接引用。

### 8. 严重案件与低风险案件压力测试

- **严重案件。** 罪名严重不会把程序价值降为装饰；对儿童供述、辨认、评估和共同犯罪陈述仍需严格检查取得方式、理解能力与证明力。保护性程序不能替代可靠证明。
- **低风险案件。** 不应以案件较轻为由降低说明、异议和证明要求，也不应为获得“教育性真相”而扩大讯问、评估或信息收集。

### 9. 少年司法八闸门

| 闸门 | 迁移要求 |
|---|---|
| 最有利于未成年人 | 价值基础同时保护免受错误事实认定和免受不当取证 |
| 发展中能力 | 对理解权利、陈述后果和证据意义作个别化判断 |

| 机构支持义务 | 由机构承担说明、翻译、沟通和合理调整义务 |
| 有效审查与救济 | 对不当取得、用途越界、证明不足和不利推定提供及时救济 |

### 10. 合意性安排专项检查

本文不以协议制度为直接对象，但其规则后果适用于认罪、承诺和协议事实基础：签字或口头同意不能自动证明理解、自愿和真实。少年司法中仍需持续、知情、可撤回且受支持的参与，并对说明、资源、能力和撤回后果作独立审查。

## 七、`CMF3HLNP` 初稿卡

### 1. 基本标签

- 题名：陈瑞华，《未决羁押制度的理论反思》。
- 题录：`《法学研究》2002年第5期，印刷页60—83`。
- 主路线：`教义学`。
- 辅助模块：`比较法/制度史`。
- 素材池：`方法补强`。
- 证据层：`规范`、`理论`、`事实/实证`、`比较法/制度史`、`实施条件`。
- 训练角色：主角色 `方法补强`；兼具 `历史演变`、`对抗`、`边界`。
- 重要作者覆盖层：陈瑞华。

### 2. 问题如何提出

**作者明示。** 文章从1996年刑事诉讼改革后未决羁押问题并未因文本调整而根本改变出发，认为症结不仅是个别期限或审批条款，而是中国法未把“逮捕、拘留等启动措施”与“持续剥夺自由的羁押状态”作制度分离，导致审查、期限、场所、救济和法律后果都附着在办案机关与案件进度上。[`CMF3HLNP`，印刷页60—66、73—77]

**训练综合。** 该问题化方法是`名义措施—实际状态分离`：先问当事人实际承受什么持续法律状态，再问哪个决定触发、谁维持、多久复核、在哪里执行、如何解除，而不是只围绕决定名称或一次审批讨论。

### 3. 概念如何拆分和界定

**作者明示。**

- 区分拘留、逮捕等强制措施与未决羁押这一持续状态；
- 区分程序性理由与实体性理由；
- 区分办案期限与羁押期限；
- 区分职权主动审查与被羁押人申请救济；
- 区分追诉机关、审查机关和羁押执行场所；
- 区分审前控制与提前惩罚。[印刷页60—77]

**训练综合。** 可形成“自由限制七环”：触发、理由、决定者、参与/听证、期间与复查、执行场所、解除与救济。任何一环缺失，形式上的一次合法决定都可能演变成持续失控。

### 4. 规范、类型、模式或理论如何建构

**作者明示。** 文章依次分析羁押性质、理由、期限、救济、场所，继而从任意性、惩罚化、比例失衡、非司法化和救济空缺作整体批判，再提出法治原则、改革方案及权力结构障碍。[印刷页60—83]

**训练综合：候选新动作。**

- `持续状态闭环控制`：把入口决定与存续控制分开，要求持续理由、定期复查、独立决定、个别参与和解除救济。
- `期限—案件进度解耦`：机构办案需要不能自动延长个人自由受限状态。
- `名义—效果校正`：名为教育、保护、考察、安置的措施，只要实际限制自由、日常生活或退出权，就按实际效果进入严格控制。

### 5. 竞争观点和最强反驳

**作者明示的竞争关系。** 追诉便利与人身自由、行政性审批与司法化审查、案件办理期限与羁押正当期限、惩罚预支与程序保障相冲突。[印刷页66—80]

**训练综合的最强反驳。**

1. 独立司法审查并非自动有效；若律师参与、事实披露、儿童沟通和替代资源不足，审查仍可能形式化。
2. 为所有限制状态设置高度程序化听证，可能使轻微、短暂和真正自愿的支持措施被过度司法化。
3. 2002年的制度描述、期限和机关关系已经具有明显历史性，不能当作当前中国法。
4. 单纯缩短期限可能制造更频繁但同样模板化的延长决定，真正问题仍是理由、证据、替代方案和救济质量。

### 6. 机构、权限、程序、法律效果和救济

**作者明示。** 文章逐项讨论公安、检察、法院、看守执行机构在决定、批准、维持和解除羁押中的权力关系，批评追诉机关自我授权和缺乏独立救济，并提出司法审查、期限控制、场所中立化等方案。[印刷页70—83]

**少年司法迁移闸门。** 对观护、安置、专门教育、封闭矫治或附条件不起诉中的强控制条件，应逐项写明：

- 谁提出、谁评估、谁决定、谁执行、谁复查；
- 未成年人及其支持者何时知情、陈述和申请变更；
- 自由受限的事实强度、期限、空间、接触限制和退出成本；
- 低风险、家庭贫困或服务不足是否被误作控制理由；
- 机构未供给替代资源时，不得把无法履行归责于儿童；
- 违反程序后的停止执行、变更、排除不利后果和救济。

### 7. 实施条件与边界

- 独立审查须有可争辩材料、律师/支持者参与、适龄说明和真实替代资源。
- 定期复查不能只复写原理由；应审查新事实、已履行情况、机构支持和更轻替代。
- 羁押场所和监管机构的组织利益会影响决定质量，必须纳入实施分析。
- 本文具体改革方案属于2002年语境，尤其是当时期限制度、机关配置和场所方案，均不可直接作为当前立法建议。

### 8. 严重案件与低风险案件压力测试

- **严重案件。** 严重性可进入风险和比例判断，但不能替代个别化的持续理由、证据、替代方案和定期复查。儿童的参与和救济不能因案件严重而消失。
- **低风险案件。** 不得以评估、观察、教育或家庭功能不足为由形成事实羁押；轻微案件应先检验不介入、社区支持和非控制性服务。

### 9. 少年司法八闸门

| 闸门 | 迁移要求 |
|---|---|
| 最有利于未成年人 | 以实际短期和长期影响判断限制状态，不以“保护”名称替代 |
| 发展中能力 | 在决定、复查和解除各阶段重新评估理解与表达能力 |
| 支持性参与 | 提供律师、沟通辅助、可信赖支持者和可理解材料 |
| 关系自主 | 检查家庭同意、机构建议和儿童真实意愿之间的压力关系 |
| 最小干预 | 任何持续限制先证明无更轻替代，且替代资源确实可用 |
| 比例原则 | 理由、强度、范围、期限和后果分别衡量 |
| 机构支持义务 | 由机构供给住宿、教育、治疗、交通等替代资源，不能以资源缺口加重控制 |

### 10. 合意性安排专项检查

**训练综合的最强反驳。**

1. 侦查阶段掌握信息和及时控制在某些案件中具有必要性，不能把一切前端主导都等同不正当。
2. 文中数据、案例和制度现象能支持结构性假说，但不足以单独证明每一后果的因果强度。
3. 增强法院并不自动保障儿童；若法院依赖同一案卷和成人化沟通，审判中心也可能复制前端偏见。
4. 少年司法中的专门化警检机构既可能提供保护，也可能因保护性裁量、评估垄断和跨机构信息共享形成新的“照护中心主义”。

### 6. 机构、权限、程序、法律效果和救济

**作者明示。** 文章具体连接公安强制和侦查、检察批捕起诉及程序回转、法院审理和裁判之间的权力与信息关系，并说明外部宣传、奖励和组织利益如何影响程序。[印刷页4—17]

**少年司法迁移闸门。** 产品规则应强制检查：

- 侦查机关、未检机构、社会调查者、学校、服务机构和法院是否角色分离；
- 早期“危险”“不配合”“家庭失能”标签由谁生成、是否可质疑、是否随案传递；
- 社会调查和服务信息是否设用途防火墙；
- 批捕、附条件不起诉、监督考察、违约认定和撤销是否形成自我确认链；
- 后续审查是否能接触独立材料、听到儿童意见并改变早期结论；
- 程序回转和重复评估是否延长事实控制。

### 7. 实施条件与边界

- 结构改革必须同时改变权限、绩效激励、信息载体、案卷用途和救济，不能只改机构名称。
- “专门化”不是天然保护；需审查专门机构是否兼具帮助、评估、指控和制裁权。
- 经验诊断要标明数据年份、口径和因果限度；2017年的统计与案例不可当作当前事实。
- 不应为削弱侦查中心而无限扩张法院权力；儿童支持、独立辩护和信息多元同样重要。

### 8. 严重案件与低风险案件压力测试

- **严重案件。** 舆论、绩效和公共安全压力更易锁定早期结论，必须强化证据异议、独立复核、隐私和对儿童陈述的适龄审查。
- **低风险案件。** 防止专门机构借评估、帮教和跨部门协同积累过多信息，使原本可最小干预的案件进入长期监督与标签循环。

### 9. 少年司法八闸门

| 闸门 | 迁移要求 |

### 10. 合意性安排专项检查

附条件不起诉或监督考察协议可能在侦查、检察与服务机构形成的信息链中被“预先决定”。即使儿童签字，也要查检察机关是否同时控制方案、资源、违约认定和撤销；是否有独立法律帮助和真实替代；技术性违约是否被案卷化为不配合；后续审查能否实质改变早期判断。

### 11. 可迁移方法与不可迁移结论

**可迁移方法：**

- 从改革目标反向诊断结构障碍；
- 把宏观结构拆成权力、激励、信息、流转和后果；
- 同时检查程序内机制和程序外绩效、舆论与组织利益；
- 追踪早期标签和案卷材料如何锁定后续决定；
- 用改革吸收测试识别形式变化。

**不可直接迁移的实体结论：**

- 成年刑事案件中的审判中心具体改革方案；
- 将侦查阶段任何信息优势一律视为不正当；

### 7. 迁入少年司法必须增加的保护条件

1. **最有利于未成年人：** 所有“保护、教育、治疗”措施按实际效果验证。
2. **发展中能力：** 理解、表达、权衡和履行能力须个别化、动态化判断。
3. **支持性参与：** 律师、沟通辅助、适龄材料和可信赖支持者贯穿决定、执行、变更和救济。
4. **关系自主：** 同时识别家庭和机构的支持资源与关系压力。
5. **最小干预：** 低风险案件先检验不介入及非控制性支持；避免净扩大。

## 十四、E 批跨文候选规则

> 以下均为训练候选，不能直接写进运行时工作流；须由少年司法24篇领域核心校验、独立复核、跨作者对抗和前向验证共同决定。

### A. 教义学候选规则

1. **实际状态优先于措施名称。** 对任何教育、保护、安置、考察和协议条件，先描述其实际强度、持续时间、退出成本和不利后果，再确定法律性质。
2. **建立完整规范闭环。** 至少回答触发事实、合法目的、决定权限、儿童参与、期限与复查、执行机构、法律效果和救济。
3. **期限与机关办案需要分离。** 办案未完成、服务资源不足或机构协调困难不能自动延长对儿童的控制。
4. **规则后果反推理论。** 若某理论使沉默、异议、排除、复查或救济成为不必要，该理论必须接受最强反例审查。
5. **终端规则反向约束前端。** 信息最终能否使用、用于何种目的、违法时有何后果，应反向规范取得、记录、共享和评估。
6. **合意不能截断控制。** 协议签字后仍须持续审查理解、资源、履行能力、条件变更、技术性违约、撤回和救济。

### B. 理论—制度建构候选规则

1. **旧概念再问题化 + 新现象概念化。** 先检验既有概念遗漏，再从反复实践形成候选类型。
2. **目的—结构—信息—程序—效果链。** 制度建议不得只陈述价值目标，必须连接权力配置、组织激励、信息载体、程序流转、法律效果和救济。
3. **改革吸收测试。** 检查新机构、新审查或新表格是否被旧权力、绩效和案卷结构吸收。
4. **经验—概念—命题—反证—回测。** 把理论命题写成可由事实支持或推翻的形式，并预先说明评价指标。
5. **功能冲突显式化。** 可靠性、权利、参与、效率、公共安全、恢复和发展不得都写成无冲突的目标清单。
6. **保护性家长主义对抗。** 任何家庭、矫治、治疗、合作或治理模式都须接受净扩大、关系压力、资源缺口和长期标签反例。

### C. 综述候选规则

1. **概念谱系不是作者名单。** 应展示概念怎样因问题、规则和证据变化而被拆分、体系化或扩展。
2. **作者内部变化分级。** 使用“继承、体系化、扩展、局部修正、内部张力、转向”不同标签；没有直接页证不得称“转向”。
3. **证据层级分开。** 规范文本、概念论证、比较材料、案例例示、描述统计和因果证据不得互相替代。
4. **竞争模式以条件比较。** 对每个模式写明适用案件、机构能力、资源前提、失败机制和救济，而不是列优缺点。
5. **规范—经验冲突并列。** 当规范目标与实施证据不一致时，不能以规范正确推定实施有效，也不能以短期执行困难否定规范要求。
6. **以未决争议收束。** 清楚区分最低共识、真正争议、证据空白和需要何种新研究。

## 十六、新动作、实质修订、重复与饱和信号

### 1. 本批新增的方法动作

1. `理论前提—规则命运反推`（`C4D3DFJT`）。
2. `名义措施—实际持续状态分离`与`自由限制闭环`（`CMF3HLNP`）。

4. `结构—激励—信息—流转—后果`与`改革吸收测试`（`TZGYBRVL`）。
5. `旧概念再问题化—新现象概念化`及`经验—概念—命题—证实/证伪—效果回测`（`B9TRMQUA`）。

### 2. 对既有候选规则的实质修订

- “规范链”不应只到权利义务，须增加持续状态、期限、执行场所、信息流转和可改变原决定的救济。
- “双路线比较”中的理论—制度建构路线，不能只比较理论优雅度；须加入改革吸收、组织激励和信息载体。
- “原文忠实”不仅是正确转述作者结论，还要区分作者明示、训练综合和少年司法迁移闸门。
- “合意性”由一次自愿检查升级为持续、知情、可撤回且受支持的参与，并与资源、履行能力、技术性违约和救济联动。
- “证据基础”由有/无材料升级为规范、历史描述、案例、描述统计和因果证据分层。

### 3. 重复与合并

- 2001年的程序价值与2006年的证据法功能不是两条重复规则：前者提供前提反推，后者提供体系落地，合并为一条“基础—体系—功能”链。
- 2002年的侦查中心障碍与2017年的侦查中心主义不是重复：前者是羁押制度末端的结构障碍，后者将其扩展为宏观机制；运行时只保留一次结构诊断动作，训练证据保留两篇纵向来源。
- B9论文的诉讼构造与2017年的结构诊断部分重合：前者作为基础理论地图，后者作为机制化压力测试，不生成两套近义运行时规则。
- 五篇都强调权力约束，但分别提供理论前提、持续状态、规则体系、结构机制和检验闭环；当前仍有实质增量。

### 4. 饱和判断

- **本批结论：未饱和。**
- 理由：这是陈瑞华纵向组首个五篇批次，连续产生五组可区分的新方法动作，并对合意性、自由限制、证据分层和结构实施规则产生实质修订。
- 可观察的重复信号：程序独立价值、公权力控制、概念分类和实施落差已在多篇重复出现，后续若连续两批只增加同义例证而不改变动作、边界或少年司法保护条件，应合并为重复例证。
- 触发后续饱和检查的标准：连续两批不再产生新的方法动作，也不再实质修订适用条件、反例、证据等级或八闸门内容。
