## 三、`EWW6AFJP` 初稿卡

### 1. 基本标签

- 题名：栗峥，《合理怀疑的本土类型与法理建构》。
- 题录：`《中国社会科学》2019年第4期，印刷页49—74；英文摘要页205`。
- 主路线：`理论—制度建构`。
- 辅助模块：`实证诊断`、`比较法/制度史`。
- 素材池：`方法补强`。
- 证据层：`规范`、`理论`、`事实/实证`、`比较法/制度史`、`跨学科机制`、`实施条件`。
- 训练角色：主角色 `方法补强`；兼具 `历史演变`、`对抗`、`边界`。
- 重要作者覆盖层：栗峥。

### 2. 问题如何提出

**作者明示。** 文章从“合理怀疑”被中国立法直接引入、但未经历本土实践自然演化和充分测试的错位切入，认为不能只从域外概念到本土概念，而要追问它如何适合中国、解决哪些实践问题、产生何种增量，并回到中国裁判文书和典型错案中寻找本土形态。[`EWW6AFJP`，印刷页49—50]

**训练综合。** 可迁移的问题化动作是`外来/抽象概念—本土实践遭遇—操作失灵—材料回返`：先查概念移植或规范口号在真实程序中怎样被使用，再从使用失败、异质案件和反例中重建类型，而不是以域外定义作为免检答案。

### 3. 概念如何拆分和界定

**作者明示。**

- 怀疑被界定为贯穿刑事诉讼的状态与过程，并随侦查、起诉、审判、再审阶段具有不同方向。[印刷页51—52]
- 合理怀疑被拆为“疑点—疑点效—疑点群—怀疑版本”：疑点是最小单位，疑点效是其对证明的动摇，疑点群是多个疑点的束状聚合，怀疑版本则是能与有罪版本对抗的整体叙事。[印刷页52—53、67—70]
- 合理性被区分为四阶形态：无限可能的一阶、证据支持的二阶、内部融贯的三阶、兼具融贯与外在真实支撑的四阶；作者最终主张四阶形态，并提出一致性、完整性、真实性、独立性标准。[印刷页55—59]
- 证明被进一步区分为微分式证明与积分式证明，前者处理单个证据和局部疑点，后者聚合为整体版本。[印刷页70—73]

### 4. 经验材料如何进入类型、结构与理论

**作者明示。**

1. 以2013年1月1日至2016年12月31日裁判文书网中包含“合理怀疑”的6692份文书为宏观样本，统计“排除/无法排除合理怀疑”、地域、罪名、审级、程序变动和辩护意见采纳等分布。[印刷页59—61]
2. 从样本和错案材料中选取八个典型案件深描，提炼八种怀疑版本：依赖口供且有相反供述；仅有证人证言；在场与不在场证据并存；时间、地点、人物、工具等存在双重解释；有悖逻辑常识、客观规律或一般经验；缺乏客观性证据；另有真凶可能；多被告、多证人陈述不一或相互矛盾。[印刷页61—66]
3. 将类型提升为“怀疑版本”，再以“聚类集成”说明疑点如何从微观流量聚合成宏观存量，最终建立微分式/积分式证明范式。[印刷页67—74]

**训练综合：候选新动作。**

- `总体材料分布—成功/失败个案深描—类型公式—结构关系—上位理论`五级链。
- `最小单位—局部效果—群组—整体版本`四级聚合。
- `有罪版本/反方版本并行建模`：不满足于零散反驳，主动组织最强反方；但迁入少年司法时绝不能把“形成完整无罪故事”的负担转给未成年人。

### 5. 规范、类型、模式或理论如何建构

**作者明示。** 文章先以根据论和融贯论的竞争暴露各自缺陷，再组合其优势形成“融贯且真实”的四阶形态；随后用八种错案类型把抽象标准变成可描述的怀疑版本，最后借聚类集成形成微分式/积分式证明理论。[印刷页55—59、61—74]

**训练综合。** 这是一条从经验材料向自主概念体系上升的典型路线，但每次提升都必须保留“材料覆盖范围—类型形成标准—反例—外推边界”，不能因为结构漂亮而推定周延。

### 6. 竞争观点和最强反驳

**作者明示的竞争观点。**

- 域外概念直接移植与本土实践建构；
- 根据论与融贯论；
- 单一疑点与整体怀疑版本；
- 一元证成与有罪/怀疑双轨；
- 微分式证明与积分式证明。[印刷页49—59、67—73]

**训练综合的最强反驳。**

1. 6692份是关键词命中文书，不是全国全部刑事案件，也受裁判文书上传、检索词、写作习惯和年份限制；比例不能直接解释司法因果。
2. 八个典型错案如何从总体样本中选出、是否存在反类型、编码能否复现，原文没有提供足够的方法透明度；“相对周延”必须降级为样本内候选。
3. 要求怀疑形成“一致、完整、真实、独立”的替代版本，可能把证明责任转移给辩方；尤其未成年人常难以持续、线性、无矛盾地讲述。
4. 将聚合后的怀疑对应为统一概率或“5%”尺度，不能由本文材料直接验证。
5. 类型工具可能让裁判者只寻找八种既定形式，忽略不典型、关系性、发展性或表达受限的儿童案件。

### 7. 机构、权限、程序、法律效果和救济

**作者明示。**

- 侦查、审查起诉、审判、再审阶段对怀疑具有不同方向和制度功能；检察官的客观义务、辩方提出疑点及法官保持怀疑共同构成怀疑版本的力量来源。[印刷页51—52、69—70]
- 合理怀疑的法律效果最终落到不能定罪、改判无罪、撤回起诉、不起诉、发回重审或维持既判力等程序结果。[印刷页51—52、61—66]

**少年司法迁移闸门。**

- 证明责任始终由追诉方承担；儿童无需提供完整替代故事才可受益于合理怀疑。
- 侦查讯问、检察审查、社会调查、心理评估和审判不得共同复制同一早期叙事。
- 辩护人、适龄沟通者和独立专家须帮助儿童识别、表达和组织疑点。
- 法官必须能审查证据来源、访谈污染、语言/发展差异及反方材料，而不能用陈述不一致自动否定儿童。
- 对错误使用儿童陈述、评估或数据，应有排除、限制用途、重新鉴定、变更决定及上诉/复核救济。

### 8. 实施条件与边界

- 类型形成必须报告样本框、检索式、时间、缺失数据、筛选步骤和反例。
- “融贯”不能掩盖共同来源、共同偏见或相互污染；“真实”需要外部证据和可质疑过程。
- 不能以是否符合八种成人错案类型作为儿童案件的机械判断表。
- 文中2013—2016年统计和2019年前的实践判断具有历史性，须用当前材料复核。
- 文章没有针对未成年人样本，任何少年司法适用均属于二次迁移。

### 9. 严重案件与低风险案件压力测试

- **严重案件。** 社会压力可能推动裁判把零散有罪证据聚成唯一版本，更应独立审查来源、替代解释和儿童陈述取得条件；案件严重性不降低证明标准。
- **低风险案件。** 不能因案件轻微而以简化程序、认错教育或协议签字替代事实审查；同时也不得为构建完整“怀疑版本”而扩大对儿童、家庭和学校的信息收集。

### 10. 少年司法八闸门

| 闸门 | 对本文方法的迁移要求 |
|---|---|
| 最有利于未成年人 | 类型工具须优先防止错误认定、污名和长期记录，不以定罪便利评价 |
| 发展中能力 | 叙述不完整、时间顺序混乱和表达反复应结合年龄、创伤、语言和记忆发展解释 |
| 支持性参与 | 提供律师、适龄解释、沟通辅助和独立支持，帮助表达疑点但不转移证明责任 |
| 关系自主 | 检查家庭、警察、学校、同伴和服务人员对陈述版本的共同塑造 |
| 最小干预 | 为核实轻微争点而扩张访谈、评估和数据收集须受限制 |
| 比例原则 | 取证侵入、信息范围、反复讯问和程序负担与证明需要相称 |
| 机构支持义务 | 机构负责保存原始材料、记录访谈过程、提供合理调整和独立核验资源 |
| 有效审查与救济 | 儿童可质疑来源污染、类型套用、材料遗漏和不利推定，并获得实质纠正 |

### 11. 合意性安排专项检查

附条件不起诉、认罪认罚或监督考察协议仍须具有可靠事实基础。一次签字、认错或接受条件不能替代排除合理怀疑，也不能证明儿童形成了稳定、独立的事实版本。须检查说明方式、关系压力、法律帮助、持续理解、资源核验、撤回、条件变更、技术性违约和救济。

### 12. 可迁移方法与不可迁移实体结论

**可迁移方法：**

- 从本土实践检验抽象或移植概念；
- 由总体分布进入典型个案，再由类型、结构上升到理论；
- 以最小单位—局部效果—群组—整体版本组织复杂材料；
- 同时建立主张版本与最强反方版本；
- 组合根据与融贯，并用外部证据防止封闭叙事；
- 明确类型的样本、反例和外推边界。

**不可直接迁移的实体结论：**

- 成年刑事案件的八种合理怀疑类型；
- “四阶合理怀疑”作为少年案件的法定标准；
- 6692份文书的比例和地域/罪名结论；
- 聚类集成、5%或完整怀疑版本足以决定少年案件的结论；
- 儿童须提出完整替代叙事方可触发疑罪从无。

## 五、`TMF76MJS` 初稿卡

### 1. 基本标签

- 题名：栗峥，《印证的证明原理与理论塑造》。
- 题录：`《中国法学》2019年第1期，印刷页264—283`。
- 主路线：`理论—制度建构`。
- 辅助模块：`实证诊断`、`比较法/制度史`。
- 素材池：`方法补强`。
- 证据层：`规范`、`理论`、`事实/实证`、`比较法/制度史`、`跨学科机制`、`实施条件`。
- 训练角色：主角色 `方法补强`；兼具 `历史演变`、`对抗`、`边界`。
- 重要作者覆盖层：栗峥。

### 2. 问题如何提出

**作者明示。** 文章从印证在中国司法规范和裁判中的高频使用、但理论上同时受到支持与“去印证化”批判切入，依次追问印证是否是有效证明方式、是否必须与自由心证兼容、哲学基础是什么以及有无替代模式。[`TMF76MJS`，印刷页264—265]

**训练综合。** 其问题化动作是`高频本土实践—理论地位不清—竞争批评—原理重建`：不因实践普遍就默认正当，也不因存在错案就整体废弃，而是拆分运行条件、偏差机制和哲学前提。

### 3. 概念如何拆分和界定

**作者明示。**

- 印证不同于完备证明，是非饱和、进阶、可废止的论证；证据越多并不自动等于证明完成。[印刷页265—267]
- 印证的对立面是“孤证”，孤证不是单纯数量为一，而是证据之间不能传递和支撑信息。[印刷页267—268]
- “相互”位于完全内容重合与仅方向一致之间，要求证明意蕴真正叠加。[印刷页267—268]
- 相互印证以非同一来源为前提，以概率叠列为理论说明。[印刷页268—271]
- 裁判信念被分为生成、培育、偏差和修正；临时性信念经印证检测才成为结论性信念。[印刷页275—279]
- 可靠主义被用来连接外部印证、内部信念与不确定司法证明。[印刷页279—283]

### 4. 规范、类型、模式或理论如何建构

**作者明示。**

1. 先确立印证的制度定位：非完备、进阶、可废止。[印刷页265—267]
2. 再提出运作条件：来源独立、证明意蕴重合、概率叠列。[印刷页267—271]
3. 以“口供印证勘验笔录”和聂树斌/王书金材料展示表面吻合、共同来源、信息要素可人为伸缩及跨案竞争的偏差。[印刷页271—275]
4. 由认知心理学构建信念生成—培育—偏差—修正，再以可靠主义提供哲学基础。[印刷页275—283]

**训练综合：候选新动作。**

- `关系成立前先查来源谱系`：一致之前先问是否独立取得、是否共享访谈者、材料、模型、数据或机构目标。
- `临时判断—偏差攻击—二次检测—结论判断`四段校验。
- `外部材料结构—内部判断机制—哲学评价标准`三层建构。
- `表面一致反转测试`：一致程度越“完美”，越要检查诱导、复制、数据泄漏、共同来源和人为选择分母。

### 5. 竞争观点和最强反驳

**作者明示的竞争关系。**

- 印证保留/去印证化；
- 完备证明/非饱和进阶论证；
- 单一证据/相互印证；
- 因果基础/概率叠列；
- 印证/自由心证；
- 确定性/不确定性/可靠性第三维度。[印刷页265—283]

**训练综合的最强反驳。**

1. 概率相乘只有在独立性等条件成立时才有意义；“不同来源”不必然等于统计独立，文章的示例不能直接成为定量证明公式。
2. 多个证据可能共享同一错误来源、同一访谈污染、同一数据库偏见或同一机构叙事，数量和一致性会放大而非纠正偏差。
3. “满意而非最大化”的可靠主义若处理不当，可能降低刑事证明应有的严格性。
4. 印证检测仍使用同一种印证逻辑，可能形成自我确认循环；必须引入异质材料、最强反方和独立复核。
5. 儿童陈述的一致与反复都具有发展、创伤和关系背景，不能用成人案件的“独立来源 + 一致”简单评分。

### 6. 机构、权限、程序、法律效果和救济

**作者明示。** 文章重点不在机构法，但通过口供与勘验笔录说明同一侦查机关、同一组人员和先勘验后讯问会破坏来源独立性；不同机关取得材料、跨案竞争及法院的证据评价影响最终有罪/无罪判断。[印刷页268—275]

**少年司法迁移闸门。**

- 对儿童多次陈述建立完整来源图：首次披露、家长询问、学校/社工访谈、侦查询问、心理评估、庭审陈述之间是否互相污染。
- 评估机构、服务机构和追诉机构不得通过共享模板、风险标签或案件摘要制造“相互印证”。
- 对每项一致和不一致保留原始记录、提问方式、时间、支持条件和修正路径。
- 法官或独立审查者必须测试共同来源、相反材料、遗漏信息和结论可废止性。
- 错误印证应产生排除、降低证明力、重新访谈/鉴定、变更决定和有效上诉等后果。

### 7. 实施条件与边界

- 来源独立须具体到人员、信息接触、访谈脚本、数据集、模型和组织激励，不能只看机构名称不同。
- 概率叠列是解释性模型，不是可直接套用的数值公式。
- 临时信念必须可撤销，二次检测须允许新证据和反方版本改变原结论。
- 认知心理学和可靠主义是理论支撑，本文没有提供少年司法中的实证验证。
- 2019年的规范文本、案例叙述和技术性概率假设不宜当前化或量化使用。

### 8. 严重案件与低风险案件压力测试

- **严重案件。** 严重性会强化锚定和确认偏误，更要检查口供、勘验、鉴定和评估是否真正独立；不能因“多项吻合”而忽略共同来源。
- **低风险案件。** 不应为追求更多印证而反复讯问儿童、扩张家庭/学校数据或制造多机构记录；最小干预优先。

### 9. 少年司法八闸门

| 闸门 | 对本文方法的迁移要求 |
|---|---|
| 最有利于未成年人 | 印证用于减少错误和伤害，不以提高定罪效率为唯一目标 |

### 10. 合意性安排专项检查

儿童承认事实、接受协议或同意信息使用，不会使其陈述与其他材料自动独立。若后续勘验、社会调查、评估或监督报告均以该承认为起点，表面多源实为单源派生。必须检查持续理解、法律帮助、提问污染、资源条件、撤回、条件变更、技术性违约和救济。

### 11. 可迁移方法与不可迁移实体结论

**可迁移方法：**

- 区分完备证明与进阶、可废止的判断；
- 不按证据数量，而按来源独立和证明意蕴关系审查；
- 在一致性之前绘制信息来源谱系；
- 用临时判断—偏差攻击—二次检测—结论判断避免锚定；
- 把技术原理、认知机制和评价哲学分层；
- 对“完美吻合”实施污染和共同来源反转测试。

**不可直接迁移的实体结论：**

- 印证是少年司法事实认定的首选模式；
- 成年案例中的口供、勘验、概率比例和证明结论；
- 证据越多、越一致就越可靠；
- 可靠主义“满意解”足以达到少年案件的证明标准；
- 成年裁判者信念生成模型可以直接解释未成年人陈述。

### 2. 问题如何提出

**训练综合。** 可迁移的问题化动作是`角色争论—能力清单—流程拆解—节点失真—有限方案`。面对技术、评估工具或新制度，先拆它在每一环节做什么、丢失什么、谁负责、如何纠正，而不是先回答“支持还是反对”。

### 3. 概念如何拆分和界定

**作者明示。**

- 人工智能介入司法被分为机械替代、辅助、预测参考和直接参与决策四层。[印刷页117—118]
- 事实认定被分为证据数据化、数据整合和结论输出三阶段。[印刷页118—119]
- 证据从完整“块结构”转为结构化数据，涉及特征提取、层级表达和语义/语法/语用难题。[印刷页119—123、130—132]
- 数据整合区分因果推理与概率推理，并进一步识别算法的可计算性和复杂性难题。[印刷页123—126]

### 4. 规范、类型、模式或理论如何建构

**作者明示。** 文章以输入—处理—输出为主链：

1. 输入端将实体证据转成结构化数据，但面临特征选择、信息减损和语言理解。[印刷页119—123]

## 十、H 批跨文候选规则

> 以下只是本批候选。须经独立复核、跨作者对抗、少年司法24篇领域核心校验和前向测试后，才可能进入运行时工作流。

### A. 教义学候选规则

1. **证明责任锁定。** 反方版本用于测试追诉命题，不得成为儿童必须完成的证明任务。
2. **来源谱系先于一致性。** 对口供、证言、社会调查、评估和数字记录，先画取得与传递路径，再判断是否独立支持。
3. **法律效果分层。** 信息存在、可采、可信、证明力、达到标准和可作为处分依据分别判断。
4. **临时判断可废止。** 初步评估、风险标签和协议事实基础必须允许新材料推翻，并配置复核和救济。
5. **共同来源排除。** 同一儿童陈述派生出的多份材料不能按数量累加证明力。
6. **技术输出不替代理由。** 概率、评分或模型文本必须还原为可理解、可质疑的事实和规范理由。

### B. 理论—制度建构候选规则

1. **材料—类型—结构—理论五级链。** 每级保留样本、筛选、反例、证据强度和外推边界。
2. **最小单元—关系—整体。** 先识别疑点/证据/数据特征，再解释关系和整体效果，避免直接跳到宏大概念。
3. **聚合污染测试。** 聚合前检查共同来源、共同偏见、组织激励、标签循环和数据泄漏。
4. **输入—转换—处理—输出—责任—救济。** 技术或评估制度必须完成全流程闭环。
5. **能/不能/尚不能证明。** 把制度能力与愿景分开，所有技术判断标时间。
6. **有限微结构试验。** 仅在限定问题和法律后果下前向验证，明确退出条件和人工可推翻性。
7. **本土生成不等于本土正当。** 高频实践先进入对抗和失败机制检查。

### C. 综述候选规则

1. **材料类型分层。** 规范、关键词统计、个案深描、跨学科理论和技术愿景分别评价。
2. **类型必须带反类型。** 每组分类至少报告无法归类、边界模糊和非典型儿童表达。
3. **作者变化分级。** 没有直接页证不写“转向”；优先使用继承、扩展、边界细化或内部张力。
4. **同一概念正反向追踪。** 比较证据如何聚成有罪版本与疑点如何聚成怀疑版本。
5. **技术现状加时间戳。** 历史技术判断只用于理论史，不用于当前产品事实。
6. **证据冲突不强行调和。** 当结构美感与样本局限、概率与因果、效率与儿童参与冲突时，保留争议并说明需要何种新证据。
