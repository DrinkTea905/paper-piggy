### 5.4 严重案件与低风险案件压力测试

#### 严重案件

1. 严重罪名、舆论关注、可能重刑、笼统“主观恶性”或风险高分均不能自动证明羁押必要。决定者必须指出现实、具体、迫近的逃跑、妨害证据或严重再犯风险，并说明证据来源。
2. 必须逐项解释为何住所支持、第三方保证、联系限制、陪同、治疗、密集社工、电子签到等较轻方式不足；不得把机构未提供资源归责于儿童。
3. 涉及被害人安全时，可以增加接触禁令、安全计划和被害人支持，但仍须个别化、期限化、可调整。
4. 如确需重大自由限制，应由中立机关作出有理由决定，儿童和律师获得材料并有效参与，设最短期限、自动定期复审、上诉或独立复核。
5. 观护表现不得反向证明有罪；拒绝思想汇报、心理测试、劳动或教育不得被解释为危险或悔罪不足。

#### 无风险或低风险案件

1. 不存在具体风险时，默认无条件释放；“为了教育”不能独立产生监管权限。
2. 低风险只允许与已识别风险严格对应的最少条件。住所、学习、就业、心理等服务应可自愿领取，不与强制监督或实体优惠捆绑。
3. 一次迟到、未汇报、学习困难或技术性违约须先作履行能力和支持核验；不得自动撤销、批捕或转为半开放基地。
4. 儿童拒绝基地、要求更换服务者或撤回非必要项目时，不得失去原本可获得的非羁押地位。

## 六、少年司法迁移闸门复核

| 闸门 | 两篇材料暴露的问题 | 迁移到专项工作流的强制条件 |
|---|---|---|
| 最有利于未成年人 | 两篇都以保护、复归和降低羁押为目标，但可能用保护目标正当化扩大监管、数据收集和提前矫治 | 每项限制分别说明为何真正改善该儿童利益，并审查短期自由、污名、教育中断、隐私和长期后果；保护目的不能替代权限 |
| 发展中能力 | 对年龄和心理有所提及，却没有把理解风险评估、基地规则、拒绝后果和表现报告用途作为持续能力任务 | 使用适龄语言和分段说明，反复确认理解；能力是具体任务、动态且可受支持的，不由一次签字或监护人同意替代 |
| 支持性参与 | 有听取意见、本人申请和监护人同意的零散做法，没有完整反馈、撤回和异议机制 | 决定前告知方案及后果，提供律师/合适成年人支持；参与须持续、知情、可撤回；决定者须回应儿童意见 |
| 关系自主 | 家庭、保证人、基地和办案机关既可能支持，也可能控制；监护人与儿童利益冲突未处理 | 同时审查儿童、监护人、律师、社工和机构关系；提供独立支持者，监护人同意不能压倒儿童意见，关系缺位触发机构补足 |
| 最小干预 | 量化高风险自动羁押、无风险仍监督、半开放限制和思想/劳动要求均可能过度 | 先无条件释放，再最少条件，再支持性替代；每次升级均须证明较轻方式不足，技术性违约不得自动升级 |
| 比例原则 | 风险等级替代了目的—必要性—衡量；半开放和更严监管没有清晰期限与复核 | 分别说明合法目的、适合性、必要性、负担衡量、期限和退出；严重案件也不能免除个别比例审查 |
| 机构支持义务 | 两篇最有价值的共同线索是住所、保证、教育和服务应由制度补足，但又被重新编码为个人风险 | 先做资源核验和合理调整；无住所、贫困、户籍、监护薄弱和服务不可达不得作为羁押或不利表现依据 |
| 有效审查与救济 | 两篇均以检察内部审查为主，缺乏法院/独立复核；基地条件、报告和数据无完整异议路径 | 提供律师、材料阅览、适龄理由、风险与报告更正、条件变更、退出、投诉、自动定期审查和独立上诉/复核；救济不得只在原决定系统内部循环 |

对合意性安排的特别迁移要求：本人申请、监护人签字或接受基地都只能证明某一时点的形式表示，不能直接证明理解、能力、公平或真实协商。专项工作流必须继续检查说明方式、资源核验、合理调整、条件可履行性、变更机制、技术性违约、撤回后果和独立救济。
