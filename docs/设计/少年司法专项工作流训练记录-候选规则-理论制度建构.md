# 少年司法专项工作流训练记录：理论—制度建构候选规则

## 一、适用边界

本文件仅提炼“论文初稿（少年司法版）”中理论—制度建构路线的有限根规则。规则依据已经完成逐页核验的少年司法核心材料、陈瑞华—栗峥作者纵向组，以及 A-P0、B-P0、A-P1、B-P2、C-P2、C-作者组原文裁决。陈瑞华、栗峥材料只提供问题化、概念操作、类型构造、规范链、证据评价与制度设计方法，不把成年刑事诉讼或证据法实体结论直接迁入少年司法。

以下定位中的“印刷页”是原刊印刷页；以训练文档条目定位的内容，均限于相应裁决或对抗记录已经重读、核实的字段。`core` 表示跨题目默认执行的根规则，`domain_specific` 表示少年司法专门闸门，`controversial` 只能生成争议矩阵或压力测试，`rejected` 必须从正面规则中删除。

rule_id: "JJ-T-09"
workflow_type: "论文初稿（少年司法版）"
scope: "真实负担、最小干预与比例控制"
trigger: "制度以非羁押、教育、保护、服务、分流或自愿等名称安排义务、监督、数据处理或行为限制"
required_inputs:
  - "措施的实际内容、频率、期限、累计要求和不履行后果"
  - "儿童及其家庭的时间、交通、经济、照护、学习、健康和数字接入条件"
  - "较低干预替代方案及其预期效果"
operation: >-
  不按措施名称而按真实负担评价干预强度。计算直接限制、累计义务、隐私成本、家庭转嫁和失败风险，
  逐项检验合法目的、适合性、必要性和狭义比例；优先采用能够达到目的的最低干预方案，
  并设置期限、复核、减免、调整和退出。把机构不能提供资源造成的失败从儿童责任中剥离。

## 五、不进入运行时的实体结论

以下内容可以作为具体论文的待证命题、争议背景或反例，但不能成为工作流默认答案：

- 独立少年司法体系必然优于少年案件特别程序。
- 某一精确年龄界限天然具有普遍正当性。
- 例外移送、逆送或回转模式在中国应当当然采用或当然排除。
- 半开放式观护、帮教或社会支持基地当然属于某一确定法律性质。
- 检察机关中心模式或法院司法化模式在所有案件中具有唯一优势。
- 法院参与协商、决定与事后审查可以当然由同一主体完成。
- 退出分流、撤回同意或未完成协议必然产生某一种固定实体效果。
- 家长同意、律师在场、一次签字、沉默或服从足以证明未成年人具备能力并真实同意。
- 教育、保护、社区、非羁押或自愿等名称足以排除措施的强制性。
- 高风险、高需要、家庭贫困、支持不足或服务失败可以自动提高控制强度。
- 技术性违约、迟到、漏报或资源不足导致的未履行可以自动撤销分流或升级处遇。
- 社会调查、心理、家庭、教育或服务信息可以默认跨机构共享，拒绝提供即可作不利推断。
- 风险评估、算法分数或机构记录可以自动决定处遇，且无需独立说明、质证、纠正和复核。
- 个案、单地访谈、相关关系或有限样本足以证明全国性事实、因果效果或制度普遍优越。
- 陈瑞华、栗峥关于成年刑事诉讼、证据法或认知结构的实体结论可以直接转化为少年司法制度答案。
