### （一）独立原文判断：方法与实体结论分离

**可保留的方法依据**

1. 将立法目标拆成适用率、适用条件、监督方式、条件内容、参与主体、违规处理和撤销等可观察环节，再用官方统计、案卷和多角色访谈交叉检查。作者同时主动披露非随机选点、样本偏向少年司法发展较好地区、案卷信息缺失以及没有长期再犯随访等局限。〔PDF 1—5／印刷页150—154〕
2. 将适用附条件不起诉的判断从单一罪名、刑期扩展到悔罪、各方意见、社会连接、监督需要、机构能力和办案组织条件，揭示规范入口与实施资源相互作用。〔PDF 5—10／印刷页154—159〕
3. 将监督考察连续拆成期限、场景、主体协作、未成年人理解与参与、考评、附带条件和撤销，为“决定—执行—变更—退出”全流程审查提供素材。〔PDF 10—18／印刷页159—167〕
4. 通过未成年人自己的叙述检验制度名义：部分未成年人不能完全理解监督考察，只能将其理解为“让做什么就做什么”；对重复思想汇报和不适龄材料缺乏兴趣，监督方式选择也有限。〔PDF 13—14／印刷页162—163〕
5. 把社会资源作为制度效果和适用平等的重要事实变量：家庭监管、本地联系、异地协作、社工、学校、观护基地和经费都会影响分流机会与实际履行。〔PDF 8—13、21—22／印刷页157—162、170—171〕

**只能作为作者实体主张、不得直接迁入运行时规则的结论**

1. 将是否具有监督考察必要性作为相对不起诉与附条件不起诉的主要界分，并认为多数涉罪未成年人都存在需要干预或支持的偏差、困境。〔PDF 9、19／印刷页158、168〕
2. 取消或大幅放宽罪名限制、把可能刑罚范围扩展到三年以下，并使具有一定风险者进入附条件不起诉。〔PDF 19／印刷页168〕
3. 由检察官居于监督考察核心，对推进、变更、终结和惩戒作决定。〔PDF 20／印刷页169〕
4. 把附带条件视为具有法律强制力的“刚性内核”，并以警告、训诫、延长期限、惩戒性临时羁押、撤销起诉构成递进制裁。〔PDF 17、20—21／印刷页166、169—170〕
5. 对不履行监管义务的监护人考虑警告、训诫、强制亲职教育乃至罚款。〔PDF 20／印刷页169〕

上述实体主张只能进入对抗和边界材料，不能仅凭本文直接成为少年司法工作流规则。

## 三、`UBBSPRAD` 独立复核

### （一）独立原文判断：方法与实体结论分离

**可保留的方法依据**

1. 对输入理论先做历史来源核查，识别同一“保护主义”标签下的国家干预、家庭控制、程序转处和避免刑事司法伤害等不同目标。〔PDF 1—5／印刷页724—728〕
2. 将国家亲权、最佳利益、特殊保护、优先保护分别放回理论基础、法律原则和规则要求等不同层次，检验概念之间能否真实推导，而不是用“保护”循环解释。〔PDF 5—7／印刷页728—730〕
3. 以功能而非法典外观组织分散规范，提出支持、矫治、转处三支柱，再检查“保护区、试验田、连通器”等支柱接口。〔PDF 7—10、13—20／印刷页730—733、736—743〕
4. 同时检查儿童、家庭、被害人、社会安全和刑法整体改革，迫使宏观体系论面对竞争价值。〔PDF 13—20／印刷页736—743〕
5. 用发展犯罪学材料反驳把早期越轨稳定等同于成年犯罪倾向，强调结构环境、司法制裁和发展机会的作用。〔PDF 14—15／印刷页737—738〕

**只能作为作者实体主张、不得直接迁入运行时规则的结论**

1. 中国分散立法已能通过功能分化形成体系，现阶段没有制定统一少年法、少年刑法或少年司法法的制度需求。〔PDF 7—8／印刷页730—731〕
2. 专门教育即使具有强制、不定期和限制人身自由等特点，仍因目的有利而属于保护处分、不是刑罚。〔PDF 11—13／印刷页734—736〕
3. 刑罚对未成年人具有不可替代的预防功能，下调最低刑事责任年龄具有科学性。〔PDF 13—14／印刷页736—737〕
4. 扩大专门矫治教育适用范围，并以刑法对严重不履行保护义务的行为适度犯罪化。〔PDF 19／印刷页742〕

### （三）保护处分、最低年龄和最佳利益专项复核

1. **实质制裁性**：专门教育的法律性质不能只看“教育”“有利”目的。至少应按决定是否违背本人意愿、是否限制人身自由、期限是否预先确定、违反后果、记录与污名、退出机制和救济进行实质审查。叶文确认其强制、不定期和限制自由，却以目的有益直接排除刑罚性质，这一推理不足以排除制裁性保障。〔PDF 12—13／印刷页735—736〕建议结论：保留争议。
2. **最低年龄**：叶文讨论降低刑事责任年龄，却没有为不以刑罚命名的限制自由保护处分设置最低年龄。若措施可能比刑罚更早、更久、更难退出，最低年龄与发展中能力审查不能因改变名称而消失。〔PDF 12—14／印刷页735—737〕建议结论：修正建议。
3. **最佳利益与刑法原则**：可以保留“最佳利益不能替代罪刑法定、责任和罪责刑相适应”，但应同时明确最佳利益、最小干预和发展中能力能够约束制度目的、程序支持、干预强度和替代措施选择；两组规范不是非此即彼。〔PDF 5、10、14／印刷页728、733、737〕建议结论：修正建议。
4. **严重案件**：必须检验被害人保护和公共安全，但个案轶事不能代替责任能力、程序能力、制裁效果和替代方案证据。〔PDF 13、16／印刷页736、739〕建议结论：降级建议。
5. **低风险案件**：对一般不良行为或结构性困境，应先使用普惠支持、学校支持和家庭服务；行政强制、不定期处置若没有窄入口和退出权，会重演作者自己批判的网络扩大。〔PDF 11—13、18／印刷页734—736、741〕建议结论：保留争议。

### （四）本篇复核小结

- 试读 A 对理论路线、保护主义内部拆分、三支柱方法价值以及实质强制风险的识别总体可靠。
- 必须纠正一处原文忠实性问题：叶文只说最佳利益不能“替代”刑法原则，试读 A 不应把它归纳为最佳利益不能成为少年刑法内部约束。
- 必须新增一个独立争点：专门教育等限制自由保护处分的最低年龄不能被刑事责任年龄或“有利目的”自动替代。
- 三支柱、“保护区—试验田—连通器”可作为组织材料的方法，但人力资本、高危群体、专门教育非制裁、下调年龄科学性、扩大矫治和刑法适度犯罪化均属于实体政策主张。

## 四、交叉压力测试

### （一）低风险案件

- 何文可能把本可相对不起诉的低风险儿童因“监督需要”纳入有期限、有条件、有违约后果的考察；叶文的分级矫治则可能把不良行为和环境困境儿童纳入强制、不定期专门教育。两者共同提示：支持需要不能自动等于强制干预必要性。〔何挺，PDF 9、19／印刷页158、168；叶小琴，PDF 11—13／印刷页734—736〕
- 工作流候选规则应先问：不介入、无条件分流或普惠支持能否满足需要；若能，强制考察或限制自由保护处分不得仅因“教育更好”而启动。建议结论：保留。

### （二）严重案件

- 何文以较高法定刑、暴力后果和一定风险说明附条件不起诉可扩大，但缺少长期效果和严格独立审查；叶文以被害人保护、刑罚预防和严重个案支持惩罚与下调年龄，但证据不足以证明一般规则。〔何挺，PDF 6—7、10、18—20／印刷页155—156、159、167—169；叶小琴，PDF 13—16／印刷页736—739〕
- 严重案件不能因保护口号自动分流，也不能因个案恐惧自动重罚。至少应同时检验责任能力、受审能力、事实证明、被害人安全、最小干预、比例、替代方案、机构资源和救济。建议结论：保留。

### （三）名义保护与实质制裁

- 何文把附带条件界定为刚性法律义务，并主张分级惩戒；叶文则把强制、不定期、限制自由的专门教育排除于刑罚。两篇从相反方向共同证明：制度名称和善意目的都不能替代权利效果审查。〔何挺，PDF 17、20—21／印刷页166、169—170；叶小琴，PDF 12—13／印刷页735—736〕
- 候选规则应统一审查强制性、期限、自由限制、条件负担、违约后果、信息记录、决定主体、参与、变更、退出和救济。建议结论：保留。

### （四）决定权集中与独立审查

- 何文以检察官为监督、变更、惩戒和终结核心；叶文描述专门教育由教育行政部门或其会同公安机关决定、指导委员会评估退出。两种结构都缺少充分的独立审查设计。〔何挺，PDF 20／印刷页169；叶小琴，PDF 12／印刷页735〕
- 对限制自由、延长期限、增加条件、惩戒和撤销等重要不利决定，不能只依赖原决定或执行机关内部评估。建议结论：修正建议。
