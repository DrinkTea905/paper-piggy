## 0. 本轮要形成什么

本轮主任务只有两项：

1. `论文初稿（少年司法版）`
2. `综述（少年司法版）`

产品实施时同时调整路由：

- 现有 `写论文与综述` 缩窄并改名为通用 `综述`；
- 少年司法主题的综述自动采用 `综述（少年司法版）`；
- 少年司法主题的论文初稿自动采用 `论文初稿（少年司法版）`；
- 从少年司法初稿版删去领域专门模块，派生一个 `论文初稿（通用暂用版）`，供其他领域暂用。它不是本轮独立训练对象，并须注明尚未经过其他部门法素材验证。

临时通用版名称已经确定为 `论文初稿（通用暂用版）`。

## 1. 自动路由

先识别任务类型，再识别主题：

| 用户任务 | 少年司法主题 | 非少年司法主题 |
|---|---|---|
| 文献综述、研究现状、学说史、争议地图、资料汇编 | `综述（少年司法版）` | `综述` |
| 论文初稿、章节初稿、中心命题论证、制度建构稿 | `论文初稿（少年司法版）` | `论文初稿（通用暂用版）` |
| 只说“研究提纲”或“研究报告”，无法判断文体 | 只问一个问题：要综述还是论证型初稿 | 同左 |

少年司法主题包括但不限于：少年司法、未成年人司法、未成年人刑事司法、罪错未成年人、涉罪未成年人、附条件不起诉、社会调查、合适成年人、犯罪记录封存、专门教育、专门矫治教育、未成年人犯罪处遇、少年法庭、未成年人检察。

专门版优先于通用版。不能因为项目主线是少年司法，就把任何刑法或刑诉任务都误判为少年司法；仍须看具体研究对象。

### 1.1 初稿工作流只设两条主路线

`论文初稿（少年司法版）` 内部只设两条路线，不再拆成两个顶层工作流：

1. **教义学路线**：处理现行规范的含义、位阶、冲突、体系位置、适用条件、程序、法律效果、例外与救济。
2. **理论—制度建构路线**：处理基础概念、正当性、基本原则、少年司法模式、立法批判与制度体系重构。内部可以标注“偏理论重构”或“偏立法批判”，但不再拆成新版本。

另设两个可叠加而不独立成版本的证据模块：

- **实证诊断模块**：用调查、案例、统计或实施材料检验制度问题及改革必要性；
- **比较法/制度史模块**：说明制度谱系、前提差异和可移植边界。

混合题目必须确定一条主路线，另一条路线只能作为辅助论证。若用户真正要求原创实证研究，
且核心结论依赖尚未取得的数据，不得把它硬塞进上述两条路线，也不得编造数据；应先建议转为实证研究设计。

### 1.2 起草前的双方案选择闸门

识别为少年司法论文初稿后，先分析题目，再向用户同时提交两张方案卡：

| 必填项 | 教义学方案 | 理论—制度建构方案 |
|---|---|---|
| 适配度 | 推荐 / 可选 / 不建议，并说明原因 | 推荐 / 可选 / 不建议，并说明原因 |
| 拟题 | 给出与本路线一致的完整标题 | 给出与本路线一致的完整标题 |
| 核心问题 | 现行规范究竟应如何理解和适用 | 既有概念、原则或制度模式为何需要重构 |
| 中心观点 | 可由规范依据和解释方法推出的命题 | 可由理论前提、制度功能与反例支持的命题 |
| 大纲 | 至少给出三级提纲骨架 | 至少给出三级提纲骨架 |
| 主要内容 | 逐部分说明要解决的问题 | 逐部分说明理论、批判与建构任务 |
| 所需材料 | 法源、案例、解释资料、反方与救济 | 理论谱系、制度史、比较法、实证与反例 |
| 风险 | 越过解释边界、规范缺位、救济不足等 | 口号化、概念层级错置、制度不可实施等 |

必须明确推荐其中一条，但在用户选择前不得直接进入全文起草。若某条路线明显不成立，
仍需说明其可能标题、论证方向及失败原因，不能用一个空泛选项凑数。

### 2.1 本轮素材准入硬门槛

正式训练素材必须同时满足：

1. 正文为中文；
2. 发表在中国大陆期刊；台湾期刊及以台湾制度为主要训练对象的论文不纳入；
3. 有可逐页读取的完整全文；
4. 来源属于三大刊或 CLSCI；CSSCI-only、CSSCI扩展、普通期刊不纳入；
5. 实际完成了本工作流需要的方法作业，而不是仅有相关关键词。

域外制度可以作为大陆中文 CLSCI 论文中的比较对象，但不得用外文原文或台湾论文直接训练。
书籍、学位论文、报告和 Wiki 可以用于发现线索，不能进入本轮规则蒸馏的正式训练集。

按这一标准，原24篇共享核心中有7篇因属于CSSCI、CSSCI扩展或台湾期刊而退出；已经全部用
大陆中文CLSCI论文替换。37篇机器候选中还会继续排除台湾制度专门研究、一般轻罪制度等误入材料。

合格的少年司法文章中，暂未发现标题明确以“综述、述评、研究进展”等为体裁的完整范本。

## 3. 够不够

### 3.1 结论

现有材料**足够直接启动两个少年司法专项工作流的 v1 训练，不需要用户现在继续下载刑诉法或刑法论文**。

但也有两个限定：

1. 仅靠三大刊中7篇少年司法文章不够；必须同时使用符合门槛的少年司法CLSCI论文，以及三大刊/CLSCI刑诉、刑法方法素材。
2. `综述（少年司法版）` 缺少同等级的完整综述范本。v1先把合格论文中的文献评述、问题史、理论谱系和争议整理部分作为训练单元，并以真实任务验证；如果仍不稳定，只报告缺口，不自动放宽期刊等级。

### 3.2 本轮推荐规模

两个工作流共享一个冻结素材池，但分别做文章卡和规则卡。**24 篇共享领域核心足以形成最低可用开发集**；
本轮又确定将所有通过门槛的陈瑞华、栗峥论文作为必读的重要作者纵向组，因而不能再沿用
32—40 份的旧上限。当前可见的题录准入候选为 17 篇，连同 24 篇领域核心共有 41 份候选素材；
其中 `Z3GBTTSC` 尚未完成深索，当前可立即精读的是 40 份。用户所说的第二篇新加栗峥论文尚未在快照中出现。
`Z3GBTTSC` 与第二篇新增论文都就绪且通过门槛后，最低池为 42 份。

因此，本轮可用 v1 的操作目标调整为 **42—48 份独立素材**；若一篇或两篇新增论文到冻结时仍未就绪或不符合门槛，
可以先以 40—41 份已就绪素材完成当前批次，将未就绪者列为具名待核材料，不为凑数而降低标准。只有前向测试仍暴露
明确的方法缺口时，才在作者组之外再补 1—6 篇刑诉或刑法素材：

| 模块 | 建议数量 | 说明 |
|---|---:|---|
| 少年司法领域核心 | 24 | 全部为大陆中文、三大刊/CLSCI全文 |
| 陈瑞华重要作者纵向组 | 当前13 | 全部合格篇必读；制度结构、程序价值、协商、审查、救济与实施条件 |
| 栗峥重要作者纵向组 | 当前可见4，另1篇待出现 | 全部合格篇必读；关系结构、证明机制、经验类型与理论建构 |
| 其他教义学/理论建构补强 | 0—6 | 仅在作者组和领域核心仍留下明确缺口时定向补入 |
| 文献评述/问题史/理论谱系片段 | 5—8 | 从合格论文内部抽取，可与前三组重合 |
| 同题对立立场与强反例 | 至少 6 组 | 同样可与前三组重合 |

首轮不必等全部素材读完。先用 **18 份试读集**定标签和文章卡；结构成立后，再扩到
24 篇领域核心，再集中处理陈瑞华、栗峥重要作者纵向组并观察饱和。42—48 份是本轮的目标区间，
不是要求从同义文章中机械制造不同规则。

因此，数量口径不是“两个工作流各准备几十篇”。两者共享24篇领域核心；
初稿工作流再分别提取教义学与理论—制度建构规则，综述工作流另做综述卡。
重复进入不同训练任务的同一篇文章只计一份独立素材。

#### 纵向与交叉提炼

陈瑞华作者纵向卡重点观察：

- 从证据法的价值与功能、羁押和侦查结构，发展到诉讼模式、协商程序、救济和实施条件的连续链条；
- 如何从中国制度经验形成概念和中层理论，再以反例、比较法及运行效果校验；
- 如何把机构、权限、程序、法律效果和救济连接成制度架构。

栗峥作者纵向卡重点观察：

- 从证据关系和结构，到证明机制、经验类型、法理建构及技术边界的演进；
- 如何把概念拆到最小分析单元，再从关系、类型和机制上升到中层理论；
- 如何处理本土经验、外来概念与一般理论之间的张力。

两组至少建立五类交叉对抗：

1. 程序价值与权利控制，对知识、证明和关系结构；
2. 国家权力、机构功能与救济，对证据组织和认知机制；
3. “经验—问题—概念—理论”，对“数据/材料—类型—机制—范式”；
4. 形式合意、自愿和理性选择，对能力、支持、关系自主与持续参与；
5. 规范法律效果，对结构性、经验性和实施条件解释。

迁入少年司法时只迁移方法，不直接迁移成年刑诉结论。每一候选规则都要再经过最有利原则、发展中能力、
支持性参与、最小干预、比例原则、机构支持义务和24篇领域核心的校验。尤其在附条件不起诉和监督考察协议中，
必须区分一次性签字与持续、知情且受支持的参与，检查说明、资源核验、合理调整、履行能力、条件变更、
技术性违约、撤销及救济，不能把“同意”直接等同于能力或公平。

## 4. 素材覆盖矩阵

少年司法领域核心至少覆盖：

1. 少年司法模式、国家亲权、最有利原则与发展型司法；
2. 保护、责任、惩罚、教育、再社会化与最小干预之间的关系；
3. 刑事责任年龄、责任能力、违法与有责；
4. 侦查、起诉、审判、执行中的专门程序和权利保障；
5. 分流、相对不起诉、附条件不起诉和监督考察；
6. 社会调查、风险—需求评估及专业社会支持；
7. 犯罪记录封存、复归社会和附随后果；
8. 专门教育、专门矫治教育、社区处遇和监禁；
9. 被害人、恢复性司法和严重暴力案件的反向压力；
10. 儿童参与、发展中能力、程序理解与关系自主；
11. 中国制度史、域外模式与比较法转化；
12. 规范研究、实证研究和跨学科证据的关系。

教义学路线训练还要确保出现以下动作：

- 法源、位阶、时效和机构权限；
- 文义、体系、目的、历史、合宪性和比较法解释；
- 概念—类型—要件—程序—法律效果—例外—救济；
- 一般法与特别法、实体与程序、保护法与刑事法的协调；
- 解释论与立法论分离；
- 最强反方、边界案件和实施条件。

理论—制度建构路线训练还要确保出现：

- 区分儿童福利、未成年人保护、少年司法与少年刑事司法的概念层级；
- 识别国家亲权、儿童权利、责任、教育、惩罚、福利和社会防卫之间的竞争前提；
- 从制度史、比较法与中国实践中提炼中层命题，避免直接搬运域外模式；
- 把原则重构转化为机构、权限、程序、措施、效果与救济的制度架构；
- 区分对现行法的批判、解释论可行空间与真正需要立法解决的问题；
- 用严重案件、低风险案件、被害人利益、资源不足和机构失职检验理论；
- 避免只靠价值宣示、概念换名或宏大叙事得出制度结论。

综述训练还要确保出现：

- 明示检索与纳入边界；
- 时间、地域、学科、方法和证据类型等多重分类轴；
- 代表观点、继承关系和真实分歧；
- 规范论证、实证效果和跨学科机制证据分层；
- 共识、争议、证据强弱与空白的限定表达；
- 从文献地图导向可研究问题，而不是在结尾罗列口号。

## 5. 两套独立训练产物

### 5.1 初稿文章卡

每篇记录：

- 主要路线标签：教义学 / 理论—制度建构 / 两者均可；
- 辅助模块标签：实证诊断 / 比较法与制度史 / 无；
- 素材层与训练角色：领域核心 / 重要作者纵向组 / 对抗 / 历史 / 边界 / 重复例证；
- 规范或实践难题；
- 现行规范地图；
- 竞争解释与论证负担；
- 作者实际完成的教义学或理论—制度建构动作；
- 形成的概念、要件、程序、法律效果、例外或救济；
- 少年司法特殊逻辑与普通刑法、刑诉逻辑如何协调；
- 若属理论—制度建构，理论前提如何落到可执行的制度安排；
- 反例与实施边界；
- 可迁移方法、不可迁移结论和原文页码。

### 5.2 综述文章卡

同一篇文章另行记录：

- 研究范围与材料边界；
- 分类轴；
- 学说或制度演进；
- 代表观点和依据；
- 争议的真正对象；
- 规范、实证、比较和跨学科证据如何分层；
- 作者如何提出研究缺口；
- 可迁移结构、过度概括风险和原文页码。

两套卡不得合并成“一篇论文一个万能摘要”。

### 5.3 重要作者纵向卡

陈瑞华、栗峥除逐篇制作初稿卡和综述卡外，各自另做一张滚动更新的作者纵向卡：

- 稳定的问题意识；
- 反复使用的概念、类型和关系操作；
- 常见的理论建构与制度推理链；
- 不同年份文章之间的继承、修正和转向；
- 作者内部尚未解决的张力；
- 可以迁入少年司法的研究方法；
- 不能迁入的成年刑诉或证据法实体结论；
- 少年司法迁移时必须补入的能力、支持、比例、最小干预与救济条件；
- 对两套专项工作流分别贡献了哪些候选规则，以及哪些文章只作历史、对抗或边界材料。

作者纵向卡不写成作者思想综述，也不以作者声望替代规则验证。若多篇文章只重复同一方法动作，
仍逐篇记录其训练角色，但候选工作流只保留一条经合并的规则。

## 6. 子代理分工

每批 4—6 篇，按下列顺序运行：

1. **读取代理**：完整阅读原文，生成一种任务类型的文章卡。
2. **独立复核代理**：抽取 25%—35% 样本重新阅读；核心文章、低置信度和新标签强制复核。
3. **对抗代理**：用同题异说、规范位阶、制度前提和边界案件攻击文章卡与候选规则。
4. **裁决代理**：只针对异议重读原文页，决定保留、修正、降级、保留争议或删除。
5. **教义学路线总结代理**：只读取裁决后标为教义学的初稿卡，生成教义学路线规则。
6. **理论—制度建构路线总结代理**：只读取裁决后标为理论—制度建构的初稿卡，生成该路线规则。
7. **综述总结代理**：只读取裁决后的综述卡，生成综述规则。
8. **重要作者纵向总结代理**：分别形成陈瑞华、栗峥纵向卡，标出跨年修正、内部张力和文章角色。
9. **交叉对抗代理**：按价值/认知、权力/证明、合意/能力、规范效果/结构解释进行作者间对抗。
10. **主代理**：检查三套规则是否越界、是否遗漏少年司法专门性，并把两条初稿路线合并进同一个候选工作流。

这不是匿名 A/B 测试。独立复核用于发现阅读误差，对抗用于检验规则，最后依据原文裁决。

### 阶段三：生成候选工作流

`论文初稿（少年司法版）` 的共同流水线拟为：

1. 判断是否为少年司法论文初稿任务；
2. 诊断题目更适合教义学还是理论—制度建构路线，并识别是否需要实证诊断、比较法/制度史模块；
3. 为两条路线分别生成标题、核心问题、中心观点、三级提纲、主要内容、所需材料和风险；
4. 明确推荐路线及理由，等待用户选择；
5. 按选定路线建立少年司法专门规范/理论地图及普通刑事法基线；
6. 构造争点树、竞争解释或竞争理论；
7. 把儿童发展、最有利原则、参与和最小干预，与责任、法定、程序正当、比例、被害人和社会保护并置；
8. 用严重案件、低风险案件、资源不足、权利限制和机构失职做压力测试；
9. 分节起草；
10. 做规范/理论、反方、事实证据和引注四重核验。

教义学路线必须完成规范位阶、解释、体系、要件/程序、效果、例外和救济作业，并标明解释论边界。
理论—制度建构路线必须完成概念层级、理论前提、竞争模式、中层命题、制度落点、实施条件和反例作业。
陈瑞华、栗峥作者组对初稿工作流主要贡献问题提炼、概念拆分、类型/模式构造、规范链、机构与程序设计、
法律效果、救济、最强反例和实施边界；运行时不得要求机械引用作者，也不得把成年刑诉结论直接写成少年司法规则。

`综述（少年司法版）` 的核心流水线拟为：

1. 明确时间、地域、对象、制度和材料类型边界；
2. 建检索词族与纳入/排除标准；
3. 形成理论—制度—程序—实践—效果的文献地图；
4. 逐篇精读并区分作者主张、研究方法和证据；
5. 按问题与争点组织，不按作者流水账排列；
6. 展示观点谱系、真实争议和时代变化；
7. 分层评价规范理由、实证效果与跨学科证据；
8. 识别有边界的证据缺口和待研究问题；
9. 起草综述并逐项核验；
10. 交付文献地图、正文和缺口清单。

陈瑞华、栗峥作者组对综述工作流主要贡献理论谱系、概念演进、竞争模式、证据基础、作者内部修正和未决争议的
组织方法。综述必须区分“作者原有主张”“跨篇纵向重构”“训练者的跨作者综合”，不得把作者序列压成一个静态标签。

### 阶段四：直接前向验证

不用匿名 A/B。分别选择未直接用于规则总结的真实少年司法题目：

- 初稿路线判断：一个明显适合教义学的题目、一个明显适合理论—制度建构的题目、一个两条路线都可行的混合题目；
- 初稿成文：在用户选择路线后，分别完成一个教义学题和一个理论—制度建构题；
- 综述：一个宽主题、一个窄争点、一个规范与实证证据冲突的主题。

按完成标准检查触发、双方案质量、推荐理由、用户选择闸门、原文忠实、路线作业、反方、边界和可用性，再修订工作流。
