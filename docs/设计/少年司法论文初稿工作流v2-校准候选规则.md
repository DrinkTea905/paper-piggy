# 少年司法论文初稿工作流 v2｜校准候选规则登记表

> 状态：校准阶段候选历史快照；24篇训练后的最终裁决与去向以《[24篇规则冻结与运行时映射](少年司法论文初稿工作流v2-24篇规则冻结与运行时映射.md)》为准。
> 来源范围：仅限 C01—C08 八份已裁决写作工艺卡。
> 使用禁令：本表只保存“前8篇校准时看到了什么”，不得单独作为运行时事实源；后续使用须读取24篇冻结记录，并继续接受未见验证。
> 门槛口径：只有“至少 3 篇论文、跨 2 组作者”的跨文规律才可登记为一般候选。未达到者只作设计记录。同一作者的多篇论文保守地只计一个作者来源。
> 性质口径：下列候选本身均为跨卡“训练综合”，不是任何作者明示的通则；“作者明示／结构推断”只说明候选所依赖的卡内基础判断性质。
