## 3. 逐篇文章卡

### 3.1 `TXY75SMN`：最有利于未成年人原则适用的检察路径

#### A. 初稿卡

- **主路线**：教义学。文章不是对单一法条作狭义涵摄，而是先解释《未成年人保护法》第 4 条原则的内涵和法律地位，再把它转换为检察裁量、法律解释及制度建构标准，属于“原则型教义学＋制度应用”。辅助模块为无；文中官方统计、文身公益诉讼等仅用于提示现实问题和制度例证，不构成因果性实证研究。[顺序页 2—3 / 印刷页 4—5；顺序页 7 / 印刷页 9]
- **素材层 / 训练角色**：领域核心；承担“抽象原则操作化”的核心规则依据，同时用于警示价值原则不能跳过现行法、权限、其他主体利益和救济。
- **问题如何提出**：作者从两类落差提出问题：一是未成年人犯罪、被害和民事行政权益损害的复合现实与单一刑事处理之间的落差；二是普通成人程序的惯性与社会调查、合适成年人等特别赋权形式化之间的落差，进而要求用最有利原则统一未检的刑事、民事、行政和公益诉讼履职。[顺序页 2—3 / 印刷页 4—5]
- **概念如何拆分和界定**：
  1. 本质要求是未成年人权利本位，既指个体、特定群体，也指未成年人整体；保护必须纳入儿童自身意愿，而不是单向给予。[顺序页 4—5 / 印刷页 6—7]
  2. 该原则是所有成年人和相关组织处理涉未事项的普适义务，家庭负首要责任，国家负监督和兜底责任，司法是最后防线。[顺序页 5 / 印刷页 7]
  3. 特殊、优先考虑不等于未成年人利益无序扩张：有明确部门法时在现行法空间内最大化；无明确规定时也须尊重其他部门法原理和其他主体利益。[顺序页 5 / 印刷页 7]
  4. 原则必须由沟通、事实获取、时限、专业人员、法律帮助、相反决定说明理由、儿童权利影响评估等程序保障承载。[顺序页 5—6 / 印刷页 7—8]
- **规范、类型、模式或理论如何建构**：文章形成“4 项内涵＋3 层法律功能＋5 组实施路径”的结构。三层功能是个案权衡标准、现行法解释依据、制度发展和体系建构动力；实施路径依次为理念更新、双向保护、综合司法保护、“六大保护”协同和专业队伍建设。[顺序页 6—7 / 印刷页 8—9；顺序页 7—13 / 印刷页 9—15]
- **竞争观点和最强反驳**：
  - “最有利”与其他主体利益：作者明确拒绝未成年人利益无边界扩张，并要求尊重部门法框架。[顺序页 5 / 印刷页 7]
  - 法定代理人优先到场与最适合儿童的支持者到场：亲子紧张或监护缺失时，不能把父母身份机械等同于最有利，应结合儿童意愿、情感支持和候选合适成年人选择。[顺序页 6 / 印刷页 8]
  - 教育宽缓与严重案件责任：作者主张避免“不教而罚”和“不教而宽”，轻微初偶犯宽缓，严重恶性案件依法惩罚、教育和管束一体落实。[顺序页 8 / 印刷页 10]
  - 分流率与最低干预：可直接不起诉的案件不得为提高附条件不起诉率而进入更重的监督考察。[顺序页 8 / 印刷页 10]
  - 本卡提出的最强外部反驳是：原则只能提供解释方向，不能自行生成职权、剥夺自由或替代明确法律；“综合履职”也不能代替中立复审和可执行救济。文章已触及前半问题，但后半制度保障不足。
- **机构、权限、程序、法律效果和救济**：
  - 机构：未成年人检察机构、公安、法院、司法社工、心理咨询师以及家庭、学校、社会、网络、政府等保护主体。[顺序页 3—4 / 印刷页 5—6；顺序页 12—13 / 印刷页 14—15]
  - 权限：原则被用来填充、引导并限制个案裁量，也用作法律解释和检察监督、公益诉讼、支持起诉、监护监督的方向标准；但文章没有为原则创设法外权力。[顺序页 6—7 / 印刷页 8—9；顺序页 10—12 / 印刷页 12—14]
  - 程序：沟通与听取意见、社会调查、法律帮助、相反决定说理、权利影响评估、系统审查和综合取证、融合履职程序衔接。[顺序页 5—6 / 印刷页 7—8；顺序页 10 / 印刷页 12]
  - 效果：分案、分别关押，少捕慎诉慎押，直接不起诉优先于不必要的附条件不起诉，犯罪记录封存，一站式询问和综合救助，民事行政公益权益协同保护。[顺序页 8—12 / 印刷页 10—14]
  - 救济：文章提到被害人对附条件不起诉和不起诉决定向上一级检察院申诉，以及法律援助、检察听证和行政争议实质化解；对未成年人不服“最有利”判断的独立复审、撤回、申诉和司法救济未形成完整设计。[顺序页 6 / 印刷页 8；顺序页 11 / 印刷页 13]
- **实施条件与边界**：
  - 必须有专业机构、专业人员、社会支持、动态社会调查、跨部门协同、合理考评和儿童意见机制，不能把原则停留在政治或价值口号。[顺序页 3、8、12—13 / 印刷页 5、10、14—15]
  - 对父母亲权干预应分级，撤销监护资格是迫不得已措施，轻微失职优先采用督促、指导和关系修复。[顺序页 11 / 印刷页 13]
  - 双向保护要求同时照顾涉罪未成年人和未成年被害人，恢复性安排须以双方真实意愿为前提，不能把对行为人的宽缓等同于被害人保护已经实现。[顺序页 9—10 / 印刷页 11—12]
- **少年司法专门逻辑**：权利主体地位、发展规律、儿童意见、特殊优先保护、非犯罪化/非刑罚化/非监禁化、双向保护和分级干预共同构成成人刑事司法基线之外的专门校验；严重案件仍受法定、比例和程序约束。[顺序页 4—6 / 印刷页 6—8；顺序页 8—10 / 印刷页 10—12]
- **可迁移方法**：
  1. 对抽象原则依次完成“规范文本—构成要素—法律地位—场景化程序—机构实施”的五步操作。
  2. 同时区分个体、特定群体和整体儿童利益，防止个案结论直接外推政策。
  3. 每次援引原则都附带“现行法边界、其他利益、程序保障、相反决定说理”四项检查。
  4. 用低风险案件、严重案件、行为人与被害人均为儿童、家庭失灵四类压力场景检验原则。
- **不可迁移的实体结论**：
  - “帝王条款”的修辞不能替代规范位阶论证。
  - 检察机关“四大检察”融合、具体政策口号、截至 2022 年机构数字和 2018—2021 年案件统计是特定制度时点材料，不自动成为工作流常量。[顺序页 2—3 / 印刷页 4—5]
  - 对文身、入职查询、公益诉讼管辖等具体结论只能在相应法源和权限重新核验后使用。[顺序页 7、10—12 / 印刷页 9、12—14]

#### B. 综述卡

- **范围边界**：2023 年中国未成年人检察语境中的原则解释与履职路径；以规范、政策、检察实践例证为主，不是系统检索的学术综述，也不评价各种保护措施的因果效果。[顺序页 1—3 / 印刷页 3—5]
- **分类轴**：
  1. 原则的意义—内涵—法律地位—具体适用；
  2. 个体儿童—特定群体—全体儿童；
  3. 涉罪未成年人—未成年被害人—公共利益；
  4. 刑事、民事、行政、公益诉讼与家庭、学校、社会、网络、政府、司法保护。
- **谱系 / 演进**：从《儿童权利公约》的儿童最大利益原则，经修订《未成年人保护法》第 4 条的本土表达，发展为检察个案权衡、法律解释和制度建构依据。[顺序页 2、4—7 / 印刷页 4、6—9]
- **代表观点及证据**：文章引用儿童权利理论、儿童最佳利益研究、未成年人特别程序形式化研究及联合国儿童权利委员会第 14 号一般性意见，并以检察统计、合适成年人/社会调查实践、文身公益诉讼和综合履职场景支撑制度说明。[顺序页 2—7 / 印刷页 4—9]
- **真实争议**：未成年人利益优先是否有边界；保护是单向替代还是支持性参与；宽缓、教育与严重案件责任如何协调；检察综合履职能否越过部门法权限；行为人保护和被害人保护如何同时落实。[顺序页 5、8—11 / 印刷页 7、10—13]
- **证据分层**：
  - 规范层：国际公约、一般性意见、未成年人保护法、刑事诉讼法及立法解释。
  - 实证层：官方案件数字和个别实践案例，只能证明问题存在或制度运作，不能单独证明措施有效。
  - 比较层：联合国程序保障清单。
  - 跨学科层：青春期违法高峰与自我终止犯罪的犯罪学论据，仅为最低干预方向提供机制背景。[顺序页 5—8 / 印刷页 7—10]

### 3.2 `28ZHYN6P`：中国未成年人司法制度的建构路径

#### A. 初稿卡

- **主路线**：理论—制度建构；辅助模块为比较法/制度史。文章先诊断“成人司法例外化、制度分散化”的结构问题，再以历史与四国模式提炼中国方案，以四原则支撑五组制度构造。[顺序页 2—10 / 印刷页 3—11]
- **素材层 / 训练角色**：领域核心、宏观制度建构核心依据；同时作为对抗样本，检验宏大原则能否落实为机构、权限、程序、效果和救济。
- **问题如何提出**：现有制度虽已有未成年人刑事特别程序和保护法框架，但罪错行为标准、处遇衔接、刑罚精细化、国家责任、社会支持、被害人和民事行政权益保护仍分散在成人司法例外条款中，无法形成专门独立体系。[顺序页 2、4—6 / 印刷页 3、5—7]
- **概念如何拆分和界定**：
  - 未成年人法律体系被拆成福利法、保护法、司法法三部分；未成年人司法不是所有涉未规则总和，而是其中专门法部分。[顺序页 8 / 印刷页 9]
  - 从“小司法”转向“大司法”，从刑事诉讼中心扩展到非诉、社会力量及民事行政公益保护。[顺序页 8 / 印刷页 9]
  - 目标模式被定义为具有“专门、独立、福利色彩、综合性”的未成年人司法，而非单一“宜教不宜刑”。[顺序页 8 / 印刷页 9]
- **规范、类型、模式或理论如何建构**：
  1. 比较模式：美国多元型、德国刑事法原型、瑞典北欧福利原型、日本少年与家事法融合原型；多样模式共享福利/刑事动态平衡、最大利益与专门机构、国际准则本土转化。[顺序页 6—8 / 印刷页 7—9]
  2. 四原则：最有利于未成年人、综合保护、比例、专门保护。最有利原则包含国家责任、主体地位和责任不被免除；比例原则把行为严重性与个体危险、挽救可能、保护处分负担并置；专门保护落实到机构、人员和知识。[顺序页 8—10 / 印刷页 9—11]
  3. 五组制度：规则提炼；罪错未成年人保护处分体系；被害人权利与临时保护；民事行政综合司法；国家主导的多主体共治。[顺序页 11—13 / 印刷页 12—14]
- **竞争观点和最强反驳**：
  - 福利本位与刑事本位不是二选一，作者以动态平衡和比例原则协调教育、责任及最小刑事干预。[顺序页 7、9—10 / 印刷页 8、10—11]
  - 国家亲权与儿童主体地位：国家责任的目的应是增强儿童未来生活能力，不能替代儿童选择和决定。[顺序页 9 / 印刷页 10]
  - 附条件不起诉范围存在维持一年、放宽两年、统一不起诉等竞争方案；作者主张三年以下、扩至所有罪名。[顺序页 11 / 印刷页 12]
  - 本卡提出的最强反驳：专门、福利和保护处分可能扩大国家干预；“所有罪名＋三年”及最长五年的专门矫治教育如果缺少法定条件、定期审查、律师帮助和解除救济，会使福利语言遮蔽权利限制。[顺序页 11—12 / 印刷页 12—13]
- **机构、权限、程序、法律效果和救济**：
  - 机构：专门未成年人司法机构和专业人员、家庭/少年审判、未成年人检察、行政和社会支持主体。[顺序页 10、13 / 印刷页 11、14]
  - 权限：主张未成年人司法作为特别法优先适用，并让未检综合承担公诉、国家监护、权利保护和法律监督；但具体权限来源与冲突规则仍需细化。[顺序页 8、13 / 印刷页 9、14]
  - 程序：社会调查、司法转处、附条件不起诉、听取儿童意见、一站式询问、临时代理/监护、调解、支持起诉和执行监督。[顺序页 11—13 / 印刷页 12—14]
  - 效果：训诫、管教、督促矫治、专门教育、专门矫治教育的分级处遇；紧急带离、人身安全保护令、临时监护、精神损害赔偿；民事行政权益保护。[顺序页 11—13 / 印刷页 12—14]
  - 救济：文章提出支持起诉、临时诉讼代理、优先执行和执行监督，但对保护处分的申请、异议、定期审查、变更、解除和赔偿没有形成完整链条，是宏观方案的关键缺口。[顺序页 12—13 / 印刷页 13—14]
- **实施条件与边界**：必须有专门组织、专业知识、社会支持、部门联动和法律体系配套；比较法模式只能提炼功能，不能照搬机构。制度边界还应由最小干预、比例、正当程序和儿童意见控制。[顺序页 7—10、13 / 印刷页 8—11、14]
- **少年司法专门逻辑**：国家保护责任与儿童主体地位并存；少捕、慎诉、少监禁不等于免除责任；保护处分和刑事处遇均需比例控制；从行为人扩展到被害人及民事行政权利，但不得用“综合”消解不同法律关系。[顺序页 5、8—10 / 印刷页 6、9—11]
- **可迁移方法**：
  1. “历史形成—现状成就—体系缺口—比较模式—本土立场—基本原则—制度组件”的建构链。
  2. 比较法先提炼模式的功能和前提，再提出中国方案，而不是逐国制度拼贴。
  3. 每项原则必须落到机构、人员、规则、措施和法律效果。
  4. 宏观方案必须另做“权力扩张、自由限制、资源不足、严重案件、低风险案件”压力测试。
- **不可迁移的实体结论**：
  - 附条件不起诉扩大至三年以下并适用于所有罪名，是作者的立法论方案，不是现行法，也不是已验证的通用规则。[顺序页 11 / 印刷页 12]
  - 保护处分三分类、专门矫治教育具体年限及未检综合职能是特定方案，须经现行法、权利限制和救济验证。[顺序页 12—13 / 印刷页 13—14]
  - “完整未成年人法律制度必然包含三大法”的体系划分是分析模型，不得写成唯一正确分类。[顺序页 8 / 印刷页 9]

### 3.3 `F2EI6QQ8`：涉罪未成年人诉讼参与权的中国实践

#### A. 初稿卡

- **主路线**：教义学；辅助模块为实证诊断。文章不是从法条直接列举权利，而是把参与权操作化为五个可观察要素，用访谈、问卷和观察诊断实现状态，再提炼程序标准和主体义务。[顺序页 2—3、10—12 / 印刷页 123—124、131—133]

- **问题如何提出**：国内规范虽承认参与，但实践仍把儿童视作被保护客体；抽象权利、法律术语和繁琐程序造成形式参与，未成年人难以理解程序并影响决定。[顺序页 2 / 印刷页 123]
- **概念如何拆分和界定**：参与被定义为未成年人通过表达意见主动推进、影响相关诉讼活动或决定，拆成知情、理解、表达意见、考虑意见、给予反馈五项要素。五项不是一次性清单，而是在诉讼推进、能力变化和关系互动中持续实现的过程。[顺序页 1—2、8—11 / 印刷页 122—123、129—132]
- **规范、类型、模式或理论如何建构**：
  - 知情标准：全面、准确、及时，书面与口头结合。
  - 理解标准：通俗语言、反复解释、持续且针对性的教育，不能只凭儿童口头表示“懂了”。
  - 表达标准：儿童友好场所、少用戒具、尊重互动、及时专业法律援助、合适成年人支持。
  - 考虑标准：多主体信息共享和线上线下持续互动。
  - 反馈标准：说明决定依据、理由及如何考虑儿童意见。[顺序页 10—11 / 印刷页 131—132]
- **竞争观点和最强反驳**：
  - “已告知/已签字”与真实知情理解：简单口头或书面签字会使权利形式化。[顺序页 4 / 印刷页 125]
  - 儿童当下表达与其长远利益：有儿童因难忍监督考察而要求撤销附条件不起诉；作者认为应通过持续支持帮助形成理解，但也承认这是其选择和成长体验。[顺序页 5 / 印刷页 126]
  - 圆桌形式与真实互动：圆桌审判并不当然消除恐惧，法官态度、戒具、父母和律师支持同样决定表达。[顺序页 7—8 / 印刷页 128—129]
  - 父母在场与适当支持：父母往往能安抚儿童，但文章没有充分处理父母与儿童利益冲突、虐待或控制情形。
  - 本卡提出的最强反驳：持续解释和教育可能滑向要求儿童接受机构预设决定；“为其最大利益”不能取消儿童撤回、异议和独立帮助，支持必须以理解和能力为目标，而非服从。
- **机构、权限、程序、法律效果和救济**：
  - 机构：侦查人员、检察官、法官、法律援助律师、合适成年人、社工、监护人和观护人。[顺序页 3—12 / 印刷页 124—133]

  - 程序：附条件不起诉宣告、考察帮教、阶段性考评会、线上联络、侦查讯问、法庭审理及决定反馈贯穿五要素。[顺序页 4—11 / 印刷页 125—132]
  - 效果：儿童可以影响观护岗位和帮教方案，获得对判决和意见处理的说明；参与不应止于陈述机会。[顺序页 8—9 / 印刷页 129—130]
  - 救济：作者提出合适成年人未在讯问笔录签名时原则上排除口供、检察机关纠正违法和重新讯问；该法律效果属于作者改革主张，现行法依据与例外边界须独立复核。[顺序页 11—12 / 印刷页 132—133]
- **实施条件与边界**：
  - 需持续联络、稳定信任关系、专业社工和律师、儿童友好场所、时间资源及多主体信息共享。[顺序页 5—6、10—12 / 印刷页 126—127、131—133]
  - 调查为探索性研究：覆盖 7 省市 12 地区，访谈 221 人次，回收有效问卷 176 份，并观察有限庭审和考评活动；作者明确承认样本集中性、均衡性、代表性和程序覆盖不足。[顺序页 2—3 / 印刷页 123—124]
  - 样本中重罪未成年人较多，庭审戒具比例不能外推全国全部未成年人案件。[顺序页 7 / 印刷页 128，注 17]
- **少年司法专门逻辑**：发展中能力意味着知情不等于理解、表达不等于被考虑、签字不等于真实参与；机构负有反复说明、合理调整、支持表达和反馈理由的积极义务。关系自主要求借助可信赖的律师、社工和适当成年人提升能力，而不是由成年人替代决定。[顺序页 4—11 / 印刷页 125—132]
- **可迁移方法**：
  1. 把抽象程序权利拆成“信息—理解—表达—考虑—反馈”的闭环指标。
  2. 对每个要素同时检查制度文本、实际环境、主体行为、儿童体验和法律后果。
  3. 将能力视为动态状态，按阶段重复确认，而不是用一次签字冻结。
  4. 从实证差异中提炼最低标准，但明确样本和适用边界。
- **不可迁移的实体结论**：
  - 合适成年人单独交流“15 分钟以内”、圆桌审判具体排除案件、未签名口供排除等均为具体方案，不是通用工作流规则。[顺序页 12 / 印刷页 133]
  - 2017—2020 年局部地区的律师介入时间、戒具比例和儿童感受不能作为当前全国事实。[顺序页 3、7—8 / 印刷页 124、128—129]

#### B. 综述卡

- **范围边界**：2017 年 6 月至 2020 年 6 月，对 7 省市 12 地区中侦查讯问、附条件不起诉和法庭审理三个环节的探索性考察；对象包括办案人员、律师、社工、儿童和监护人。[顺序页 2—3 / 印刷页 123—124]
- **分类轴**：
  - 权利要素：知情、理解、表达、考虑、反馈。
  - 程序阶段：侦查、审查起诉/监督考察、审判。
  - 主体：儿童、办案人员、律师、合适成年人、社工、监护人。
  - 条件：硬环境（法庭、戒具）与软环境（态度、关系、支持）。
  - 证据方法：访谈、问卷、实地观察。
- **谱系 / 演进**：从《儿童权利公约》第 12 条和欧洲 11 国少年法庭研究提炼共通要素，再按中国司法环境修正为五要素框架，最后由本土实践形成实现标准。[顺序页 2 / 印刷页 123]
- **代表观点及证据**：
  - 简单告知无法形成知情；反复、持续解释才可能形成理解。[顺序页 4—6 / 印刷页 125—127]
  - 律师迟延介入、合适成年人角色形式化、成人法庭和戒具限制表达。[顺序页 6—8 / 印刷页 127—129]
  - 考评会、社工陪伴和决定说理让意见进入实际决策。[顺序页 8—9 / 印刷页 129—130]
- **真实争议**：形式参与与有效参与；保护性教育与自主选择；儿童主观表达与其背后需要；父母/专业支持与儿童独立意见；程序友好形式与权力关系实质。
- **证据分层**：
  - 规范证据：儿童权利公约、北京规则和国内保护规范。
  - 实证证据：221 人次访谈、176 份有效儿童问卷、庭审和帮教观察。
  - 比较证据：欧洲少年法庭研究用于生成初始维度。
  - 跨学科证据：发展心理、社会工作关系和社会融入机制，但文章未独立验证机制效应。
- **研究缺口**：样本非全国代表、程序阶段不全、长期效果不明；性别样本高度不均；残障、语言、认知差异、父母利益冲突、撤回与申诉机制、不同支持方式的效果比较均不足。[顺序页 3 / 印刷页 124]
- **可迁移结构**：“权利规范—操作要素—研究设计—分要素实践—实现标准—主体义务—改革事项”。
- **过度概括风险**：不得把探索性样本写成全国参与权水平，不得把相关性写成因果，不得将“持续教育”概括为儿童必须接受机构方案。

#### C. 低置信度、新标签与待复核字段

- **低置信度**：合适成年人未签名口供的排除规则及检察纠正方式，强制进入规范位阶和现行法复核。[顺序页 11—12 / 印刷页 132—133]
- **新标签候选**：`参与权五要素闭环`。可作为教义学和综述共享的方法标签，但必须写成过程检查，不得简化成五项静态清单。
- **待复核**：儿童要求撤销附条件不起诉的案例应如何兼顾真实意愿、发展中能力、可撤回参与和最有利原则；建议对抗代理重读顺序页 5 / 印刷页 126，避免把作者评价直接升级为“不准撤回”规则。

### 3.4 `SVNSFFZ3`：涉罪未成年人羁押率的实证考察与程序性控制路径

#### A. 初稿卡

- **主路线**：教义学；辅助模块为实证诊断，并使用少量比较法。文章从国际与国内“非羁押为原则”建立规范基线，再用问卷、访谈和案例数字识别适用因素和高羁押原因，最后建立程序控制链。[顺序页 1—4、8—14 / 印刷页 129—132、136—142]
- **素材层 / 训练角色**：领域核心、对抗；主要补强“实证发现如何进入规范诊断及制度设计”，并暴露风险量化、审查主体和权利救济的内部张力。
- **问题如何提出**：国际规则和国内法倡导非犯罪化、非羁押化，但实践出现普遍羁押、超期羁押和一押到底，外地户籍儿童尤其不利；作者追问年龄、危险性、替代条件、观护和办案理念如何共同造成落差。[顺序页 1—5 / 印刷页 129—133]
- **概念如何拆分和界定**：
  - 羁押问题被拆成规范正当性、适用率、适用考量、成因和控制机制。
  - 逮捕与羁押被区分为不同决定：逮捕不应自动导致持续羁押。
  - 替代体系包括取保候审、监视居住和社会观护；风险评估用于判断是否适用及采用何种保障方式。[顺序页 3、10—13 / 印刷页 131、138—141]
- **规范、类型、模式或理论如何建构**：
  - 国际准则被概括为非羁押权、无罪推定、羁押最后手段、替代措施、司法听证、优先办理、保护目的、捕押分离、特殊处遇和程序法定十项。[顺序页 3 / 印刷页 131]
  - 高羁押原因模型含以捕代侦、风险评估缺失、取保/监居不健全、社会观护不完善及侦查中心主义等因素。[顺序页 6—8 / 印刷页 134—136]
  - 控制链包括羁押必要性审查、替代支持、风险评估、理念更新、捕押分离、信息平台和救济。[顺序页 8—14 / 印刷页 136—142]
- **竞争观点和最强反驳**：
  - 混同捕押造成审查与救济虚无，或侦查/逮捕中心主义导致高羁押，是既有两类解释；作者以问卷提出多因素共同作用。[顺序页 5—8 / 印刷页 133—136]
  - 全面审查保障平等，但案件量巨大；作者提出分层滤网和重点审查协调资源。[顺序页 9 / 印刷页 137]
  - 量化评估提高一致性，但也可能把户籍、家庭资源、社会支持缺失再次编码为儿童“风险”，加剧原本要纠正的不平等。
  - 作者一方面主张逮捕和羁押决定司法化、走向审判中心，另一方面又主张审查启动和标准坚持“检察中心主义”，并由刑事执行检察部门办理，存在未解决的制度立场张力。[顺序页 9、13—14 / 印刷页 137、141—142]
  - 本卡提出的最强反驳：对“高风险”儿童自动拒绝替代措施不符合个别化、比例和最小干预；风险应触发更强支持和更严格审查，不能直接等同羁押必要性。[顺序页 12 / 印刷页 140]
- **机构、权限、程序、法律效果和救济**：
  - 机构：刑事执行检察部门为作者指定的审查主体，侦监、公诉、侦查、案管、检察技术配合；公安执行；律师、法定代理人、被害人和一定社会参与者进入听证；社会观护组织提供支持。[顺序页 9—11 / 印刷页 137—139]
  - 权限：依职权或申请启动羁押必要性审查，调查、听取意见、书面和言辞审查；捕押分离后分别作决定。[顺序页 9、13 / 印刷页 137、141]
  - 程序：全面与重点审查、公开为原则、秘密为例外、听证、动态风险评估、信息查询和定期复查。[顺序页 9、12—13 / 印刷页 137、140—141]
  - 效果：变更强制措施、释放、适用不同替代措施；观护和支持用于确保到案及复归。
  - 救济：建议赋予对审查结果申诉、复议复核，知悉羁押理由、律师帮助、申请捕后审查、解除超期羁押和非法羁押赔偿等权利。[顺序页 9、13 / 印刷页 137、141]
- **实施条件与边界**：
  - 需完善替代措施、观护资源、专业评估、公开审查、司法救济和考核机制，不能只细化审批表。[顺序页 8—14 / 印刷页 136—142]
  - 数据基础为 1,850 份发放问卷、1,348 份回收、1,286 份有效问卷，主体含公检法司人员、律师和社会公众；它主要测量认知和态度，不是全国案件层面的因果数据。[顺序页 1—2 / 印刷页 129—130]
  - 各地区羁押/不捕数字来自不同年份和口径，适合提示问题，不能直接横向比较或推出全国羁押率。[顺序页 4 / 印刷页 132]
- **少年司法专门逻辑**：儿童年龄、发展、家庭和社会支持条件必须进入个别化审查；非羁押是优先方向，外地户籍和贫困不能因缺保证资源转化为羁押理由；每次限制自由均需比例、听取意见、律师帮助、定期复查和救济。[顺序页 3—7、9—13 / 印刷页 131—135、137—141]
- **可迁移方法**：
  1. 先建立规范基线，再用案件/调查材料定位“纸面规则—实际运行”的断裂。
  2. 将高羁押原因拆成决策理念、法律标准、替代资源、风险工具、组织结构和考核激励，而非单因解释。
  3. 改革方案同时包含决定程序、物质支持、监督救济和组织激励。
  4. 对风险工具额外做平等影响、可解释性、人工复审、支持替代和隐私审计。
- **不可迁移的实体结论**：
  - 文中历年羁押率、不捕率和职业态度比例不能作为当前事实常量。
  - 由检察执行部门统一审查、坚持检察中心主义、公安维护全国信息平台是作者方案，不是通用制度答案。[顺序页 9、13 / 印刷页 137、141]
  - “高风险即拒绝替代措施”的处理不得迁入专项工作流。[顺序页 12 / 印刷页 140]

- **范围边界**：中国涉罪未成年人审前羁押的规范和运行，兼及域外保释/羁押制度；实证材料主要形成于 2018 年前后的问卷、访谈和既有统计。[顺序页 1—15 / 印刷页 129—143]

- **过度概括风险**：不得把受访者认知写成真实原因占比，不得把异年异地数字直接比较，不得把量化称为天然客观。

### 3.5 `QIDFLN9E`：国家亲权理论与少年司法

#### A. 初稿卡

- **主路线**：理论—制度建构；辅助模块为比较法/制度史。文章以美国为中心，从国家亲权概念史进入福利型少年司法，再以实践落差解释正当程序改革和中国迁移边界。[顺序页 1—4 / 印刷页 92—95]
- **素材层 / 训练角色**：领域核心、历史、边界；主要贡献不是输出国家亲权的实体结论，而是训练“理论先说明贡献，再由反例和制度史揭示其控制风险”的方法。
- **问题如何提出**：国家亲权强调国家积极保护、超越报应和儿童最大利益，但在少年司法中容易产生理念与实践落差；问题因此不是简单接受或拒绝理论，而是识别其制度贡献、风险和修正路径。[顺序页 1 / 印刷页 92]
- **概念如何拆分和界定**：
  - 历史三阶段：父母绝对亲权、国家亲权辅助父母、国家亲权超越父母。
  - 理论三内涵：国家是最终监护人；父母失职时国家可干预；国家须为儿童福利行事。[顺序页 1 / 印刷页 92]
  - 制度贡献三项：福利取向、排斥报应的矫正模式、以社会调查和专业方法实现个别化。[顺序页 2—3 / 印刷页 93—94]
  - 质疑三项：干预圈过大、保护名义与惩罚实践断裂、缺乏正当程序。[顺序页 3 / 印刷页 94]
- **规范、类型、模式或理论如何建构**：文章形成“概念源流—英美制度结合—制度贡献—三类质疑—美国改革—中国暗合与落差”的理论评估链。美国改革被概括为增加正当程序并调整国家亲权适用范围，而非完全放弃少年司法二元体系。[顺序页 2—4 / 印刷页 93—95]
- **竞争观点和最强反驳**：
  - 福利保护与社会控制：国家干预可能披保护外衣扩大控制和标签化。[顺序页 3 / 印刷页 94]
  - 个别化与正当程序：为寻求“最佳处遇”而弱化程序，可能侵害儿童宪法权利。[顺序页 3 / 印刷页 94]
  - 保护处分与刑罚：名义差异不代表实际负担不同。
  - “慈母型”福利司法与“严父型”教育惩罚：中国和英美制度互相吸收，但这种性别化/家长化比喻不能替代儿童权利分析。[顺序页 4 / 印刷页 95]
  - 本卡提出的最强反驳：国家责任必须转译为可审查的支持义务，不能转译为国家替代儿童和家庭的一般权力；严重案件也不能被排除出少年司法的基本程序保护。
- **机构、权限、程序、法律效果和救济**：
  - 机构：英国大法官法庭、美国少年庇护所和少年法院被用于展示国家亲权的制度化。[顺序页 2 / 印刷页 93]
  - 权限：父母不能或不当履责时国家干预，但文章重点是理论正当化，不是中国权限清单。
  - 程序：社会调查、观护、心理鉴别和弹性程序实现个别化；后期改革以正当程序保障纠正滥权。[顺序页 2—3 / 印刷页 93—94]
  - 效果：福利处遇、矫正、个别化；反面效果是扩大干预、标签化和保护处分刑罚化。[顺序页 2—3 / 印刷页 93—94]
  - 救济：仅原则性提出正当程序，未设计听证、律师、复审、变更和赔偿，不能作为完整制度方案。
- **实施条件与边界**：
  - 理论必须以实际处遇负担、程序权利和标签效果检验，不能凭“为了儿童”自证正当。
  - 中国“三像方针”和教育感化挽救政策虽与国家亲权有相似性，但缺乏系统刑罚替代措施和制度保障，不能以文化类同比附制度移植。[顺序页 4 / 印刷页 95]
  - 文章的历史视野截止 2008 年，后续儿童权利、发展中能力和支持性参与理论必须另补。
- **少年司法专门逻辑**：国家负积极保护责任，但保护须受儿童最大利益、最小干预、程序正当和个别化控制；“儿童是权利主体”应取代国家家长的替代性决定，关系自主和机构支持义务是迁移时必须补入的现代保护条件。
- **可迁移方法**：
  1. 对基础理论分别写清来源、核心命题、制度贡献、最强批评、历史修正和本土迁移。
  2. 用“理念承诺—真实处遇—程序权利—标签效果”四层检验理论。
  3. 将理论迁移限定为方法和问题意识，不直接移植特定国家的机构或结论。
- **不可迁移的实体结论**：
  - “轻轻重重”并将少数恶性少年排除在少年司法保护范围外，是作者对美国改革的概括/评价，不能迁为少年司法规则；严重儿童仍享有专门程序和儿童权利保护。[顺序页 3 / 印刷页 94]
  - 国家高于父母、严父/慈母、“三像”类比均不能直接生成权限。
  - 2005 年美国判例和早期制度史只作历史材料，使用时需核验更新和法域差异。

#### B. 综述卡

- **范围边界**：国家亲权理论的英美起源、美国少年司法结合与改革，以及中国少年司法政策类比；不是系统检索，主要依赖历史案例和二手比较文献。[顺序页 1—4 / 印刷页 92—95]
- **分类轴**：
  - 亲权关系阶段；
  - 理论内涵；
  - 制度贡献与制度批评；
  - 美国制度史与中国政策类比；
  - 理念与实践落差。
- **谱系 / 演进**：从英国国王/大法官对无能力者的监护，经美国殖民地干预、19 世纪庇护所、1899 年少年法院，发展到高尔特案后正当程序化和严罚趋势，再与中国恤幼、“三像”和教育为主政策对话。[顺序页 1—4 / 印刷页 92—95]
- **代表观点及证据**：福利本位、反报应和个别化构成支持谱系；社会控制、处分刑罚化和程序权利缺失构成批评谱系；美国改革史被用于说明理论可修正而非只能接受/抛弃。[顺序页 2—3 / 印刷页 93—94]
- **真实争议**：国家保护还是社会控制；福利处分是否实质轻于刑罚；个别化是否牺牲平等和程序；严重案件是调整处遇还是退出少年司法；中国政策类同能否支持制度移植。
- **证据分层**：
  - 理论/历史：概念史、案例和制度史。
  - 比较：英美与中国政策类比。
  - 规范：儿童最大利益和正当程序仅作原则性支点。
  - 实证：没有独立经验数据，不能证明某种模式的实际效果。
- **研究缺口**：儿童权利和关系自主理论、国家干预法定条件、机构问责、实际处遇负担、救济、严重案件的普遍权利、2008 年后制度演进。
- **可迁移结构**：“理论谱系＋制度贡献＋内在反例＋历史修正＋本土边界”的理论综述结构。
- **过度概括风险**：不得把美国少年司法写成单一福利—严罚直线，不得把中国恤幼传统等同现代儿童权利，不得把作者的历史概括当作最新现状。

#### C. 低置信度、新标签与待复核字段

- **低置信度**：美国改革“主要是缩小理念—实践落差而非背弃国家亲权”的总判断，属于作者的跨时期综合，须在后续综述中标为作者判断而非既定事实。[顺序页 3 / 印刷页 94]
- **待复核**：“将极少数恶性少年排除在少年司法保护范围”与最有利原则、平等和专门程序的冲突，建议对抗代理定向重读顺序页 3 / 印刷页 94，并降级为历史争议。
- **标签处理**：`理念—实践落差检验`并入理论—制度建构既有压力测试，不另造路线。

### 3.6 `WMMXTGHA`：涉罪未成年人审前非羁押支持体系实证研究

#### A. 初稿卡

- **主路线**：教义学（制度构造）；辅助模块为实证诊断。文章用三地 18 个月调查拆解观护基地的进入、评估、保证、监管、证明和退出流程，再从效果与问题提出制度化方案。[顺序页 1—14 / 印刷页 98—111]
- **素材层 / 训练角色**：领域核心、对抗；核心贡献是把“非羁押”从消极不逮捕改造成国家和社会提供资源的积极支持体系，同时检验支持是否异化为准羁押、劳动控制或提前矫正。
- **问题如何提出**：外来儿童即使符合取保或监居条件，也可能因无适格保证人、保证金和本地住所而被羁押；形式中立的资格条件把贫困和流动状态转化为自由受限，需要观护基地提供食宿、保证、教育和服务。[顺序页 1—2 / 印刷页 98—99]
- **概念如何拆分和界定**：
  - 观护基地首先被定位为审前非羁押支持，而非刑罚执行机构。
  - 类型轴包括开放/半开放、集中/个别、分类/不分类。
  - 运行链包括适用条件、动态风险评估、保证人/保证金、监督教育、情况证明和缩短办案期限。[顺序页 3—7 / 印刷页 100—104]
  - 法律身份必须区分：被取保/监居者尚非犯罪人，不能以矫正改造方式对待；被不起诉帮教与社区矫正是不同职能。[顺序页 12 / 印刷页 109]
- **规范、类型、模式或理论如何建构**：
  - S 市把取保条件与观护条件分开，W/C 市合并；对比暴露“支持是取保后的服务还是取得取保的门槛”的制度选择。[顺序页 4 / 印刷页 101]
  - 风险评估含侦查、批捕、起诉和观护中的动态跟踪，并区分社会调查与法律评估。[顺序页 4—5 / 印刷页 101—102]
  - 效果评价分审前羁押、定罪量刑、复归社会和办案理念四类。[顺序页 7—12 / 印刷页 104—109]
  - 制度修补分职能定位、机关关系、权利义务、风险评估、监管、技能培训和考核七项。[顺序页 12—14 / 印刷页 109—111]
- **竞争观点和最强反驳**：
  - 平等保护与风险控制：观护解决外地儿童资源缺失，但半开放基地、集中监管可能形成准羁押和交叉影响。[顺序页 3、14 / 印刷页 100、111]
  - 支持与惩罚：思想汇报、劳动、法制教育和情况证明可以提供支持，也可能在未定罪阶段转化为强制改造或实体处罚；作者后文明确主张不得对未决儿童矫正改造、不得强迫劳动。[顺序页 6—7、12、14 / 印刷页 103—104、109、111]
  - 观护表现与量刑：良好表现可能带来不起诉或轻缓刑，但也可能使不接受观护、无法完成劳动的儿童承受程序性惩罚。
  - 风险评估与支持：家庭条件、学校和保证资源既是支持需求，也是评估变量；若不分开，资源匮乏会再次被当作风险。
  - 本卡提出的最强反驳：观护基地不能同时充当保证人、监管者、服务提供者和影响实体处理的评价者而缺少儿童申诉、独立监督及退出机制。
- **机构、权限、程序、法律效果和救济**：
  - 机构：公安、检察院、法院、司法行政、地方领导小组、观护基地、保证人、社工、学校、心理机构和群团组织。[顺序页 2—7、12—14 / 印刷页 99—104、109—111]
  - 权限：公安执行取保/监居，检察监督并推动基地，领导小组批准接收，基地负责日常支持、监督和报告；各方权限来源及委托边界仍不够清楚。[顺序页 4—5、12—13 / 印刷页 101—102、109—110]
  - 程序：告知、申请、自愿/监护人同意、风险评估、审批、入驻、动态跟踪、教育/服务、情况证明和后续处理。[顺序页 4—7 / 印刷页 101—104]
  - 效果：取保率上升、部分案件不起诉或非监禁化、复学就业和办案理念变化；证据主要是试点前后数字、相似案例、问卷和回访，存在选择偏差和缺少对照。[顺序页 8—12 / 印刷页 105—109]
  - 救济：文章没有形成儿童对入驻条件、限制、劳动安排、评估、情况证明、退出或变更的申诉与独立审查机制；这是制度构造必须补足的关键字段。
- **实施条件与边界**：
  - 需要政府资源补助、基地权利义务平衡、责任边界、专业评估、差别化监管、隐私保护、儿童适配的教育/技能项目和考核改革。[顺序页 12—14 / 印刷页 109—111]
  - 对低风险儿童优先开放、分类、个别监督；较强限制必须基于具体风险、定期复审且仍轻于羁押。[顺序页 14 / 印刷页 111]
  - 技能培训须以儿童情况和意愿为前提，在校者优先复学，不得强迫劳动，心理支持不得变相成为未决人员改造。[顺序页 14 / 印刷页 111]
  - 调查为 S 市、J 省 W 市和 C 市的 2010—2011 年试点研究：300 份问卷中 253 份有效、16 次集中访谈、51 人次个访及文献/档案分析；儿童问卷 43 份、个访 18 人次，效果外推有限。[顺序页 2—3 / 印刷页 99—100]
- **少年司法专门逻辑**：非羁押不仅是“不给羁押”，还要求机构主动核验资源并提供住所、保证、教育、心理和社会支持；支持须尊重发展中能力、儿童意愿、比例、最小干预和未定罪地位。一次申请或监护人同意不能替代持续知情、可撤回且受支持的参与。
- **可迁移方法**：
  1. 对试点制度制作“对象—入口—评估—决定—服务—监管—证明—退出—救济”全流程图。
  2. 将措施效果分为直接程序效果、实体关联效果、社会复归效果和组织行为效果，并分别评价证据强度。
  3. 区分服务对象的法律身份，防止同一机构把未决支持、附条件帮教和刑罚矫正混为一体。
  4. 检查考核指标和资源条件是否制造机构逆向激励。
  5. 把儿童缺少的资源定义为机构支持义务，不自动定义为个体风险。
- **不可迁移的实体结论**：
  - 具体地区取保率、轻刑比例、复学就业率和再犯数字不能作为当前全国效果结论。
  - 观护基地出具表现证明影响不起诉或量刑、对基地罚款和追责等方案须经法定权限、无罪推定和程序救济核验。[顺序页 7—9、13 / 印刷页 104—106、110]
  - 思想汇报频率、限制离开基地、具体办案期限等地方做法不进入运行时工作流。[顺序页 6—7 / 印刷页 103—104]

#### B. 综述卡

- **范围边界**：2010 年 5 月至 2011 年 10 月三地观护基地试点；关注审前非羁押支持的运行、效果和制度问题，不是全国代表性或长期因果评估。[顺序页 2—3 / 印刷页 99—100]
- **分类轴**：
  - 基地类型：开放/半开放、集中/个别、分类/非分类。
  - 流程：条件、评估、保证、监管教育、证明、期限。
  - 效果：羁押、定罪量刑、复归、办案理念。
  - 治理：职能、机关关系、权利义务、评估、监管、培训、考核。
  - 法律身份：未决、被不起诉、社区矫正。
- **谱系 / 演进**：地方检察机关从为外来儿童提供保证条件开始，逐步扩至本地无资源儿童、动态评估和多部门领导机制；文章再由试点经验提出制度化和职能分化。[顺序页 1—5、12—14 / 印刷页 98—102、109—111]
- **代表观点及证据**：
  - 观护基地扩大保证来源并降低资源性羁押。[顺序页 8—9 / 印刷页 105—106]
  - 支持可能关联不起诉、轻缓量刑和复归，但证据主要是描述统计、相似个案和小样本回访。[顺序页 8—12 / 印刷页 105—109]
  - 权责不平衡、评估单一、监管方式、技能匹配和考核冲突构成实施瓶颈。[顺序页 12—14 / 印刷页 109—111]
- **真实争议**：基地是服务还是强制措施执行空间；开放还是半开放；集中效率还是个别隐私；表现证明是支持证据还是提前实体评价；自愿劳动教育还是未决改造；风险管理还是资源歧视。
- **证据分层**：
  - 规范：刑诉法的限制逮捕、取保和监居规则。
  - 实证：三地问卷、访谈、档案、统计和回访。
  - 比较：文章没有系统域外比较。
  - 跨学科：心理、教育、劳动技能和社会融入机制，多为实践观察，非因果验证。
- **研究缺口**：随机/匹配对照、长期再犯和生活质量、儿童和家庭持续意见、退出与救济、基地劳动和数据隐私、第三方责任、不同基地模式的净效果。
- **可迁移结构**：“试点背景—研究设计—运行机制—多维效果—权利与治理问题—制度化建议”。
- **过度概括风险**：不得把进入基地者的好结果归因于基地本身；进入者原本即经低风险筛选，且办案人员和基地存在选择效应。不得把表现良好与认罪、再犯风险或未来适应能力直接等同。

#### C. 低置信度、新标签与待复核字段

- **低置信度 / 强制复核**：观护对不起诉、轻缓量刑、复归和理念变化的因果效果；独立复核时须把“观察到关联”与“可归因效果”逐项分开。[顺序页 8—12 / 印刷页 105—109]
- **新标签候选 / 强制复核**：`支持体系的准羁押审计`，包括自由限制、劳动、思想汇报、表现证明、退出、投诉和独立监督；应与 `SVNSFFZ3` 的风险评估规则交叉复核。
- **待复核**：观护基地及保证人的罚款/责任、情况证明进入实体决定、半开放限制的法律依据与救济。[顺序页 7、13—14 / 印刷页 104、110—111]

## 4. 本批方法动作增量与重复判断

### 4.1 新增或得到实质强化的方法动作

1. **原则操作化三段桥**：抽象原则不能直接跳到政策主张；先拆内涵，再确定其在个案权衡、法律解释和制度建构中的不同功能，最后配程序保障和相反决定说理。主要依据 `TXY75SMN`。[顺序页 4—7 / 印刷页 6—9]
2. **参与权五要素闭环**：把一次告知/签字拆成知情、理解、表达、考虑和反馈，并按发展中能力持续确认。主要依据 `F2EI6QQ8`。[顺序页 4—11 / 印刷页 125—132]
3. **宏观制度建构的“模式—原则—组件”桥**：制度史和比较法先形成竞争模式，原则再被迫落到机构、人员、规则、措施与效果，避免停在宏大价值宣示。主要依据 `28ZHYN6P`。[顺序页 6—13 / 印刷页 7—14]
4. **自由限制的“双层控制”**：决定程序与物质支持必须同时设计；只有审查程序、没有住所/保证/服务，会让资源不足继续产生羁押。主要依据 `SVNSFFZ3` 与 `WMMXTGHA`。[`SVNSFFZ3` 顺序页 8—13 / 印刷页 136—141；`WMMXTGHA` 顺序页 1—8 / 印刷页 98—105]
5. **理论理念—真实处遇落差检验**：基础理论要分别接受干预范围、实际负担、标签效果和正当程序检验。主要依据 `QIDFLN9E`。[顺序页 2—3 / 印刷页 93—94]
6. **试点证据四层效果表**：程序效果、实体关联、社会复归和组织行为效果分别记录证据，禁止把相关结果统一写成制度有效。主要依据 `WMMXTGHA`。[顺序页 8—12 / 印刷页 105—109]
7. **风险—支持变量分离**：家庭、户籍、住所、保证和社会服务不足首先表示机构应补支持，不能未经审查直接编码为儿童危险。该动作由 `SVNSFFZ3` 与 `WMMXTGHA` 的张力共同推出，当前为候选规则，须独立复核。

### 4.2 重复动作，不应生成同义规则

- `TXY75SMN` 与 `28ZHYN6P` 都从最有利原则、综合保护、比例和专门化导向制度安排；运行时只保留一条“原则须制度化并受法定/程序/救济控制”的合并规则。
- `F2EI6QQ8`、`SVNSFFZ3`、`WMMXTGHA` 都使用“规范要求—实践落差—机制原因—改革路径”；区别只在参与、羁押和支持场景，不应按论文各造一条流水线。
- `SVNSFFZ3` 与 `WMMXTGHA` 都提出风险评估、观护支持和替代羁押；前者偏程序控制和救济，后者偏机构运行和资源支持，应合成一条双层制度规则。
- 六篇均出现专业机构/人员、跨部门协作、社会支持和个别化；这是重复的实施条件，应作为共通检查表，不按出现次数增加权重。
- `QIDFLN9E` 与 `28ZHYN6P` 都使用制度史和比较模式；前者贡献理论自我批判，后者贡献制度组件化，不能把两篇的实体模式叠加成“唯一中国方案”。

## 5. 本批核心对抗

1. **最有利原则 vs 法定权限与可救济性**：`TXY75SMN`赋予原则统领、解释和制度推动功能，`QIDFLN9E`则显示“为了儿童”的理论可能扩大干预并削弱程序。候选规则必须要求说明权限来源、限制强度、儿童意见、相反决定理由和独立救济。
