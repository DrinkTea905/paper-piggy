# 少年司法专项工作流训练记录：陈瑞华作者纵向卡

> 记录性质：陈瑞华 13 篇合格论文的独立作者纵向总卡。  
> 训练用途：分别为 `论文初稿（少年司法版）` 与 `综述（少年司法版）` 提炼可迁移的方法动作、历史关系、内部张力和迁移边界。  
> 证据纪律：本文已完整吸收 E/F/G 三批逐篇卡、独立复核 07/08 和陈瑞华—栗峥交叉对抗记录，并对各批“供合并重读页”逐篇回读原文。作者声望、论文时间先后、自引和代理多数票均不构成裁决理由。  
> 迁移纪律：13 篇论文只提供方法训练。成年刑事诉讼、证据法和认罪协商的实体结论，未经 24 篇少年司法共享核心与八项保护闸门重新校验，不得转化为少年司法运行时规则。

## 一、总裁决

1. **13 篇全部有实际训练角色，没有一篇仅因作者声望进入。** 其中 10 篇主要承担方法补强、历史演变、对抗或边界任务；`PU8KYVZV`、`TUL4PJQR` 可在严格限缩后承担核心规则依据，`YBR6HBLG` 仅有“模式组件化”部分可作核心依据。
2. **本组最稳定的贡献不是某项成年刑诉制度答案，而是一套问题化与制度构造方法**：从名义概念转向真实结构，从理论前提反推规则命运，把机构、权限、程序、法律效果、救济和实施条件串成闭环，再以最强反例和运行效果回测。
3. **未发现足以认定为根本“观点转向”的纵向证据。** 可确认的关系主要是继承、体系化、适用域扩展和局部限缩。尤其是 2001→2006、2019→2021 均不得写成“思想转向”。
4. **唯一可以直接页证支持的较强“局部修正”**，是作者对程序性违法量刑补偿的态度逐步收紧：早期把量刑减让列为值得研究、须设边界的可能机制，2025 年则主张其退出正式制度，仅在认罪协商且不排挤正式制裁和救济的狭窄场景保留剩余空间。这是适用范围的限缩，不是从赞成到反对的整体翻转。[`B9TRMQUA`，印刷页10—11、16—17；`TUL4PJQR`，印刷页113—125]
5. **作者组的核心未解张力必须进入工作流，而不能被“统一理论”抹平**：现实中的权力不对等与理性选择假设、反家长主义与沉默弃权、律师支持与律师否决、法院促成协商与法院中立审查、协议稳定与反悔/上诉、量刑利益与正式救济之间都存在真实张力。
6. **少年司法迁移后的最低结论**只能是：形式签字、家长同意、律师在场或获得有利结果，均不当然证明未成年人有能力、公平地、真实地参与；同意必须被重构为持续、知情、可撤回且受到支持的过程。

## 三、稳定的问题意识

### 1. 不让制度名称代替真实结构

作者反复从“名义上是什么”转向“实际如何运行”。羁押不能只看拘留、逮捕等启动决定，而要看到持续剥夺自由的状态；“审判中心”不能只看改革口号，而要检查卷宗、财物处置、羁押和程序倒流是否仍由侦查结论支配；“认罪认罚”或“听取意见”不能仅因具结书和签字存在就被称为协商。[`CMF3HLNP`，印刷页73—83；`TZGYBRVL`，印刷页3—19；`PU8KYVZV`，印刷页5—17]

**可迁移动作：** 对任何少年司法制度先列“法律名称—形式要件—实际控制者—真实负担—退出后果”五栏，禁止用“教育、保护、矫治、协商”等善意名称免除实质审查。

### 2. 理论前提会决定规则能否成立

单一认识论如果把诉讼只理解为发现客观事实，就难以解释为何需要沉默权、证人特权、非法证据排除、证明责任和程序保障；证据法只有把合法、公正地形成事实作为对象，才能形成证据资格、证明规则、适用程序和救济体系。[`C4D3DFJT`，印刷页24—28；`KCEMBPA4`，印刷页87—93]

**可迁移动作：** 使用“理论前提—规则命运压力测试”，追问采用某一前提后，哪些权利、程序和法律效果会被支持、架空或消失。这里是规范后果压力测试，不是经验意义上的“反事实检验”。

### 3. 公共权力必须被拆成机构、权限和角色

侦查、追诉、监督、审查、裁判、支持和执行不是可以任意叠加的抽象“国家职能”。同一机关兼具相互冲突的角色，会产生自我审查、既定结论维护和责任规避风险。检察机关虽可在特定体制下代行司法审查，但作者也明确承认其追诉立场使其无法成为真正中立的预审法官，只能作为“两害相权取其轻”的现实选择。[`TZGYBRVL`，印刷页11—19；`CKER5L8Q`，印刷页8、13—16]

**可迁移动作：** 画出“机构—权限—角色—利害关系—复核者”图；但结构性角色冲突只能证明风险，不能自动证明每一个案已经发生信息污染或不公。

### 4. 个人应是决定形成的参与者，而非善意治理的客体

对物之诉论文以反家长主义为起点，要求利害关系人通过举证、质证、辩论和上诉影响决定；协商论文则把本人参与、知情、律师帮助、选择和程序反悔视为主体性的条件。[`LD68HVXY`，印刷页211—223；`HIDEIB2X`，印刷页9—15；`PU8KYVZV`，印刷页13—19]

**可迁移动作：** 制度设计不能只问“机关是否替他考虑”，还要问本人是否得到可理解信息、表达偏好、提出异议、改变决定和获得复核的真实机会。

### 5. 文本改革可能被结构、激励、信息和资源吸收

法院、检察机关或侦查机关对案件结局的利害关系，卷宗单向流动，责任追究与绩效考核，人员和专业资源不足，都可能把新制度重新拉回旧轨道。作者并不把法律条文出台等同于改革完成。[`CMF3HLNP`，印刷页80—83；`TZGYBRVL`，印刷页11—19；`PF6DLVQ3`，印刷页14—18；`E9ZYIT5Z`，印刷页150、157—163]

**可迁移动作：** 每项规范方案同时写“结构—激励—信息—资源—执行节点—失败反馈”，并设置改革吸收测试。

### 6. 法律效果与救济必须和规则目的相连

作者持续强调，权利和程序规则若无不利后果与救济就会落空。但这不意味着所有违法都统一适用排除、无效或量刑减让。证据资格、证明责任、程序无效、人员责任、赔偿和上诉各有不同对象；量刑利益若替代无效、排除、追责和赔偿，反而可能使违法获益。[`C4D3DFJT`，印刷页24—28；`KCEMBPA4`，印刷页87—93；`TUL4PJQR`，印刷页113—125]

**可迁移动作：** 先确定规则来源和保护目的，再分别配置违法认定、程序效果、实体责任和个体救济；禁止“一种好结果吸收全部违法”。

### 7. 经验必须被概念化，但理论也必须返回经验

作者主张从改革和案件经验识别新现象，经概念化形成命题与模式，再回到经验检验、修正或证伪；同时警惕漂亮制度目标在现实中无法实现。[`B9TRMQUA`，印刷页7—17]

**可迁移动作：** 固定“经验材料—概念—命题—竞争解释—反例—可观察效果—修正/证伪”链。典型个案或机关文件只能生成假设，不能自行证明普遍性。

### 8. 制度目的不能免除最强反例与边界审查

从羁押司法化、检察审查、协商司法到附条件不起诉，作者一方面提出规范理想，另一方面反复承认司法体制、角色冲突、羁押、信息差、律师资源和社会支持不足会使方案失真。[`CMF3HLNP`，印刷页73—83；`CKER5L8Q`，印刷页13—16；`PF6DLVQ3`，印刷页14—18；`E9ZYIT5Z`，印刷页150、162—163]

**可迁移动作：** 理论—制度建构路线不得只写应然结构；必须附最强经验反例、实施前提和不适用边界。

## 五、跨年继承、体系化、扩展与局部修正

### 1. 2001→2006：继承与体系化，不是转向

2001 年论文论证单一认识论不足以支撑证据规则，将程序正义和形式理性纳入理论基础，但没有否定事实可靠性；2006 年论文进一步把这一基础落实为证据法的调整对象、证据资格/证明规则体系、适用程序和多重功能。[`C4D3DFJT`，印刷页24—28；`KCEMBPA4`，印刷页87—93]

**裁决：** `继承＋体系化`。不得写成“从追求真实转为反对真实”，也不得把所有程序违法统一推成证据排除或事实不成立。

### 2. 2002→2017：由特定制度障碍扩展为宏观结构模型

2002 年论文在未决羁押问题上已指出，侦查主导、法院地位、检察机关角色和体制条件会使司法化改革形式化；2017 年论文把这一障碍扩展为涵盖羁押、财物、卷宗、公开定性、检察强化、程序倒流及审判形式化的“侦查中心主义”模型。[`CMF3HLNP`，印刷页80—83；`TZGYBRVL`，印刷页3—19]

**裁决：** `适用域扩展＋结构模型系统化`，不是观点转向。宏观结构只提供风险解释，具体案件仍须追踪材料和决定链。

### 3. 2017→B9：纳入更宽的基础理论生成框架

2017 年论文集中建立侦查中心主义的结构解释；`B9TRMQUA` 把诉讼构造、合作司法、程序制裁和犯罪治理等新现象纳入刑事诉讼基础理论的概念生成，并要求以经验效果继续验证。[`TZGYBRVL`，印刷页17—19；`B9TRMQUA`，印刷页7—17]

**裁决：** `理论框架扩展`。因 `B9TRMQUA` 纸刊年期未由原文确认，除网络首发时间外不得制造更精细的年度演进叙事。

### 4. 2019→2021：经验诊断上升为理论体系并延伸适用，不是转向

2019 年论文从量刑协商实践中揭示检察主导、羁押、信息差、值班律师和形式审查；2021 年论文提出可弃权性、自愿性、可协商性、获益性和最低参与性五要素，并将其延伸至认罪认罚、刑事和解、未成年人和合规不起诉。[`PF6DLVQ3`，印刷页7—18；`HIDEIB2X`，印刷页9—18]

**裁决：** `理论体系化＋适用域扩展`。不得写成作者由“批判协商”转向“赞成协商”。2019 年的现实批判和 2021 年的规范理论处于不同层次，但理性行动者前提是否足以回应现实能力差距，仍须保留争议。

### 5. 2021→2023：从一般协商理论进入监督考察制度全链，但少年化不足

2021 年论文已把协商性程序正义延伸到未成年人附条件不起诉，却只提出自愿认罪、自由选择考察措施和陈述等最低条件；2023 年论文进一步设计适用对象、基本/专门义务、协议、第三方组织和验收程序。[`HIDEIB2X`，印刷页18；`E9ZYIT5Z`，印刷页145—163]

**裁决：** `适用域扩展＋制度组件化`，不是已完成少年司法转化。两文都没有完整建立发展中能力、关系自主、持续可撤回参与、条件变更、技术性违约和独立救济链。

### 6. B9→2025 量刑补偿论文：局部限缩与精细化

`B9TRMQUA` 把以量刑减让回应程序违法列为可研究的程序制裁/治理现象，同时明确要求界定边界、评估效果；`TUL4PJQR` 系统论证正式量刑补偿会承认违法收益、削弱制裁和救济，主张其逐步退出正式制度，但为无法律明文无效后果、被告人自愿认罪且不排挤正式制裁的场景保留有限协商空间。[`B9TRMQUA`，印刷页10—11、16—17；`TUL4PJQR`，印刷页113—125]

**裁决：** `局部修正/适用范围限缩`。不是彻底否定先前命题；纵向写作须同时呈现“正式制度退出”和“残余协商空间”。

### 7. 2025 年两篇量刑协商论文：同年互补，不证明先后转向

`PU8KYVZV` 以职权宽恕、合意性司法和量刑协商三分法，集中解决被追诉方的参与能力；`YBR6HBLG` 以合意约束和职权裁量两模式，集中处理协议效力、法院审查、反悔和上诉。[`PU8KYVZV`，印刷页5—21；`YBR6HBLG`，印刷页6—24]

## 七、对 `论文初稿（少年司法版）` 的可迁移方法

### （一）教义学路线

1. **确定规范对象。** 区分启动决定、持续状态、条件义务、数据处理、撤销决定和后续记录，不把长期影响压进一次决定。[`CMF3HLNP`，印刷页73—83]
2. **拆法源与规则目的。** 标出法律、司法解释、办案规则、地方实践和作者建议的位阶；以保护目的决定违法后果，不作统一排除或统一补偿。[`C4D3DFJT`，印刷页24—28；`KCEMBPA4`，印刷页87—93]
3. **完成规范链。** 每个争点依次写机构、权限、启动条件、程序参与、证明责任、法律效果、复核和救济。[`KCEMBPA4`，印刷页87—93；`TUL4PJQR`，印刷页113—125]
4. **拆分法律关系与决定对象。** 对附条件不起诉、监督考察和涉案数据分别识别谁提出、谁受影响、谁证明、谁审查和谁上诉，防止主程序吞没附属权利。[`LD68HVXY`，印刷页211—223]
5. **设置救济替代审计。** 检查不起诉、从宽或条件减免是否挤压无效、排除、更正、赔偿、追责和独立复核；该审计从属于规范链，不另立根规则。[`TUL4PJQR`，印刷页113—125]
6. **对合意作三层审查。** 分开同意事实是否真实、谁有权同意及其效力、本人是否具备受支持的真实能力。[`PU8KYVZV`，印刷页13—21；`YBR6HBLG`，印刷页11—24]

### （二）理论—制度建构路线

1. **从经验异常而非抽象口号起步。** 先说明现行制度为何无法解释或实现目标，再提出概念和理论。[`B9TRMQUA`，印刷页7—17]
2. **用理想类型组织竞争方案。** 类型须列构成要素、制度前提、优势、风险和不适用边界，不能把作者建议写成现行事实。[`PU8KYVZV`，印刷页5—8；`YBR6HBLG`，印刷页6—24]
3. **建立权限—角色图。** 特别检查追诉、支持、协商、条件提供、履约判断、撤销和复核是否集中于同一机关。[`TZGYBRVL`，印刷页11—19；`CKER5L8Q`，印刷页13—16]
4. **建立规范链—实施链。** 除纸面权限外，写明律师、社工、心理、教育、交通、照护、经费、信息和专业人员如何到位。[`E9ZYIT5Z`，印刷页150、157—163]
5. **强制最强反例。** 以羁押、信息不对称、资源匮乏、角色冲突和制度激励攻击理想方案。[`PF6DLVQ3`，印刷页14—18；`PU8KYVZV`，印刷页13—19]
6. **回到可观察效果。** 不以签字率、履约率、结案率代替最有利、参与质量、再融入和权利救济效果。[`B9TRMQUA`，印刷页16—17]

### （三）只作辅助模块的方法

- **实证诊断模块：** 用于验证结构风险和实施效果，不以相关性替代因果，不因样本高频产生规范正当性。

## 九、不得迁入少年司法的实体结论

1. 不得把成年被追诉人抽象成稳定、信息充分、能最大化利益的理性行动者。
2. 不得把 `PF6DLVQ3`、`PU8KYVZV` 所用“无行为能力人”或“无诉讼行为能力人”的批判性表述，改写为普遍心理学或法定能力结论。
3. 不得把认罪、签字、沉默、未申请、未上诉或短期履约直接解释为真实同意和权利放弃。
4. 不得把律师明确同意改写为律师可以代替未成年人意愿；律师也不能当然拥有否决本人受支持选择的权力。
5. 不得把成年量刑协议的拘束力、信守承诺、阶梯从宽和协议稳定原则直接用于未成年人。
6. 不得把撤回、反悔、上诉或对条件提出异议直接标记为违约、态度恶劣或加重处理根据。
7. 不得把法院直接参与协商与法院独立、中立审查视为天然兼容。
8. 不得把检察机关兼任追诉者、社会医生、教师、工程师、支持者和违约裁判者作为少年司法的默认机构模式。
9. 不得把“基础义务＋专门义务”清单或扩大到所有轻罪的建议直接写成少年司法规则。
10. 不得把量刑优惠、不起诉结果或考察成功替代程序无效、证据排除、条件变更、赔偿、追责和独立救济。
11. 不得把成年证据法中的具体排除范围、证明责任或司法审查制度机械移植到少年司法。
12. 不得把家庭模式、教育矫治或国家亲权等名称本身当作保护正当性；必须审查实际负担和权力边界。
13. 不得从侦查中心、检察角色冲突等宏观结构直接推定某一未成年人个案已经受到不当影响。

## 十、迁入少年司法必须增加的八项保护条件

### 1. 最有利于未成年人

判断对象是方案对该未成年人的即时和长期实际影响，包括自由、教育、家庭关系、隐私、再融入和污名，而不是“不起诉”“矫治”“保护”等名称。任何有利结果也不能自动治愈程序缺陷。

### 2. 发展中能力

能力必须针对具体决定、具体信息和具体时间动态判断。应分别检查理解选项、预测后果、表达偏好、抵抗压力、寻求帮助、履行条件和改变决定的能力；不得由年龄、一次签字或律师在场机械推定。

### 3. 支持性参与

必须提供适龄语言说明、充分准备时间、独立律师或适当支持者、秘密沟通、重复确认和表达异议的机会。支持的功能是提升本人理解与表达，不是替代本人决定。

### 4. 关系自主

家庭、律师、社工、学校和检察机关既可能提供支持，也可能施加压力。应审查依赖关系、利益冲突、信息来源和共同决定过程，并保留未成年人单独表达的空间。

### 5. 最小干预

在设置附条件方案前，必须先比较不介入、无条件不起诉、警告、简易转介和自愿服务。低风险未成年人不得因进入“协议”而承受比无条件退出更重的条件、数据采集和监控。

### 6. 比例原则

每项条件、期限、报告义务、数据使用、变更和违约后果都须分别与行为严重性、实际需要、能力和资源相称，不能用总体“同意”包裹不相称的单项负担。

### 7. 机构支持义务

在评价履行前，机构须完成说明、资源核验、服务供给、合理调整、交通和照护支持、教育协调及困难记录。资源不足和支持失败不能转化为未成年人的主观不服从。

### 8. 有效审查与救济

救济必须覆盖条件设置、信息使用、能力判断、条件变更、技术性违约、撤销、重新起诉和记录后果；并分列无效、排除、更正、减免、替换、中止、撤回、申诉、上诉、赔偿和人员责任。

## 十一、合意性安排的连续程序闸门

对附条件不起诉、监督考察协议及类似安排，运行时必须逐项回答：

| 字段 | 必答问题 |
|---|---|
| 替代方案 | 是否明确说明无条件不起诉、较少干预方案和拒绝签署的后果 |
| 一次签字与持续参与 | 条件变化、履行困难和重要决定时是否重新说明并听取本人意见 |
| 知情 | 是否以适龄语言说明目的、期限、判断标准、数据用途和不利后果 |
| 可撤回 | 何时、如何撤回；撤回是否自动恢复追诉；能否重新协商 |
| 律师与支持者 | 是否独立沟通、是否忠于本人利益；有无把支持变成替代或否决 |
| 资源核验 | 交通、照护、学业、医疗、网络、家庭和经济资源是否足以履行 |
| 合理调整 | 残障、语言、心理状态、学业和照护责任是否触发调整 |
| 履行能力 | 是否逐项核验，而非由签字推定能完成全部义务 |
| 条件变更 | 谁可减免、替换、中止或延长；本人能否申请并获得理由化决定 |
| 技术性违约 | 迟到、失联、设备或交通故障是否与实质风险和拒绝履行区分 |
| 撤销 | 撤销前是否告知、听取意见、核验机构支持义务并先采用较轻替代 |
| 救济 | 对条件、变更、违约认定、撤销、重新起诉和记录使用是否有独立审查 |

## 十三、交叉对抗吸收后的强制收缩

1. **理论演进收缩：** 2001→2006、2019→2021 只写继承/体系化/扩展，不写转向。
2. **理性选择收缩：** 从理论根基降级为必须逐案验证的假设；羁押、信息、时间、律师、发展中能力和关系压力均可能使其失真。
3. **结构因果收缩：** 权力结构说明风险，个案是否污染仍须追踪具体材料、信息传播和决定过程。
4. **律师作用收缩：** 律师明确同意可作为额外保障候选，但不能写成律师替代本人参与；其是否形成不当否决权保留争议。

6. **少年迁移收缩：** 作者直接谈及未成年人也不等于完成发展中能力、支持性参与、关系自主和最小干预转化。
