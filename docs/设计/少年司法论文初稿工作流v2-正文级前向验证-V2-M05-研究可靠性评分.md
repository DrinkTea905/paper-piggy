## 六、最终判定

V2-M05 原始输出达到研究可靠性门槛，且是当前前向验证中“规范层级—证据能力—迁移限制”处理较完整的一份。它没有把“风险评估有一定预测效度”偷换为“可以用于任何决定”，也没有把“现行法允许社会调查”偷换为“报告内容当然真实可靠”；这正是双重准入模型具有研究价值的地方。

后续若制作回归补充，最有价值的不是增加更多抽象论证，而是：

1. 补入与社会调查、附条件不起诉、量刑程序和未成年人检察直接相关的现行司法解释、检察规则或规范性文件，逐节点标注法源层级与核验时点；
2. 把“保护处分”“动态调整”“理由说明”“重新评估”等制度建议显式标成解释论、立法论或机构操作规范；
3. 保存完整检索式、筛选范围和排除理由；
4. 若要提出中国工具的具体准入标准，必须另行取得中国工具、地方实施、亚群体公平和下游决定效果资料。

这些以后补入的材料不得倒算进本次原始输出的95分；只有单列回归复评时，才可依据新增的一手来源和实际修复内容重新评分。
