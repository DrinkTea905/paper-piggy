## 一、验证目标与冻结规则

前向验证只回答五个问题：

1. 是否把任务路由到正确的顶层工作流和内部路线；
2. 少年司法论文初稿能否生成真正不同、各自闭合的两张路线卡，并在用户选择前停止；
3. 少年司法综述能否完成范围控制、检索纳排、谱系与争议组织、证据分层和原文回溯；
4. 候选规则是否会制造错误路由、概念混同、证据越级、保护主义扩权或少年司法专门性不足；
5. 发现失败后，应当对哪条候选规则作 `保留`、`修改`、`降级`、`删除` 或 `新增`，以及用什么任务回归验证。

正式执行前必须冻结并登记：

| 冻结项 | 执行前登记内容 | 约束 |
|---|---|---|
| 候选规则版本 | D、T、R 三套规则所依据的文件名、规则编号、文件时间或提交标识 | 六题首轮完成前不得边测边改 |
| 工作流模板版本 | 四个顶层工作流的候选模板文本及路由说明版本 | 不得把测试题答案临时补入模板 |
| 任务题面 | 本文件第三节的六段“生成侧题面” | 不得向生成侧附加评审预期 |
| 执行环境 | 模型、工具、知识库快照时间、是否可读原文 | 同一轮保持一致并如实记录 |
| 结果落点 | 另建的前向验证结果文件 | 本文件保持为干净协议，不回填结果 |

## 二、执行与隔离协议

### 1. 上下文隔离

- 六题分别在干净上下文执行，后一题不得看到前一题的生成结果、评分或规则回写意见。
- 生成侧只接收相应题目的“生成侧题面”和当时冻结的候选工作流；不得看到“评审侧预期”“硬失败”或评分锚点。
- 评审侧可读取冻结规则、生成结果及其实际使用的原文，但不得根据自己偏好的实体结论代替评分表。
- “未见”是指这六个题目没有参与候选规则的归纳与措辞；不要求回答时排除已经进入训练集的合格原文。

### 2. 初稿三题的执行停止点

前三题模拟用户只提出论文方向、尚未选定路线且没有声明“不需要比较”。生成侧必须：

1. 识别为 `论文初稿（少年司法版）`；
2. 同时提交教义学、理论—制度建构两张路线卡；
3. 明确推荐其中一条并给出与题目结构相连的理由；
4. 在要求用户选择后停止。

本轮不得模拟用户选路，不得起草摘要、引言、章节正文或完整论文。若生成侧越过停止点，属于硬失败，不因其正文质量较高而补分。

### 3. 综述三题的执行深度

后三题识别为 `综述（少年司法版）`。实际执行时必须完成足以检查原文忠实度的研究综述，而不是只给目录或检索建议，至少留下：

- 范围与边界；
- 检索词族、数据库／知识库范围和纳入排除记录；
- 文献地图或证据矩阵；
- 按争点组织的正文；
- 逐项可回到原文页码的来源记录；
- 反方、适用边界和有界证据缺口。

题录摘要、SAC 摘要和检索片段只能用于发现文献；凡进入实体评价的论文必须逐页读取原文。

### 4. 评分次序

1. 先查硬失败；出现任一硬失败，该题直接判为“不通过”，但仍完成其余维度评分以定位规则缺口。
2. 再按对应百分制表逐项评分，每项必须附生成结果中的可定位证据，不凭整体印象打分。
3. 最后按第七节决定规则去向；不得先决定修改结论，再倒推分数。

## 三、固定六题：生成侧题面与评审侧预期

### F-D01：明显适合教义学路线

**固定题目**：未成年人犯罪记录封存的查询例外与二次使用

**生成侧题面**

> 我准备写一篇少年司法法学论文，研究“未成年人犯罪记录封存的查询例外与二次使用”。请先判断写作路线并给出可供选择的方案。我尚未选定路线。

**评审侧预期（不得发送给生成侧）**

- 应触发 `论文初稿（少年司法版）` 和双路线卡。
- 教义学路线应被判断为明显更适配并获得明确推荐；如反向推荐，须有足以改变题目中心任务的具体理由，否则路由失败。
- 两张卡必须围绕同一研究对象展开，不能把理论—制度建构卡写成教义学卡的换标题版本。
- 重点压力：查询主体、授权根据、查询例外、二次使用、法律效果、程序控制与救济能否形成闭合规范链；评审只检查方法作业是否到位，不预设实体答案。
- 输出必须停在用户选路处。

### F-T02：明显适合理论—制度建构路线

**固定题目**：最小干预原则下专门矫治教育的制度重构

**生成侧题面**

> 我准备写一篇少年司法法学论文，研究“最小干预原则下专门矫治教育的制度重构”。请先判断写作路线并给出可供选择的方案。我尚未选定路线。

**评审侧预期（不得发送给生成侧）**

- 应触发 `论文初稿（少年司法版）` 和双路线卡。
- 理论—制度建构路线应被判断为明显更适配并获得明确推荐；如反向推荐，须证明题目已被合理缩窄为特定现行规范解释问题。
- 理论—制度建构卡应完成原则—机构—权限—程序—措施—法律效果—救济—实施条件的制度链，教义学卡则须诚实限定其能处理的规范争点。
- 重点压力：最小干预不得停留在口号，也不得以“保护”“教育”名称回避自由限制、比例、支持义务和审查救济。
- 输出必须停在用户选路处。

### F-M03：两条路线皆可的混合题

**固定题目**：少年司法社会调查报告的法律性质与制度重构

**生成侧题面**

> 我准备写一篇少年司法法学论文，研究“少年司法社会调查报告的法律性质与制度重构”。请先判断写作路线并给出可供选择的方案。我尚未选定路线。

**评审侧预期（不得发送给生成侧）**

- 应触发 `论文初稿（少年司法版）` 和双路线卡。
- 两条路线都应被评为可行；可推荐任一条，但理由必须说明用户究竟要优先解决规范定性与法律效果，还是机构、权限、程序和信息流重构。
- 不得新造“混合路线”作为第三条主路线；比较法、实证诊断或组织研究只能作为叠加模块。
- 两张卡应在核心问题、中心观点、三级提纲、证据任务和失败边界上形成实质差异，同时保持题目对象一致。
- 输出必须停在用户选路处。

### R-W04：宽综述

**固定题目**：中国少年司法模式的理论谱系、制度转型与证据基础

**生成侧题面**

> 请围绕“中国少年司法模式的理论谱系、制度转型与证据基础”完成一份证据可回溯的研究综述。请先明确时间、地域、对象与材料边界，再检索、纳排和逐页阅读原文，按争点而非按作者流水账组织正文。

**评审侧预期（不得发送给生成侧）**

- 应触发 `综述（少年司法版）`。
- 必须主动收窄可执行范围，避免把“全部中国少年司法”写成无边界百科。
- 理论谱系、制度转型与证据基础三条线须相互对照，不能只有观念史、法条沿革或案例罗列。
- 必须区分作者原说、作者跨篇纵向变化和训练者跨作者综合，并显式保留竞争模式与未决争议。
- 宽综述不以文献数量取胜；以检索可复核、纳排一致、证据分层和缺口有边界为判定中心。

### R-N05：窄争点综述

**固定题目**：附条件不起诉中技术性违约

**生成侧题面**

> 请围绕“附条件不起诉中技术性违约”完成一份窄争点研究综述。请明确概念、制度范围和纳入排除标准，逐页阅读进入评价的原文，并围绕竞争观点、规范依据、实践证据、法律效果与救济组织正文。

**评审侧预期（不得发送给生成侧）**

- 应触发 `综述（少年司法版）`，不能因主题窄而退回一般问答或直接写制度建议。
- 必须说明“技术性违约”是训练综合标签、作者原词还是现行规范术语，并分别处理。
- 应检查迟到、漏报、缺席、失联、拒绝活动等事件与实质风险、理解、履行能力、资源障碍、机构失误之间的区别；不能把所有违反一并处理。
- 综述须组织自动升级、分级回应、支持优先、撤销与救济等竞争方案，但不得把训练规则冒充单篇作者结论。
- 窄综述仍须交代反例和不适用边界，不能只汇总赞成某一方案的材料。

### R-C06：规范与实证证据冲突综述

**固定题目**：未成年人审前非羁押支持的规范正当性与实施效果

**生成侧题面**

> 请围绕“未成年人审前非羁押支持的规范正当性与实施效果”完成一份证据可回溯的研究综述。请分别梳理规范论证与实证研究，说明二者能够相互支持、相互限制或不能互相替代之处，并逐页核验进入评价的来源。

**评审侧预期（不得发送给生成侧）**

- 应触发 `综述（少年司法版）`。
- 规范正当性与实施效果必须先分层再对照，不能用“应当”证明“有效”，也不能以局部执行不佳直接否定权利原则。
- 实证评价须报告样本、地区、时间、指标、比较基准、实施条件和局限；描述数据不得被写成因果结论。
- 应区分非羁押权利、附加条件、支持服务、风险控制和机构资源，检查支持是否被转成控制及资源缺口是否反向归责儿童。
- 结论须允许“规范上成立但实施证据有限”“局部有效但外推受限”等分层状态，不强求一个胜负答案。

## 四、论文初稿三题：双路线卡完整性清单

F-D01、F-T02、F-M03 的每一张卡都必须逐项检查。两个路线名称固定为“教义学路线”和“理论—制度建构路线”。

| 必检字段 | 合格标准 | 教义学卡 | 理论—制度建构卡 |
|---|---|---|---|
| 1. 适配度 | 给出清晰等级或分值，并用题目任务而非个人偏好说明理由 | □ | □ |
| 2. 完整拟题 | 是可独立使用的完整论文标题，且与该卡路线一致 | □ | □ |
| 3. 核心问题 | 明确主要疑问、次级疑问及待解决的规范或制度冲突 | □ | □ |
| 4. 中心观点 | 是可被反驳的完整命题，不是“完善制度”等空泛目标 | □ | □ |
| 5. 三级提纲 | 至少形成章—节—目三级关系，能看出论证推进 | □ | □ |
| 6. 各部分主要内容 | 逐一说明各部分完成何种方法作业及如何支持中心观点 | □ | □ |
| 7. 所需材料 | 分列规范、理论、事实材料，说明材料用途与缺口 | □ | □ |
| 8. 优势 | 说明该路线相对另一条路线真正增加的解释或制度收益 | □ | □ |
| 9. 风险 | 指出证据、规范位阶、实施、外推或篇幅方面的具体风险 | □ | □ |
| 10. 不适用边界 | 说明何种问题目标、材料状态或事实条件下不应采用该路线 | □ | □ |

双卡之后还必须检查：

- □ 明确推荐一条路线；
- □ 推荐理由同时比较题目中心任务、可获得材料、论证闭合度和主要风险；
- □ 没有把比较法、实证诊断、制度史或“混合型”新造为第三条主路线；
- □ 明确要求用户选择；
- □ 用户选择前停止，没有任何全文起草。

### 论文初稿题硬失败

出现任一项即判该题不通过：

1. 用户未选路时只给一张卡；
2. 用户未选路时开始摘要、引言、章节或全文起草；
3. 把“混合型”、实证、比较法或制度史另造为第三条主路线；
4. F-D01 无充分理由却不推荐教义学路线，或 F-T02 无充分理由却不推荐理论—制度建构路线；
5. F-M03 的两张卡实质相同，或把其中一条写成明显不可行的陪衬；
6. 没有中心观点、三级提纲、明确推荐或不适用边界中的任一项；
7. 以作者声望、期刊等级或未经原文核验的实体断言代替路线理由；
8. 把成年刑诉、证据法或一般部门法规则直接迁成少年司法结论而未过少年司法保护闸门。

| **合计** | **100** |  |  |  |

### 综述题硬失败

出现任一项即判该题不通过：

1. 错用通用 `综述`、论文初稿工作流或一般问答；
2. 没有检索范围、纳排标准或文献地图，仅凭已有印象成文；
3. 依题录摘要、SAC 摘要、检索片段、引言或结论替代完整原文阅读；
4. 把作者原说、跨篇纵向重构和训练综合混写，造成无法追溯的归因；
5. 为求单一结论删去最强反方、关键异说或与中心观点冲突的实证材料；
6. 用规范“应当”证明实际有效，或以局部实施失败直接否定规范权利；
7. 把描述统计、个案或相关关系写成因果结论而不说明识别限制；
8. 将成年刑诉或一般风险治理结论直接转成少年司法规则，遗漏发展中能力、支持性参与、最小干预、比例、机构支持和救济；
9. 伪造来源、页码、作者观点或尚未逐页读取的材料状态。

## 七、规则回写协议

### 1. 五种规则去向

| 去向 | 使用条件 | 不得这样使用 |
|---|---|---|
| `保留` | 规则在适用题中稳定触发目标方法作业，未制造相邻任务副作用 | 不能因单题文字漂亮就保留 |
| `修改` | 规则目标正确，但措辞、顺序、触发条件、完成标准或失败警告不足 | 不能用增加题目答案的方式“修规则” |
| `降级` | 规则只在有限题型、材料状态或模块中成立，应从硬规则降为条件性提示、模块或综述争议 | 不能把未经验证的实体结论继续留在默认主路径 |
| `删除` | 规则导致错误路由、重复主路线、证据越级、虚假归因、保护主义扩权或不可修复的混乱 | 不能删除训练证据本身；只删除运行时规则 |
| `新增` | 现有规则确有稳定缺口，且可用一般方法动作而非某一道题的答案补足 | 不能为每次偶发失败新增一条题目专用规则 |

### 3. 防止围绕测试题过拟合

- 单题一般失分先记为修订假设；须由第二个独立任务复现，或能清楚追溯到一条规则造成的硬失败，才进入正式回写。
- 任何修改必须写成可迁移的方法动作、触发条件或停止规则，不得把“犯罪记录封存”“专门矫治教育”等题目答案塞进运行时模板。
- 修改后至少重跑原失败题和一个相邻对照题；路由或用户选择闸门变化须重跑 F-D01、F-T02、F-M03 全部三题。
- 综述的检索、证据分层、归因或原文忠实规则变化，须重跑 R-W04、R-N05、R-C06 全部三题。
- 若修改修复本题却使对照题下降至门槛以下，规则不得定稿。

## 八、通过门槛

### 1. 单题门槛

论文初稿题须同时满足：

- 总分不低于 85／100；
- 无硬失败；
- 两张卡十项字段均有实质内容；
- “用户选择闸门”得满分 8 分；
- “双卡实质差异”和“一致性”各不低于 10 分；
- F-D01、F-T02 的明确路线推荐符合题目主要方法作业；F-M03 的两条路线均真实可行。

综述题须同时满足：

- 总分不低于 85／100；
- 无硬失败；
- “检索记录＋纳排”合计不低于 16／20；
- “作者原说／纵向重构／训练综合分离”不低于 8／10；
- “原文忠实与页码回溯”不低于 9／10；
- 规范与实证冲突、反方和边界均有可定位处理。

### 2. 整套门槛

只有同时满足以下条件，才可在另建结果文件中判定“前向验证通过”：

1. 六题全部达到单题门槛，且六题平均分不低于 88／100；
2. F-D01、F-T02、F-M03 均正确执行双卡和用户选择停止规则；
3. R-W04、R-N05、R-C06 均完成逐页原文核验，没有来源、页码或观点归属错误；
4. 所有硬失败、重大失分和跨任务副作用均已完成规则裁决；
5. 每次 `修改`、`降级`、`删除` 或 `新增` 后，规定的原题与对照题回归验证均再次通过；
6. 没有用一题高分抵消另一题失败，也没有因结果不理想而降低任务难度、材料标准或评分门槛。

达到上述门槛前，候选规则仍是“待验证”；不得写成“已通过”，不得据此宣称产品工作流已完成。即使整套通过，仍须把测试结果、规则最终版本和尚存限制交由主流程统一审查后，才能进入产品实现。

## 九、执行结果文件的最低结构

后续实际执行时另建结果文件，至少包含：

1. 冻结版本登记；
2. 六题原始生成结果或可访问落点；
3. 六张逐项评分表及硬失败检查；
4. 原文忠实度抽查记录；
5. 规则回写表；
6. 回归验证记录；
7. 单题与整套门槛判定；
8. 未解决失败、证据限制和是否允许进入产品实现的明确结论。

本协议文件不预填上述任何结果。
