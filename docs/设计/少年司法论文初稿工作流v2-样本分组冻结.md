1. 校准集 8 篇先制作完整成文总卡、章节功能图和每篇 6—10 组论证动作卡。
2. 校准完成后只交付校准材料、完整性报告、结构原型初步观察和 schema 修订建议。
3. 用户明确确认前，不读取其余深读集 16 篇的写作工艺，不启动盲测，不形成运行时手册，不修改产品模板。
4. 校准阶段出现的结构原型只能称“初步原型候选”，不得在 24 篇完成前写成跨文稳定规则。
5. 后续一般规则仍须至少跨 3 篇、跨 2 名作者，并记录反例和不适用边界；单一作者的标题、比喻、连续句式和个人文风一律拒绝迁移。
