# V2-D02 研究可靠性独立评分

> 评审对象：《未成年人刑事案件分案审理规则的适用条件、例外与违反后果》原始输出。  
> 评审边界：只评价研究可靠性，不评价写作工艺，不以结构、文风或原创表达补足研究分。未读取 B01—B08 盲测正文，未修改原始输出或运行时文本。  
> 评审方法：读取冻结任务集和原始输出；对原稿列明的非盲测来源逐页回读，核对来源真实性、主张归属、法源层级、迁移边界和页码。

## 一、结论

**总分：90/100。研究可靠性通过。**

- 达到单题门槛 85 分。
- “来源真实性、全文阅读与页码准确”为 23/25，达到不得低于 23 分的专项门槛。
- “少年司法专门性和迁移闸门”为 18/20，达到不得低于 16 分的专项门槛。
- 九项硬失败均未触发。

主要可靠性优点是：原稿没有虚构“成年人与未成年人原则必须分案”的现行专属条款，而是承认一手规范缺口，再把“保护性推定＋不可替代性例外”明确作为本文的规范增量；对一般共同犯罪分案文献向少年司法迁移时，引入了隐私、理解、表达和支持性参与闸门。主要风险是：决定全文现行法框架的2021年刑诉法解释第220、269条并未由最高人民法院官方原文直接核对，而是依赖两篇权威论文的完整转录；同时，未取得可能直接涉及未成年人与成年人共同犯罪分案的现行专门司法规范全文，故中心命题只能作为立法／解释方案，不能表述为现行规则。

## 二、六维评分

### 1. 来源真实性、全文阅读与页码准确：23/25

**得分依据**

- 法源 `SAKBMYLE` PDF第47页确有《刑事诉讼法》第238条；第55—57页确有第277—287条，包括专业办理、法律援助、到场、不公开、封存和专章未规定事项适用普通程序。
- `E3B5K5GM` 为龙宗智《有组织犯罪案件分案审理问题研究》，第157页完整转录2021年刑诉法解释第220、269条；第158—164页论证分案的效率收益、事实碎片、质证受限、“无质证认证”与过度分案；第168—170页讨论共犯到庭、庭前会议与完善建议。
- `8XRRBTQP` 为杨杰辉《共同犯罪案件的分案审理研究》，第192—203页确有共同犯罪整体性、人数与复杂性条件、认罪认罚不宜单独分案、决定程序、质证材料、前案参考效力和裁判顺序等论述。
- `3YVQS5H4` 第38—47页确有凯瑞蒙案中的必要性描述／有罪预断区分，并明确前案必要描述不得直接成为后案定罪依据。
- `F2EI6QQ8` 第128—132页支持成人法庭环境、恐慌、理解表达、适龄语言和反馈等未成年人参与命题。
- `XVHBNB4Y` 第127、130—131页确有普通程序成人模板与未成年人特殊需要之间的紧张，以及专章适用普通程序时仍应符合未成年人特殊性的立法建议。

**扣分**

- 第220、269条是全文最重要的现行司法解释依据，但核验停留在权威学术论文的完整转录，没有直接取得最高人民法院现行官方文本，扣1分。
- 原稿明确承认未取得未成年人专属分案规范一手全文。对于一个题名直接研究“未成年人刑事案件分案规则”的教义学稿，这是关键来源缺口，扣1分。

### 2. 法源层级、时点和解释论／立法论：12/15

**得分依据**

- 正确以《刑事诉讼法》未成年人专章和2021年刑诉法解释一般分合规则分别承担特殊保护与共同犯罪程序基础。
- 将人数阈值、“同案同审为原则”、强制分案、申请异议、完整质证权和违法自动发回等内容准确标为学者主张或本文方案，没有全部冒充现行法。
- 对独立书面裁定、立即上诉、未成年人专属条件和关键共犯陈述排除均标注 unknown 或改革方案。
- 以第238条“可能影响公正审判”限制发回，没有把学者的自动发回主张直接写成现行法。

**扣分**

- 关键司法解释只经二手转录核验，法源层级虽被正确识别，但取证层级未达到教义学正式发表的最佳要求，扣1分。
- 未直接核对现行未成年人案件专门司法解释、审判工作意见或其他可能规定成年人与未成年人分案的规范，无法排除“已有更具体规则但稿件未纳入”的时点风险，扣1分。
- “保护性分案推定”与“不可替代性例外”是合理立法论，但正文个别位置语气接近可直接适用的裁判标准；虽由附件和不足事项纠正，解释论／立法论标志仍可更持续，扣1分。

### 3. 规范、理论、事实及证据能力：18/20

**得分依据**

- 把一般分案的“人数＋复杂性＋质量效率”与少年司法的隐私、参与、专业办理和个别处遇分开，再用不可替代性判断合并，推理层次清楚。
- 能区分案号分离、证据共同调查、辩论分段和个别处遇，避免把分案理解为全部证据隔离。
- 将违反后果拆为事实、质证、隐私和参与四类损害，分别连接即时恢复、证据限制和第238条发回门槛。
- 对龙宗智、杨杰辉关于一般或有组织犯罪的研究没有直接当作未成年人案件事实，而是用作共同犯罪事实结构和质证风险材料。

**扣分**

- “整体不公开或分段不公开”“社会调查不向无关同案人披露”等具体保护措施，需要进一步核对公开审判、阅卷、共同被告防御权和隐私规范之间的法源关系，目前主要是制度推论，扣1分。
- “关键共犯不到庭时限制其陈述作为不利定案根据”的精确法律效果缺少一手证据规则与裁判支持，原稿虽承认不是普遍绝对排除，但核心证据能力边界仍未完全验证，扣1分。

### 4. 少年司法专门性和迁移闸门：18/20

**得分依据**

- 不以“共同犯罪原则同审”覆盖未成年人特别程序，而是逐项审查隐私、适龄语言、法定代理人或支持者、社会调查和个别化处遇。
- 也没有把“保护未成年人”绝对化；明确指出机械分案可能损害对成年共犯的质证、造成前案预断，从而反向损害未成年人。
- 对成人／有组织犯罪文献的迁移对象主要限于事实关联、质证、裁判一致和法院承载，随后用少年司法实证材料校正。
- 困难案件包含一名未成年人和两名成年人、外围参与、多名未成年人敌对辩护、认罪成年共犯与不认罪未成年人等专门场景。

**扣分**

- 六项核心来源中，直接研究未成年人特殊程序的仅尹泠然、何挺两项；中心规范仍较大程度建立在一般共同犯罪和有组织犯罪文献上，专属规范与少年法庭实践样本不足，扣1分。
- 对犯罪时未成年、审判时成年，以及不同年龄未成年人共同受审时各项特殊规则如何分拆，只作保留而未形成可操作判断，扣1分。

### 5. 最强反方、困难案件和不确定性：10/10

**得分依据**

- 同时钢人化“一律分案保护儿童”“共同犯罪必须整体审理”“违法分案应自动发回”三类立场。
- 困难案件覆盖高度重合共同抢劫、外围参与大型组织犯罪、多名未成年人敌对辩护、部分成年共犯认罪以及法院资源充足等变量。
- 文末完整披露未成年人专属规范、最高法官方解释文本、决定形式和上诉、人数门槛、隐私修复、共犯陈述后果与本模型未经实证检验等七项不确定性。

### 6. 检索／核验记录及人类可读引注：9/10

**得分依据**

- 正文采用作者、题名、刊物、年份和印刷页引注；法源采用条文号和 PDF 顺序页。
- 来源—论断—页码表列出六项来源并说明法源无印刷页、学术论文页码可逐页核对。
- 对第220、269条的二手转录路径作了显著说明，没有伪装成直接官方核验。

**扣分**

- 核验表没有记录库内键、读取日期和具体转录版本，且未提供最高法一手文本的缺口清单入口；对最关键司法解释只能做到“可回到论文页”，不能直接回到发布机关原文，扣1分。

## 五、最终判定与使用建议

本稿可作为**通过研究可靠性门槛的原始前向验证稿**。正式发表前应优先补齐三类一手材料：最高人民法院现行刑诉法解释第220、269条官方文本；现行未成年人刑事案件审判专门司法规范中关于成年人与未成年人分案的原文及效力状态；分案后关键共犯陈述使用、未成年人隐私与公开审判冲突的代表性裁判或规范。补证应形成另稿或回归稿，不得回改原始输出。
