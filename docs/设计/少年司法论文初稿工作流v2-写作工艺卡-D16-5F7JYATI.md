### 3. 全文推理链

印刷链：

`体系化任务 → 三类运行问题 → 法德日英美制度 → 三项经验 → 四类本土建议`

`降龄与现法缺口 → 规则／考察／机构三断点 → 轻缓化与修复式教育规范方向 → 主体、标准、评估、执行、转出接口 → 分项建议`
