### 2.2 初稿卡

#### 问题如何提出

文章先确认我国实践已经出现量刑协商因素，再以三组落差把一般制度描述问题化：法律没有明文设置专门量刑协商程序，检察机关的“听取意见”常被前置讯问架空，值班律师和被追诉人缺乏信息、准备和筹码，法院又依职权全面控制协议效果，由此形成“只有合意，没有协商”的局面（顺序页1—3、8—14／印刷页3—5、10—16）。作者把问题从“有没有签字合意”改写为“协商是否平等、充分、有效，参与者是否具有改变方案的真实能力”，再以去职权化和提升协商能力两条路线提出结构改革（顺序页3、15—19／印刷页5、17—21）。

#### 概念如何拆分和界定

1. `职权宽恕`：司法机关因认罪和接受特别程序而依职权给予宽大结果，被追诉人不能影响具体方案（顺序页3—4／印刷页5—6）。
2. `合意性司法`：国家单方提出方案，被追诉人只能接受或拒绝，存在合意结果但没有异议、替代方案和相互调整（顺序页4—5／印刷页6—7）。
3. `量刑协商`：被追诉方能够提出方案、异议、证据、事实、类案和法律观点，经多轮调整、妥协形成协议，法院再行审核（顺序页5—6／印刷页7—8）。
4. 作者把最低协商结构拆成自愿选择、提出方案、提出筹码和异议、相互调整、达成妥协、签署协议及法院审核等要素；这使“签字”只成为协商链末端，而非真实协商的充分证明（顺序页5—6／印刷页7—8）。
5. `参与协商能力`不是抽象智力或一次性表达能力，而由免受羁押和强迫的地位、有效律师帮助、案卷知情、准备时间、秘密沟通和可用筹码共同构成（顺序页11—17／印刷页13—19）。
6. `制度性筹码`来自沉默、保释、律师、非法证据排除、撤销起诉和上诉等权利；`技术性筹码`来自案卷审查、调查、量刑事实、程序错误和法律争议。作者用这一对概念说明权利保障不是协商外部装饰，而会改变国家与个人的实际谈判结构（顺序页13—14／印刷页15—16）。

#### 法源与规范关系

文章以《刑事诉讼法》认罪认罚、听取意见和“一般应当采纳”条款为法律背景，并引用两高三部指导意见、检察机关监督管理办法、听取意见同步录音录像规定和指导性案例说明量刑协商在规范与实践中的形成（顺序页1—2、6、8—10／印刷页3—4、8、10—12）。作者始终把犯罪事实、证明标准、罪名、罪数与量刑幅度区分，认为前四者原则上不能成为协商对象，而法定量刑幅度内的减让可有处分空间（顺序页1、5、16、18／印刷页3、7、18、20）。这是作者的解释与改革主张，不可直接等同现行法已经确立“量刑处分原则”。

#### 规范、类型、模式或理论如何建构

作者采用“概念分层—结构诊断—能力诊断—制度重建”的推理链：

1. 先用职权宽恕、合意性司法和量刑协商三个递进概念重定研究对象（顺序页3—6／印刷页5—8）。
2. 再从认罚从宽、听取意见和法院职权裁判三处识别制度中的职权因素（顺序页6—10／印刷页8—12）。
3. 接着把参与能力拆为有效律师、知情和协商筹码三项可观察条件（顺序页11—14／印刷页13—16）。
4. 最后分别改造制度权力结构和参与条件，提出协商意向、准备、初步方案、展开协商、签署协议、提出量刑建议六环节，并设置法院不采纳事由、指定辩护、自行阅卷、准备时间和秘密沟通等配套条件（顺序页15—19／印刷页17—21）。

#### 竞争观点与最强反驳

- 竞争观点一认为认罪认罚仍只是职权从宽，并不存在协商；作者用规范文件、指导性案例和有辩护人参与的实践说明协商因素已经出现（顺序页1—3、5—6／印刷页3—5、7—8）。
- 竞争观点二认为签署具结书和听取意见已经足以保证自愿；作者以讯问前置、羁押、信息不对称、值班律师形式参与和“要么全部、要么没有”说明形式程序可能制造被动接受（顺序页2、8—13／印刷页4、10—15）。
- 竞争观点三强调法院为实体真实、罪刑法定和罪责刑相适应应全面实质审查；作者主张仅对事实、罪名、罪数、法定幅度和程序合法性作实质控制，对法定幅度内量刑减让予以尊重（顺序页9—10、16、18／印刷页11—12、18、20）。
- **最强外部反驳**：作者把“能提出更强筹码”视为协商实质化的核心，可能仍以谈判优势而非权利不可交易性衡量公正；程序违法、无罪疑点和律师权利不能只因能换取更低刑罚就被视为协商资源。法官直接与被告方协商又可能混同中立裁判者、程序主持者和结果谈判者。作者在结论中承认法官角色有争议，但未完成回避、预断防止、协商失败后的证据隔离和独立救济设计（顺序页14、18—19／印刷页16、20—21）。

#### 机构、权限、程序、法律效果和救济

- **机构**：侦查机关告知和移送协商意愿；检察机关提出方案并协商；辩护律师全程帮助；法院审核，作者还允许法院主持或直接参与审判阶段协商（顺序页15—19／印刷页17—21）。
- **权限**：控辩双方仅在不降低证明标准、不改变罪名和罪数、不突破法定量刑幅度的范围内处分；法院保留对事实、法律、法定幅度、程序合法性和真实自愿的审查（顺序页5、16、18／印刷页7、18、20）。
- **程序**：意向—准备—初步方案—异议与多轮协商—协议—量刑建议六环节；律师全程在场、阅卷、准备、秘密沟通和反馈构成前提（顺序页15—17／印刷页17—19）。
- **法律效果**：控辩协议约束检察机关和被追诉方；法院在作者限定的不采纳事由外应尊重量刑减让。未经律师全程参与的协商、合意和具结书被作者设计为无效（顺序页5—6、16—19／印刷页7—8、18—21）。
- **救济**：文章提出法院审核和无效后果，却没有系统设计儿童或成年被追诉人对拒绝启动、信息不全、律师帮助失效、检察官拒绝异议、协议变更、程序退出和协商失败后的申诉路径；对法官直接参与协商后的中立复核亦未展开（顺序页16—19／印刷页18—21）。

#### 实施条件与边界

实施需要足够的法律援助律师、合理报酬、尽早指定辩护、完整阅卷、被追诉人自行阅卷、准备期限、在押会见与秘密沟通、非羁押条件、录音录像、检察官说明理由和法院明确审查标准（顺序页11—19／印刷页13—21）。原文没有报告系统抽样、访谈或案件编码方法，对“众所周知”“普遍”“大多数”等实践判断不能作全国发生率外推（顺序页2、8—14／印刷页4、10—16）。自行阅卷、废除值班律师、法院直接协商及量刑幅度处分均是作者改革方案，不是已经实施的制度事实。

#### 严重案件压力测试

文章允许在法定量刑幅度内协商，但严重案件仍须保持犯罪事实和从重量刑情节的高证明标准，不能用认罪、协商或被害人谅解弥补证据不足（顺序页1、5、16／印刷页3、7、18）。作者没有充分处理严重暴力案件中的被害人安全、持续参与、创伤支持、意见与儿童最有利发生冲突时的决定标准。迁入少年司法时，量刑优惠的可预期性不能变成迫使儿童承认未理解事实或放弃审判的压力。

#### 低风险案件压力测试

低风险案件中，复杂协商、强制律师、完整协议和法院审核可能增加程序负担；应先判断是否可不起诉、无条件分流或最低干预，而不是为了生成“真实协议”把儿童留在更长的刑事程序中。原文把协商程序视为认罪后的改革中心，没有展开“无需协商即可退出正式系统”的优先顺序（顺序页15—19／印刷页17—21）。

#### 少年司法迁移八闸门

| 闸门 | G批核验 |
|---|---|
| 最有利于未成年人 | 原文没有少年司法适用；迁入时不能把提高协议稳定性、认罪率或诉讼效率当作最有利，须单独证明方案对该儿童的权利和发展影响 |
| 发展中能力 | “缺乏协商能力”应改造成关系性、任务特定且可支持的能力判断，不得把儿童整体定性为无行为能力；需适龄说明、重复确认和理解核验 |
| 支持性参与 | 律师、阅卷、准备、秘密沟通、提出异议、反馈理由具有直接方法价值；还须增加儿童偏好表达、适龄材料、可信支持人和持续确认 |
| 关系自主 | 文章识别羁押、信息和专业资源的不对等；迁入时还须审查监护人、律师、社工和检察官之间的依赖、利益冲突和影响方式 |
| 最小干预 | 先判断无条件退出、非正式支持或较轻程序是否足够；不得把协商本身变成进入正式控制的门槛 |
| 比例原则 | 不只审查刑罚减让是否在法定幅度，还要审查放弃权利、披露信息、协议义务和退出后果是否与目的相称 |
| 机构支持义务 | 指定辩护、信息提供、准备时间、非羁押和秘密沟通应由国家保障，不得要求儿童自行取得“筹码”证明值得从宽 |
| 有效审查与救济 | 法院审核和无效后果可迁移为起点；须补入独立复核、撤回、变更、异议、协商失败后的信息隔离和法官中立性 |

#### 合意性安排专项六分法

| 项目 | 原文与少年司法边界 |
|---|---|
| 形式同意 | 签署具结书只是链末结果；没有异议、替代方案和相互调整时属于“只有合意，没有协商”（顺序页4—6、8—9／印刷页6—8、10—11） |
| 真实协商能力 | 由律师、信息、准备、沟通、非羁押和筹码共同生成，不是一次询问能证明的内在属性（顺序页11—17／印刷页13—19） |
| 国家义务 | 国家应尽早指定辩护、提供案卷、合理准备期、秘密沟通和程序说明；迁入少年司法还须增加资源核验与合理调整（顺序页16—19／印刷页18—21） |
| 法律效果 | 协议对谁有何拘束力、法院审查范围、无律师时是否无效须分别写明；作者方案不可直接套入监督考察协议（顺序页5—6、16—19／印刷页7—8、18—21） |
| 救济 | 原文的无效和法院审核不足以覆盖拒绝、撤回、变更、错误说明和协商失败后的救济，必须补齐 |
| 技术性违约 | 本文“技术性筹码”不是“技术性违约”。反悔、上诉或改变意见也不能移植为监督考察中的迟报、漏报等技术性违约；本文没有讨论考察条件履行，不能据此生成违约规则 |

#### 可迁移方法

1. 用“职权给予—被动接受—实质协商”递进概念检验制度名称与实际参与是否一致。
2. 把真实协商能力拆成信息、律师、时间、沟通、自由状态、提出异议和影响结果的机会。
3. 从表面协议反向追查国家是否先履行说明、材料提供、资源和程序保障义务。
4. 将协商的启动、准备、方案、异议、修订、协议、审查和效果写成连续程序链。
5. 把法律效果分配到检察机关、被追诉人和法院，不能笼统写“协议有约束力”。
6. 以形式同意与实际影响能力的差距为最强反例，并检查法官兼任协商者和审查者的角色冲突。

#### 不可迁移实体结论

- 成年认罪认罚量刑协议应对法院具有何种拘束力。
- 应废除值班律师、废除具结书、确立自行阅卷和量刑处分原则的具体方案。

### 3.2 初稿卡

#### 问题如何提出

文章不再停留于“我国有没有量刑协商”，而是从检察机关和法院对同一制度的性质、程序与效力作出相反解释这一组织冲突出发，把争议重构为两个模式：量刑合意是否约束法院、法院审查到何种程度、被追诉人能否反悔和上诉，以及谁主导协商（顺序页1—3／印刷页6—8）。问题由单条规范解释上升为“同一制度在不同国家机关立场下形成何种权力结构和法律后果”。

#### 概念如何拆分和界定

1. 作者先列五个最低协商要素：检察官提出方案、被追诉方提出筹码、检察官调整、形成合意、签署协议（顺序页4—6／印刷页9—11）。
2. `合意约束模式`把量刑合意视为公法契约和国家承诺，对控辩及法院均有拘束力，法院主要作形式审查，被追诉人反悔或上诉可能失去宽大结果（顺序页6—9／印刷页11—14）。
3. `职权裁量模式`把量刑建议视为求刑权，法院保留事实、法律和量刑的实质审查，认罪认罚主要作为法定从轻情节，被告人保有上诉（顺序页11—16／印刷页16—21）。
4. 模式不是单一观点标签，而是由协商主体、协议性质、拘束对象、法院审查、反悔／上诉后果及理论根据组成的命题束。

#### 法源与规范关系

文章从《刑事诉讼法》的听取意见、“一般应当采纳”和认罪认罚条款出发，结合两高三部指导意见、检察规范、指导案例和最高司法机关代表性论述，重建两种制度解释（顺序页2—8、11—16／印刷页7—13、16—21）。作者区分了规范条文、机关立场和自己的模式评价；“公法契约”“裁判确定性”“裁判权不可让渡”等是理论说明，不是规范本身。最终方案主张废弃“一般应当采纳”、法院参与协商、保障反悔和上诉，是立法论（顺序页18—19／印刷页23—24）。

#### 规范、类型、模式或理论如何建构

1. 收集同一制度中检察机关与法院关于认罚、量刑建议、法院审查、反悔和上诉的成组命题（顺序页2—3／印刷页7—8）。
2. 以“协议约束谁、谁拥有最终决定权”为主轴，分别命名合意约束和职权裁量模式（顺序页3、6、11／印刷页8、11、16）。
3. 为每个模式重建制度表现、理论基础和最强理由，再从该模式自身目标出发暴露内在缺陷（顺序页6—17／印刷页11—22）。
4. 不在两模式间简单二选一，而提取双方不可放弃的价值：协议须有实际意义、法院须有实质审查、参与者须有真实能力、反悔和上诉不得额外受罚；据此改变两步程序和角色分配（顺序页17—19／印刷页22—24）。

#### 竞争观点与最强反驳

- 合意约束模式以公法契约、国家信用和争议解决为最强理由，强调确定性量刑建议和协议稳定性对程序激励的重要性（顺序页7—9／印刷页12—14）。
- 作者的内部攻击是：法院没有参与协商且负有独立裁判职责，不能被检察机关协议刚性约束；更根本的是，被追诉人在羁押、信息不足、值班律师无效和检察官“分而治之”下，形式自愿不等于真实利益和意志（顺序页9—11／印刷页14—16）。
- 职权裁量模式以实体真实、裁判确定、法律统一和裁判权不可让渡为最强理由（顺序页13—16／印刷页18—21）。
- 作者的内部攻击是：协议若对法院毫无效力，协商失去意义；法定幅度内并非没有处分空间；速裁和简易程序缺乏直接言词审理，法院宣称的全面实质审查可能只是目标而非可实现机制（顺序页16—17／印刷页21—22）。
- **最强外部反驳**：作者的混合方案让法院事先阅卷、主持听证、参与重新协商并最终裁判，可能加重预断和角色混同；所谓“法院实质审查＋尊重协议”仍需明确审查标准、失败后回避、材料隔离和上级救济，否则只是把权力集中点从检察机关移向法院（顺序页18—19／印刷页23—24）。

#### 机构、权限、程序、法律效果和救济

- **机构**：现状由检察机关主导协商、法院事后审查；作者方案让检察机关形成初步合意，向法院申请正式协商听证，由法院审查并可重新协商，辩护律师全程参与（顺序页18—19／印刷页23—24）。
- **权限**：控辩在法定幅度内处分量刑，不能降低证明标准、改变罪名或罪数；法院不受刚性协议约束并保留实质审查（顺序页2、17—19／印刷页7、22—24）。
- **程序**：被追诉人与律师先沟通，检察官不得单独协商；正式听证前可反悔；法院听取控辩和必要时被害方意见（顺序页18—19／印刷页23—24）。
- **法律效果**：初步合意未经法院认可不生效；无辩护律师参与或检察官单独协商的合意无效；反悔可撤销原有认罪认罚减让，但不得额外从重；上诉触发二审开庭和重新审查（顺序页18—19／印刷页23—24）。
- **救济**：作者明确保障正式听证结束前反悔和判决后上诉，较前篇补足效果；但没有完整设计对法院主持协商的异议、法官回避、协商信息隔离、律师与儿童意见冲突和错误撤销减让的救济。

#### 实施条件与边界

方案依赖强制指定辩护、案卷提供、优先非羁押、法院预先阅卷和正式协商听证、控辩律师共同到场、私下沟通以及二审开庭（顺序页18—19／印刷页23—24）。文章没有测算律师、法院和听证资源，也未报告两模式在案件中的分布和效果；两种模式是对机关权威观点的理想类型，不等于每一检察官或法官均完全符合某一模式。

#### 严重案件压力测试

严重案件中，协议稳定不能替代高证明标准、罪名和罪数审查，被害人意见也不能只作为达成量刑优惠的资源。法院参与协商后仍须有不受预断影响的事实审查和被害人安全程序。作者以钱某故意伤害指导案例说明异议与和解影响量刑，但单一案例不能证明强协议效力或制度效果（顺序页4—5、9—10、18—19／印刷页9—10、14—15、23—24）。

#### 低风险案件压力测试

低风险案件若必须进入法院正式协商听证、指定辩护和多轮协议，可能增加控制与等待。迁入少年司法时应先问是否可无条件不起诉或非正式支持；程序保障的加强不能变成把本可退出的儿童继续留在刑事系统的理由。

#### 少年司法迁移八闸门

| 闸门 | G批核验 |
|---|---|
| 最有利于未成年人 | 两模式均以成年量刑和机关权力为中心；迁入时须把儿童具体利益置于协议稳定、法院权威和办案效率之前 |
| 发展中能力 | 作者识别被追诉人缺乏协商能力，但未作年龄、发展和任务特定分析；须增加适龄说明、理解检验和可反复表达 |
| 支持性参与 | 律师全程、案卷、私密沟通、反悔和上诉具有方法价值；律师签字不能代替儿童本人意见 |
| 关系自主 | “分而治之”和信息不对称揭示国家塑造选择的关系结构；还须审查监护、律师和支持人的影响及利益冲突 |
| 最小干预 | 反悔不能额外惩罚值得迁移；但正式听证和协议程序仅在比无条件退出更必要时启用 |
| 比例原则 | 撤销原有减让与额外惩罚必须区分；量刑、协议义务和权利放弃均须比例审查 |
| 机构支持义务 | 指定辩护、材料提供、非羁押和私密沟通是国家前置义务，不应由儿童通过“表现良好”换取 |
| 有效审查与救济 | 法院实质审查、反悔和上诉形成较完整起点；须补法官回避、信息隔离、决定理由和外部复核 |

#### 合意性安排专项六分法

| 项目 | 原文与少年司法边界 |
|---|---|
| 形式同意 | 五个最低协商要素仍可能只描述形式链；作者在评价部分明确指出羁押、无知情和无有效律师时的合意不体现真实意志（顺序页6、9—11／印刷页11、14—16） |
| 真实协商能力 | 需要有效辩护、案卷、自由沟通、非羁押和可提出筹码；迁入儿童场景还须增加发展和关系支持 |
| 国家义务 | 国家应指定辩护、提供案卷、变更强制措施、禁止单独接触并组织可审查听证（顺序页18—19／印刷页23—24） |
| 法律效果 | 必须分清初步合意、正式协议、法院认可、无效、反悔和上诉的效果，不能只写“双方同意即生效” |
| 救济 | 反悔权、上诉权和不得额外惩罚是本篇实质增量；法官角色冲突和协商失败信息隔离仍缺 |
| 技术性违约 | 反悔和上诉是法定权利行使，不是监督考察中的技术性违约。即使可撤销原有量刑减让，也不得转译为对迟报、漏报或资源性不履行从重处罚 |

#### 可迁移方法

1. 把机关立场重建成由主体、权限、协议性质、审查和效果组成的模式，而不是观点口号。
2. 对每一模式先给出最强理论理由，再用其自身目标检查内在失败。
3. 将“协议稳定”与“法院独立审查”从非此即彼改成可分别配置的制度组件。
4. 把反悔、上诉、撤销优惠和额外惩罚分成不同法律效果。
5. 模式选择不止写价值宣言，还要改造启动、协商、听证、参与、审查和救济的组织接口。
6. 检查正式程序是否具备现实实现条件，防止“实质审查”或“真实协商”只停留在标签。

#### 不可迁移实体结论

- 认罪认罚已在我国无争议地形成量刑协商。
- 协商性量刑建议对法院具体具有何种效力。

### 4.2 初稿卡

#### 问题如何提出

文章从一个看似有利于被告人的裁判做法切入：国家机关程序违法后，法院不宣告行为或结果无效，也不惩罚违法者，而以从轻、减轻或免刑“补偿”被告人。作者以刘涌案、诱惑侦查规则和认罪认罚协商中的程序违法筹码说明该机制曾有实践空间，再追问这种优惠究竟是有效救济，还是以量刑利益掩盖程序法失效和权利损害（顺序页1—4／印刷页109—112）。问题由“是否给了好处”重构为“违法是否被否定、违法所得是否被剥夺、责任人是否受制裁、受害者是否真正获救济”。

#### 概念如何拆分和界定

1. `程序性制裁`：通过排除证据、撤销起诉、撤销原判等宣告无效方式否定违法行为及其结果，剥夺违法者违法所得的诉讼利益（顺序页3、5—6、11—13／印刷页111、113—114、119—121）。
2. `实体性制裁`：通过民事赔偿、行政惩戒或刑事追责限制违法办案人员的实体利益（顺序页3、6、13—15／印刷页111、114、121—123）。
3. `量刑补偿`：承认违法行为和所得证据／结果仍有效，把程序违法拟制为从宽量刑情节，给被告人刑罚优惠，但不否定违法、不惩罚违法者（顺序页5—6／印刷页113—114）。
4. 作者还区分正式规则与潜规则、犯意引诱与数量引诱、严重／较轻程序违法、无罪辩护与认罪认罚两种诉讼立场，进而限定不同法律效果（顺序页2—4、15—17／印刷页110—112、123—125）。

#### 法源与规范关系

文章以非法证据排除、撤销原判发回重审、国家赔偿、纪律责任和相关犯罪构成程序性与实体性制裁框架，以2008年“大连纪要”和2023年“昆明纪要”说明诱惑侦查法律效果变化（顺序页2—5、11—15／印刷页110—113、119—123）。比较法材料用于说明不当诱惑侦查可能走向证据禁止、诉讼障碍或撤销起诉（顺序页7、12—13／印刷页115、120—121）。作者对“无明文则无无效”的描述和未来扩大撤销起诉、强制排除、实体追责的主张须区分；后者是立法论。

#### 规范、类型、模式或理论如何建构

1. 先把程序违法的三种处理机制按法律对象和后果分开（顺序页3、5—6／印刷页111、113—114）。
2. 再以法律秩序、违法治理、裁量滥用和权利救济四个维度攻击量刑补偿（顺序页7—11／印刷页115—119）。
3. 接着追溯量刑补偿存在的制度空间：正式程序性和实体性制裁供给不足，法院才选择折中优惠（顺序页11—12／印刷页119—120）。
4. 最后以“完善正式制裁为原则、残余协商为例外”提出分流：不认罪和无罪辩护案件适用宣告无效；认罪认罚且法律无明文无效后果时，程序违法可成为量刑协商筹码（顺序页15—17／印刷页123—125）。

#### 竞争观点与最强反驳

- 支持量刑补偿者认为程序性制裁过于“全有或全无”，量刑优惠更灵活、成本更低，可以给被告人现实利益和提高救济可用性（顺序页2—3、9—11／印刷页110—111、117—119）。
- 作者最强回应是：量刑优惠不否定违法、不剥夺违法所得、不追责违法者，还可能接受非法证据并维持有罪裁判，损害法律秩序和真正救济；所谓补偿与被告人责任减轻之间只有拟制关系（顺序页5—11／印刷页113—119）。
- 作者又承认制度供给不足使该潜规则具有现实空间，并在认罪认罚中保留残余协商用途（顺序页11、15—17／印刷页119、123—125）。
- **最强外部反驳**：作者将“认罪认罚、律师放弃无罪辩护”推成放弃质疑侦查和公诉程序合法性的前提，可能把实体认罪、程序权利放弃和救济选择不当捆绑。一个在程序违法、羁押和信息不对称背景下形成的认罪决定，未必具有交换救济的真实能力；即使量刑补偿是附加利益，也不能替代国家制裁违法和修复权利（顺序页15—17／印刷页123—125）。

#### 机构、权限、程序、法律效果和救济

- **机构**：法院适用程序性制裁或量刑补偿；侦查、公诉、审判机关及个人是违法主体；纪律、民事和刑事机关承担实体追责；辩护方可提出程序性辩护或把违法作为协商筹码（顺序页3、11—16／印刷页111、119—124）。
- **权限**：无效、证据排除、撤销起诉、撤销原判须有规范依据；作者主张扩大违法公诉和严重非法实物证据的无效后果，并改革行政、民事、刑事责任（顺序页11—15／印刷页119—123）。
- **程序**：原文提出审查违法—选择制裁路径—必要时程序补救／重新起诉，但未形成逐案听证、证明责任、披露和上诉的完整程序。
- **法律效果**：程序性制裁否定行为或结果；实体性制裁追究人员责任；量刑补偿保持有罪和违法所得效力、只降低刑罚（顺序页5—6／印刷页113—114）。
- **救济**：作者强调无效、赔偿、惩戒和刑责才可能形成实质救济；量刑优惠不足以伸张正义、否定侵权和补偿损害（顺序页10—11、13—16／印刷页118—119、121—124）。但其残余方案仍允许被告方放弃程序性制裁以换取刑罚利益，形成内部张力。

#### 实施条件与边界

废止正式量刑补偿依赖非法证据排除、撤销起诉、发回重审、国家赔偿、纪律和刑责机制均能实际运行，并需要清晰违法分类、听证、证明责任、独立审查和人员问责（顺序页11—16／印刷页119—124）。文章承认实践适用频率缺少系统实证研究，不能据其“逐渐弱化”概括准确发生率（顺序页3、7／印刷页111、115）。比较法中的撤销起诉和诉讼障碍不能脱离原法域权限、补救和再起诉规则迁移。

#### 严重案件压力测试

在死刑、严重暴力或重大毒品案件中，量刑补偿表面上可能避免最严厉刑罚，但若非法证据和程序违法未被否定，仍可能维持错误有罪裁判。严重性不能降低证明标准或使刑讯、非法诱惑合法化；被害人和公共安全也不能代替国家证明及程序合法性（顺序页1—2、4—11／印刷页109—110、112—119）。

#### 低风险案件压力测试

轻微程序违法也不能自动转化为更多协商、报告或认罪义务。应先使用补正、排除、停止程序、撤销起诉等与违法性质相称的方式，防止为获得轻微量刑优惠迫使低风险儿童留在刑事系统或放弃异议。原文的“最后手段”争论提示比例分层，但作者没有少年司法退出阶梯（顺序页3、11—13、15—17／印刷页111、119—121、123—125）。

#### 少年司法迁移八闸门

| 闸门 | G批核验 |
|---|---|
| 最有利于未成年人 | 量刑减让看似有利但可能掩盖错误定罪和权利侵害；须比较无效、退出、赔偿、服务和量刑优惠的真实后果 |
| 发展中能力 | 原文没有儿童能力分析；儿童认罪或律师策略不能当然证明其理解放弃程序救济的性质和长期后果 |
| 支持性参与 | 须有适龄说明、独立律师、选择各救济路径的时间和无惩罚异议；不能只让律师把违法转换为筹码 |
| 关系自主 | 国家先实施违法再提出量刑优惠时，选择结构本身可能受胁迫；须审查羁押、依赖和律师—儿童立场冲突 |
| 最小干预 | 优先停止违法、排除不利材料、退出正式程序；不得以优惠为由维持本可终止的追诉或控制 |
| 比例原则 | 制裁须与违法严重性及法律效果相称，补偿不得抵销违法者责任；儿童承担的放弃成本也须审查 |
| 机构支持义务 | 发现、调查、制裁和补偿程序违法是国家义务，不能转嫁为儿童自行发现并议价的负担 |
| 有效审查与救济 | 本篇最强方法贡献；必须区分无效、人员追责、赔偿和量刑利益，确保后者不替代前三者 |

#### 合意性安排专项六分法

| 项目 | 原文与少年司法边界 |
|---|---|
| 形式同意 | 认罪认罚或律师放弃无罪辩护只说明诉讼立场，不能单独证明对程序违法、无效、赔偿和申诉的知情放弃 |
| 真实协商能力 | 须能识别违法、理解不同救济及后果、获得独立帮助并在无报复压力下选择；原文残余方案未完整证明这些条件 |
| 国家义务 | 国家应依法调查、宣告无效、追责和赔偿，而非等待被告方把国家违法当筹码（顺序页11—16／印刷页119—124） |
| 法律效果 | 违法行为效力、证据能力、追诉／裁判效力、责任人法律责任和被告人量刑必须分栏，不能以一项量刑优惠“一揽子结算” |
| 救济 | 量刑补偿不是无效、赔偿、惩戒或刑责的替代品；残余协商是否只是附加救济须独立裁决 |
| 技术性违约 | 本篇对象是**国家程序性违法**，不是儿童违反监督考察条件的“技术性违约”。不得因术语相似混用；更不得用儿童迟报、漏报去抵销国家的说明、支持或合法程序义务 |

#### 可迁移方法

1. 对任何“优惠式补救”做`救济替代审计`：违法是否被否定、违法所得是否被剥夺、责任人是否被制裁、受害人是否获得独立救济。
2. 按行为效力、结果效力、人员责任和受害人利益四层拆分法律效果。
3. 先识别正式救济供给为何失灵，再评价潜规则的现实功能；现实存在不等于规范正当。
4. 用最强反方说明灵活补偿的现实利益，再检验它是否制造错误定罪、裁量滥用和权利交换。
5. 把诉讼立场、权利放弃、真实能力和救济选择分开，禁止由认罪自动推出放弃程序权利。
6. 区分国家程序违法和儿童技术性违约，防止用后者遮蔽前者或抵销国家义务。

#### 不可迁移实体结论

- 认罪认罚或放弃无罪辩护等于放弃质疑程序合法性。
- 成年案件中程序违法应一律适用何种无效或量刑效果。
- 犯意引诱、数量引诱、撤销起诉和重新起诉的具体规则。
- 应增设哪些办案人员罪名、民事责任或绩效惩戒。
- 法律没有无效明文时，程序违法当然可以作为少年司法量刑或协议筹码。

### 5.5 作者内部张力

1. **权利保障与权利筹码化**：三篇都要求权利有实效，但又把非法证据排除、程序违法、上诉等权利或救济视为谈判杠杆。若国家只在个人放弃正式救济后给优惠，权利保障可能被市场化（指定页见5.4第三行）。
2. **真实协商与律师替代**：作者强调被追诉人真实能力，却提出无律师同意协议无效；律师作为必要支持是否会变成替代本人意愿，原文未解决。儿童场景必须加入儿童独立表达和律师—儿童分歧处理（`PU8KYVZV`顺序页17—19／印刷页19—21；`YBR6HBLG`顺序页18—19／印刷页23—24）。
3. **法院审查与法院协商**：作者一方面用法院独立审查反对检察协议刚性效力，另一方面让法院直接参加或主持协商；这会产生预断、压力和协商失败后信息污染（两文末页见5.4第五行）。
4. **反对量刑补偿与保留残余交易**：`TUL4PJQR`认为量刑补偿损害程序法和真正救济，却又为认罪案件留下协商空间。该空间是独立附加利益还是对正式救济的替代，文本没有给出可操作边界（顺序页15—17／印刷页123—125）。
5. **协议稳定与可撤回参与**：国家信用和协议预期要求稳定，但真实参与要求在信息、能力或条件改变时能够撤回和修正。`YBR6HBLG`补入反悔与上诉，但撤销原有减让是否形成威慑仍待裁决（顺序页18—19／印刷页23—24）。

上述均为三篇之间的**文本张力**，不是已经确认的“作者观点发生变化”。后者须在 E、F、G 全部指定页第二读后才可判断。

### 5.6 可迁移方法与不可迁移结论

#### 可迁移方法

1. 从形式签字反查真实协商能力和国家前置支持。
2. 用主体—权限—程序—拘束对象—审查—反悔／上诉构建竞争模式。
3. 对抽象“合意”“补偿”“保护”做名义—实际法律效果审查。
4. 对优惠性方案做救济替代审计，不让结果利益遮蔽国家违法和独立救济。
5. 将国家义务与儿童能力联动：说明、资源、律师、时间、合理调整和非羁押条件决定参与是否真实。
6. 将反悔、上诉、条件未履行和技术性违约分开，禁止以“信守协议”消灭权利行使。

#### 不可迁移的成年刑诉或证据法结论

- 认罪认罚量刑协议的具体效力和法院审查强度。
- 值班律师、指定辩护、自行阅卷和法院协商听证的具体立法方案。
- 程序违法能否作为成年案件量刑筹码。
- 犯意引诱、数量引诱、撤销起诉和人员追责的具体规则。
- 反悔后撤销成年量刑减让的具体效果。
- 认罪或律师放弃无罪辩护等于放弃程序救济。

### 5.7 迁入少年司法必须增加的保护条件

1. **适龄说明和理解核验**：协议目标、选择、拒绝、撤回、材料用途和后果分段说明，不以签字替代。
2. **关系性支持**：儿童本人、律师、可信支持人和必要专业人员均可帮助，但须处理监护或律师与儿童偏好冲突。
3. **资源与合理调整**：语言、认知、残障、羁押、地域和家庭条件不能成为儿童协商能力不足或不利评价的理由。
4. **持续与可撤回参与**：决定前后均可表达、修正和撤回；撤回不自动等于不悔罪、失信或技术性违约。
5. **最低干预和比例**：先排除无条件退出和非正式支持；协议负担、数据披露、监督及撤销后果分别审查。
6. **国家义务不可交易**：合法取证、律师、说明、服务供给、错误纠正和救济不能由儿童用认罪或履行换取。
7. **法律效果和角色分离**：调查、协商、支持、决定、监督和复核尽量分离；法院或检察机关兼任多角时须有回避与独立复核。
8. **有效救济**：无效、排除、变更、撤回、申诉、上诉、赔偿和人员责任分栏，不以从宽结果替代。

## 六、新动作、实质修订、重复与饱和

### 6.1 新动作

`救济替代审计`是本批唯一明确的新动作候选。面对“量刑优惠、撤销条件、附加服务、程序便利”等看似有利结果，工作流须继续问：

1. 原违法或错误是否被否定；
2. 不利材料和结果是否仍被使用；
3. 违法机关或人员是否承担责任；
4. 儿童是否获得独立、可选择的救济；
5. 优惠是否以放弃异议、上诉或其他不可交易权利为条件。

该动作来自`TUL4PJQR`顺序页5—11、15—17／印刷页113—119、123—125。它暂并入`机构—权限—程序—效果—救济全链`，须经独立复核、少年司法24篇核心材料校验和对抗裁决后，才可能成为候选规则。

### 6.3 重复补强

以下内容与冻结根动作重复，不生成同义规则：
