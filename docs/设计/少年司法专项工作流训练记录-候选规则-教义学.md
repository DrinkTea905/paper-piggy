# 少年司法专项工作流训练记录：候选规则（教义学）

> 本文件是 40 篇正式训练素材经独立复核、原文裁决、作者纵向分析、交叉对抗和饱和审计后形成的有限根规则集。它不是已冻结的产品规则，也不替代正式写作时对现行法时效的核验。  
> `删除`项不得进入正面规则；`保留争议`项只能作为未决争议或压力项。陈瑞华、栗峥组只提供方法补强，不承载成年刑诉、证据法实体结论的直接迁移。  
> 下列每条规则严格只使用十二个指定字段。

## 一、正面候选根规则

```yaml
- rule_id: "JJ-DOC-001"
  workflow_type: "论文初稿（少年司法版）/教义学路线"
  scope: "界定现行法问题，排列规范位阶，选择解释方法，并分离解释论与立法论。"
  trigger: "进入任何少年司法教义学争点，或论证拟提出新权限、新效果、新例外、新救济时。"
  required_inputs:
    - "完整拟题、核心问题、制度阶段、适用法域和法制时点"
    - "现行法律、司法解释、规范性文件及生效状态"
    - "文义、体系、目的、历史和比较解释材料"
    - "作者建议、地方实践、经验事实与理论命题的来源标签"
  operation: |-
    1. 先确定待解释的规范对象是启动决定、持续状态、条件义务、事实认定、数据处理、撤销、记录后果还是救济。
    2. 按正式规范位阶排列法源，再使用文义、体系、目的、历史和比较解释；学说与经验材料不能自行产生权限。
    3. 把现行法结论、解释余地、规范缺口和立法创建分栏；解释论不得创设法律未提供的主体、强制权、终局效果或救济。
    4. 比较法必须携带管辖、组织、辩护资源、审查和救济前提；历史趋势只能解释演变，不能直接决定当前唯一答案。
  expected_output: "输出“法源—位阶—法制时点—解释方法—现行法结论—解释边界—立法建议”表，并使标题、中心观点和三级提纲保持同一规范层次。"
  exceptions:
    - "用户只要求立法论时，仍须交代现行法基线和提案所填补的缺口。"
    - "现行法时效尚未核实时，只能标为待核，不得用训练文献的法制时点替代。"
  failure_warning: "把作者方案、地方试点或训练综合写成现行法，会制造虚假权限；把解释论和立法论混写，会使中心观点失去法源支撑。"
  supporting_sources:
    - "`UVE565B9`，印刷页32—35：区分程序支持、能力、证明对象和规范适用问题。"
    - "`UBBSPRAD`，印刷页726—730、741—743；`XDVR96NW`，印刷页1217—1223：功能与模式受法制、组织和程序前提制约。"
    - "`KCEMBPA4`，印刷页87—93：方法补强；连接规范对象、体系、程序、效果和救济。"
  counterexamples:
    - "`UVE565B9`，印刷页23—29：历史、比较和发展材料不足以把七岁“恶意补足”方案变成运行时规则。"
    - "`XDVR96NW`，印刷页1220—1223：脱离少年司法优先及配套保障只移植例外移送，已被删除。"
  status: "候选-修正"

- rule_id: "JJ-DOC-002"
  workflow_type: "论文初稿（少年司法版）/教义学路线"
  scope: "按体系位置、真实功能和实际负担定性措施，并对例外实行法定前提审查。"
  trigger: "争点涉及保护处分、专门教育、观护基地、附条件不起诉、监督考察、教育矫治、非羁押支持或其他名称温和的安排时。"
  required_inputs:
    - "措施法源、规范目的和体系位置"
    - "进入、移动、活动、报告、期限、退出、数据和违约后果"
    - "无条件退出、更轻措施和自愿服务"
    - "例外的触发事实、证明、期限和复核"
  operation: |-
    1. 不以“保护、教育、支持、非羁押、处分”名称预定法律性质。
    2. 逐项审查进入是否强制、自由与身份负担、活动和报告义务、期限、退出、数据使用及追诉后果。
    3. 依据真实体系位置配置法律保留、参与、证明、期限和救济；目的正当只完成比例审查第一步。
    4. 任何例外必须列明法源、触发事实、证明主体、适用范围、最短期限、替代方案和独立复核。
  expected_output: "形成“名称—体系位置—功能—实际负担—权限—程序保障—例外—退出／救济”矩阵；无法统一定性的措施只给事实触发器，不强作一刀切结论。"
  exceptions:
    - "半开放观护基地的实质法律性质继续保留争议，须逐地、逐规则、逐负担判断。"
    - "现实、具体且迫近的风险可触发法定临时措施，但仍须最小、最短并迅速复核。"
  failure_warning: "以善意目的消除强制性，或把“比羁押轻”写成当然合法，会遮蔽长期监督、信息留存和恢复追诉的累积负担。"
  supporting_sources:
    - "`UBBSPRAD`，印刷页735—736：专门教育具有强制、不定期和限制自由属性。"
    - "`WMMXTGHA`，印刷页100、103—104：半开放基地存在离开审批、纪律、活动及表现报告。"
    - "`I94VN74H`，印刷页163、166、169—170：条件具有强制内核，并与期限、惩戒和撤销连接。"
  counterexamples:
    - "`UBBSPRAD`，印刷页727、735；`XDVR96NW`，印刷页1214—1216：保护、教育或亲权名称不能免除权限、比例和救济。"
  status: "候选-保留"

- rule_id: "JJ-DOC-003"
  workflow_type: "论文初稿（少年司法版）/教义学路线"
  scope: "闭合“机构—权限—程序—法律效果—例外—救济”规范链，并以实施链和信息链校验。"
  trigger: "论文解释或评价决定权、调查权、支持义务、条件设置、违约认定、撤销、限制自由、信息使用或救济时。"
  required_inputs:
    - "各阶段机构、法源、角色、要件、证明与决定标准"
    - "即时、持续、附随和终局法律效果"
    - "人员、经费、地域可达、服务和合理调整资源"
    - "信息来源、取得、转述、加工、共享和决定输入"
  operation: |-
    1. 每个争点闭合机构、权限、程序、效果、例外和救济六环。
    2. 规范链列法源、主体、要件、证明、决定、效果和救济；实施链列人员、经费、服务、合理调整、地区可达和失败反馈；信息链列来源、取得、转换、传递、复用、缺失和决定输入。
    3. 三链显式连线但不互相替代：实施困难不降低权利标准，信息可见性不取代关系与发展变量，技术可行不证明规范正当。
    4. 重大不利效果必须回溯到法定权限、中立决定、书面理由和有效救济。
  expected_output: "每个中心论证形成一组三联表，标明哪些来自现行法、实施事实或立法建议，并能从法律效果反向追溯权限、程序和救济。"
  exceptions:
    - "纯规范争点无实施或信息问题时，可将相应链标为不适用，但不得虚构事实。"
    - "紧急临时措施不得免除后续理由、期限和复核闭环。"
  failure_warning: "只画机构流程不写权限和效果，会把组织便利误作合法性；只写纸面申诉而没有独立、可达的审查，也不构成有效救济。"
  supporting_sources:
    - "`I94VN74H`，印刷页161—170：条件、报告、变更、惩戒与终结提供少年司法全链压力素材。"
    - "`KCEMBPA4`，印刷页87—93；`CMF3HLNP`，印刷页73—83；`N3BY3BRD`，印刷页123—133：方法补强；分别支持规范、实施和信息三链。"
  counterexamples:
    - "`SVNSFFZ3`，印刷页137、141：原检察院或上级检察院内部复核不能当然等同独立救济。"
    - "`UBBSPRAD`，印刷页735：同一委员会按学期评估但缺少申请、质证、理由和外部审查，不构成中立复核。"
  status: "候选-修正"

- rule_id: "JJ-DOC-004"
  workflow_type: "论文初稿（少年司法版）/教义学路线"
  scope: "分立规范资格／法律效果与来源结构／事实可靠性两道阈值，并按构成要件分配证明责任。"
  trigger: "争点涉及犯罪事实、责任能力、程序事实、材料资格、儿童陈述、电子数据、风险评估或合理怀疑时。"
  required_inputs:
    - "待证构成要件、程序要件和证明责任"
    - "材料取得法源、程序资格和拟产生的法律效果"
    - "原始来源、接触节点、派生材料、信息回流和实际隔离"
    - "追诉版本、疑点和替代解释"
    - "儿童获得的适龄说明、法律帮助与合理调整"
  operation: |-
    1. 分别审查材料是否依法取得并可用于该效果，以及材料是否独立可靠；不得合成单一分值。
    2. 按构成要件列待证事实，明确控方入罪证明责任与辩方提出合理怀疑门槛。
    3. 来源不同还须核验形成、传递和使用过程是否实质隔离；不运行概率乘法公式。
    4. 由追诉方、裁判者和复核者主动检验替代解释；儿童无须证明完整反方故事。
    5. 沉默、片段化表达、前后差异或无法组织完整叙事不得作不利推定。
  expected_output: "输出“要件—责任主体—规范资格—来源谱系—可靠性—合理怀疑—法律效果—异议／救济”表；任一阈值失败均不得由另一阈值补足。"
  exceptions:
    - "来源谱系只触发污染审计；角色冲突本身不直接证明个案材料已受污染。"
    - "儿童一方提出有利支持信息不改变控方犯罪事实证明责任。"
  failure_warning: "程序形式合格不等于事实可靠，材料看似可靠也不治愈违法取得；要求儿童提出完整替代故事会倒置证明责任。"
  supporting_sources:
    - "`UVE565B9`，印刷页34—35：控方承担入罪证明责任，辩方只须提出有根据的合理怀疑。"
    - "`C4D3DFJT`，印刷页21—28；`KCEMBPA4`，印刷页87—93：方法补强；规范资格、程序价值和法律效果。"
    - "`EWW6AFJP`，印刷页69—74；`TMF76MJS`，印刷页268—283：方法补强；竞争版本、来源关系和可靠过程。"
  counterexamples:
    - "`UVE565B9`，印刷页29：以行为严重性循环证明理解错误和责任能力，已删除。"
    - "`TMF76MJS`，印刷页268—283：非同源不足以证明统计独立，概率叠加已降为来源审计。"
  status: "候选-修正"

- rule_id: "JJ-DOC-005"
  workflow_type: "论文初稿（少年司法版）/教义学路线"
  scope: "分离行为时责任能力、当前受审能力、具体决定理解、参与偏好、处遇需要与国家支持义务。"
  trigger: "争点涉及年龄、责任能力、受审能力、认罪、同意、程序参与、心理评估、拒绝活动或支持需要时。"
  required_inputs:
    - "行为时与当前程序时点"
    - "具体决定、信息和任务"
    - "理解选项、预测后果、表达偏好、抵抗压力、求助和改变决定的能力"
    - "已提供与尚可提供的说明、时间、律师、合适成年人、环境和沟通调整"
    - "处遇需要、服务可达和儿童本人偏好"
  operation: |-
    1. 六个对象分别列标准、材料、判断主体、时点和法律效果，不得互相替代。
    2. 先提供适龄语言、充分时间、法律帮助、合适成年人、环境和沟通调整，再判断可补救障碍。
    3. 支持只能帮助发挥已有或发展中的参与能力，不能创造行为时责任、改变法定年龄或虚构最低理解。
    4. 不同意、沉默、拒绝活动、要求退出或未能服从，不得直接推定无能力或不适合轻缓处理。
    5. 对支持充分性和能力判断分别给出理由并配置独立复核。
  expected_output: "形成六分能力／支持表，并分别给出“已提供支持—支持效果—尚存障碍—可否继续程序—最少不利效果—复评／救济”结论。"
  exceptions:
    - "充分支持后仍达不到最低受审能力时，不得未经能力裁决继续；暂停、终止或退出的终局效果保留争议。"
    - "低风险事项不应为证明能力启动反复、侵入性测评。"
  failure_warning: "把法院支持称为‘法院受审能力’、把量表当责任能力、或以能被教会参与反推行为时可归责，都会混淆对象和效果。"
  supporting_sources:
    - "`UVE565B9`，印刷页32—35：区分行为时归责、当前受审能力、法院支持和证明责任。"
    - "`F2EI6QQ8`，印刷页125—127、131—134：知情、理解、表达、考虑和反馈反映参与状态与支持条件。"
  counterexamples:
    - "`UVE565B9`，印刷页30—34：以社会调查和人格心理资料综合证明恶意或受审能力，已删除。"
    - "`F2EI6QQ8`，印刷页126—127：拒绝、沉默或要求起诉不能自动解释为不理智或无能力。"
  status: "候选-保留"

- rule_id: "JJ-DOC-006"
  workflow_type: "论文初稿（少年司法版）/教义学路线"
  scope: "对社会调查、心理评估、观护记录和支持资料执行“字段—阶段—效果—主体—数据—救济”防火墙。"
  trigger: "报告、量表、家校资料、服务记录、表现证明或风险信息拟进入追诉、羁押、定罪、量刑、分流、处遇、撤销或记录时。"
  required_inputs:
    - "逐字段内容、原始来源、收集主体和支持关系"
    - "拟进入的程序阶段和拟产生的有利／不利效果"
    - "取得、披露、质疑、更正和保存情况"
    - "与犯罪事实、责任事实、支持需要和措施建议的对应关系"
  operation: |-
    1. 把犯罪事实、责任事实、处遇事实、支持需要、专业判断和措施建议分栏。
    2. 报告中出现的行为、结果、因果和主观罪过信息，只有脱离报告并按定罪证据程序重新收集、固定、披露和质证，才可进入犯罪事实判断。
    3. 家庭、贫困、学校、心理、保护因素和资源只可帮助形成更少限制、可执行的支持方案，不得反向证明危险、恶意、责任或加重。

  exceptions:

  failure_warning: "以报告名称代替用途审查，会让支持关系变成取证渠道；以背景、品格、测评或观护表现补足犯罪事实，会把结构性不利转成归责。"
  supporting_sources:
    - "`LIC6NDQD`，印刷页172—179：社会调查字段跨追诉、处分和支持阶段使用，暴露整体定性的局限。"
    - "`VHGF2QPQ`，印刷页103—109、115：量刑用途仍要求相关性、合法性、专业性、质疑和不利证明。"
    - "`WMMXTGHA`，印刷页98—99、104—106：观护表现进入后续处理，须建立有利用途与反向禁用防火墙。"
  counterexamples:
    - "`LIC6NDQD`，印刷页174—178：用成长、心理和支持资料补足核准追诉‘情节恶劣’，已删除。"
    - "`SVNSFFZ3`，印刷页138—139；`WMMXTGHA`，印刷页98—99、104—106：用观护表现证明起诉、定罪或量刑，已删除。"
  status: "候选-保留"

- rule_id: "JJ-DOC-007"
  workflow_type: "论文初稿（少年司法版）/教义学路线"
  scope: "使最有利原则、法定性、责任、无罪推定和比例共同工作，并分离危险、需要、资源及多方权利。"
  trigger: "论证涉及最有利原则、国家亲权、教育矫治、羁押、分流、风险评估、被害人保护、公共安全或严重案件时。"
  required_inputs:
    - "儿童即时与长期利益、本人意见和发展影响"
    - "犯罪事实、行为时责任、当前程序能力"
    - "被害人的具体权利、支持和即时安全事实"
    - "现实危险、支持需要和住所、保证、照护、教育、交通、治疗、服务可达"
    - "无条件退出、自愿支持、更轻措施、期限和复核"
  operation: |-
    1. 最有利原则贯穿解释、程序、处遇和执行，但不替代法定性、责任、无罪推定和比例。
```

## 四、解释论边界与状态分布

1. 现行法结论必须有现行有效法源；规范缺口不等于解释空间，立法建议必须另列。
2. 最有利原则须与法定性、责任、无罪推定和比例共同约束，不能互相替代。
3. 事实可靠、来源独立、心理判断或风险分数不能自行决定规范资格、法律效果和救济。
4. 陈瑞华组的问题化、规范链、角色和救济方法，栗峥组的来源谱系、竞争版本和可废止判断，只迁移动作，不迁移成年实体答案。
5. 保留争议只能具名呈现分歧、最低保障和待核法源，不得由路由或写作模板自动转成中心结论。
