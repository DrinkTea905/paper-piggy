## 四、独立复核与原文裁决对饱和判断的影响

### 1. 独立复核没有提供“连续两批无变化”

独立复核不是新的正式素材训练批次，不能拿来替代 A—H 的连续批次检验；但它们能够检验动作是否真的已经稳定。复核结果显示：

- 独立复核 01—03 对路线、持续参与归属、最佳利益与刑法原则、能力术语、证明负担、风险量化、公开参与、因果效果和退出救济作出多项实质修正、降级或删除。
- 独立复核 04 把社会调查用途进一步改成字段—阶段—效果审计，并删除以成长／处遇材料补足追诉门槛的过度迁移。
- 独立复核 05 保留参与与能力两类根动作，却实质补入拒绝、变更、撤回和救济边界，并删除服从等于理解的迁移。
- 独立复核 06 明确不把“覆盖—到位—作用”提升为新根动作，但修正了其操作定义、证据分母、到位时点和作用强度。
- 独立复核 07—09 对作者纵向“转向”、理性行动者、协商能力、律师替代、救济替代、非同源、概率叠列、二次检测和技术边界作出系统合并与降级。

因此，复核支持“根动作库在收束”，却同时证明动作的来源层级、命名、适用条件、反例和法律效果仍在发生实质变化。

### 2. 已完成裁决仍产生大量实质修正

截至本次审计，已完成的原文裁决包括：

- `原文裁决A-P0`：Q01—Q03，集中修正社会调查用途、能力区分和持续参与的来源与边界；

这些裁决没有扩张根动作库，主要在做合并、来源纠错、边界收紧和错误实体迁移删除；这正是词汇趋稳的证据。但其修正规模也说明，不能把“标签已经很少变化”误写成“动作内容已经连续两批不再实质变化”。

裁决波次不属于新的训练素材批次，不能单独组成严格标准所要求的“两批”；即使把它们视为验证波次，它们也明显不是“无实质修订”。

## 五、严格标准计算

严格标准固定为：

> 只有连续两批都没有产生新的方法动作，也没有实质修订既有动作的适用条件、证据等级、反例、八项迁移闸门、来源归属或实施边界，才进入饱和检查。

| 批次 | 新方法动作／候选 | 实质修订 | 是否可计为无变化批 | 截至该批的连续无变化批数 |
|---|---:|---:|---:|---:|
| A | 有 | 有／建立基线 | 否 | 0 |
| B | 有 | 有 | 否 | 0 |
| C | 有或实质强化 | 有 | 否 | 0 |
| D | 有，1 项新粒度候选 | 有，7 项 | 否 | 0 |
| E | 有 | 有 | 否 | 0 |
| F | 无新增根动作；有 2 项并入型子动作 | 有，7 项 | 否 | 0 |
| G | 有，1 项后被并入的候选 | 有 | 否 | 0 |
| H | 有多项候选 | 有 | 否 | 0 |

计算结果：

1. 当前连 1 个完整的“无新增且无实质修订”训练批次都没有。
2. 最长连续合格批次为 **0**，距离严格要求的 2 批仍缺 2 批。
3. 后续复核与裁决把多项“新增”并回既有根动作，不会追溯性地把原批次变成无变化批；因为被并入、改名或降级本身仍是对动作内容和边界的实质修订。
4. 因此，本轮只能认定**根动作词汇趋稳**，不能认定**严格训练饱和**。

## 六、为何可以说“根动作词汇趋稳”

1. A—C 的《试读标签稳定化》已经把大量文章标签合并为有限的根动作族，三批之间出现稳定复现。
2. D 批除一个新粒度候选外，其余新表述均主动并回既有根动作；独立复核 06 又明确不把该候选升级为新根。
3. F 批首次出现“零新增根动作”，两个新子动作在批内即被合并。
4. G 批唯一新候选在复核和裁决后降为既有全链中的子审计。
5. H 批虽然出现多个跨学科标签，但复核与裁决持续删除公式化、首创性和作者转向等过度表述，并将其收束到既有证据、信息、实施及综述组织框架。
6. 跨 40 篇反复出现的信号已经高度稳定：概念／功能分层、原则操作化、机构全链、名义—实质、支持性参与、能力—支持、证据用途、规范—实证校验、制度移植、多轴矩阵、最强反方、严重／低风险双向压力等不再因新文章数量增加而生成同义标签。

“词汇趋稳”只说明**命名空间和动作家族正在收束**；它不说明每个动作的输入、边界、来源、法律效果和少年保护条件已经停止修订。

## 七、是否触发额外 1—6 篇补文献

### 1. 方法缺口判准

只有出现下列情形之一，才足以触发额外 1—6 篇正式训练素材：

1. 某类目标任务在现有动作库中没有可执行的方法步骤，而不是只缺少某个实体答案；
2. 前向验证连续暴露同一种结构性失败，现有文章与裁决无法通过改名、合并或边界修正解决；
3. 某个必要根动作在独立复核和裁决后被整体删除，导致教义学、理论—制度建构或综述出现空白环节；
4. 现有材料只能提出问题，完全不能训练如何组织法源、理论、事实、机构、效果、反方或救济；
5. 少年司法八项闸门中的某一项无法落入任何问题化、论证、制度或综述组织步骤。

以下事项本身**不构成方法缺口**：

- 某一实体争议仍为“保留争议”；
- 某一统计效果缺少因果证据；
- 某一具体制度需要重新核对现行法；
- 某位作者的观点变化无法确认；
- 某篇待核材料尚未深索；
- 当前数量尚未达到 42—48。

### 2. 当前覆盖判断

现有 40 篇已经在方法层覆盖：

- 教义学路线所需的问题提出、概念拆分、法源与规范关系、证明与材料用途、机构权限、程序、法律效果、救济、反方和边界；
- 理论—制度建构路线所需的理论前提、类型／模式、经验诊断、制度组件、组织激励、资源、信息流、实施条件和副作用；
- 综述所需的范围、分类轴、理论谱系、概念演进、竞争模式、证据分层、作者内部继承／修正／张力和未决争议；
- 两条路线共同需要的严重案件与低风险案件压力、八项少年司法迁移闸门、合意性安排、原文忠实和不可迁移实体结论隔离。

独立复核和裁决虽然大幅修改具体表述，却没有删除任何一条路线完成任务所必需的整类方法，也没有暴露一个只能靠新增论文才能补上的空白步骤。

### 3. 本轮触发结论

**当前不触发额外 1—6 篇补文献。**

理由不是“已经饱和”，而是：

1. 当前尚未出现明确、可命名、不可由现有材料和裁决解决的方法缺口；
2. 继续补文献最可能增加重复例证，而不是补齐空白方法；
3. 前向验证尚未运行，现阶段无法知道真正的操作失败在哪里；
4. 为达到 42—48 而补数会把规模目标错误地变成准入降标压力。

若前向验证以后出现上述方法缺口，应只围绕具体失败点补 1—6 篇，同时维持相同准入门槛；不得预先广撒网，也不得把待核材料尚未就绪解释成降低标准的理由。

## 八、为何 40 篇可以进入下一阶段，但这不等于饱和

1. 已完成当前能够正式精读的全部计划内素材：24 篇领域核心、13 篇陈瑞华、3 篇栗峥。
2. 每篇均已有双卡和训练角色，作者纵向、跨作者对抗、独立复核与原文裁决已经为候选规则整理提供可追溯输入。
3. 35% 的独立全文复核达到既定抽检比例上限，且争议字段另有强制复核；下一步继续增加同类阅读，不如用未参与总结的题目检验动作是否真正可执行。
4. 前向验证本身是发现方法缺口的工具。只有让现有动作面对教义学题、理论—制度建构题、混合选题和三类综述题，才能判断其是否出现路由混同、双卡同质、标题—观点—大纲断裂、证据失真或少年司法专门性不足。
5. 进入下一阶段时，候选规则必须保持“裁决后、可修订、待验证”状态；任何验证失败都应先回到对应文章页、复核和裁决，而不是用“40 篇很多”压过问题。
6. `Z3GBTTSC`和第二篇新增栗峥论文若以后同时满足准入与逐页精读条件，仍须补双卡、训练角色、独立复核钩子和饱和再审；它们当前不阻止 40 篇进入验证，也不被视为已经训练。

因此，允许进入下一阶段的依据是**训练覆盖已经足以接受前向检验**，不是样本数量达标，也不是连续两批无新增／修订已经成立。
