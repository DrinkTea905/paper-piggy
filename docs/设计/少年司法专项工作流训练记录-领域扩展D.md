| `问题如何提出` | **作者明示**：国际少年司法已从把儿童作为保护客体，转向承认其为享有表达、理解和参与权利的主体；欧洲法院中的真实参与仍存在明显落差，中国少年司法也需把抽象参与权转成可观察的程序条件（顺序页1—4/印刷页158—161；顺序页8—13/165—170）。**训练综合**：把“是否允许出庭/是否签字”的静态问题改写成“儿童是否获得适龄信息、能理解、能表达、意见被考虑并得到反馈、可停止参与”的连续程序问题。 |
| `概念如何拆分和界定` | **作者明示**：参与不是一次性发言，而是信息分享和尊重对话；儿童表达意见是权利而非义务，可直接或经代表表达，并可在程序任一阶段停止（顺序页3—4/160—161）。作者又将有效参与拆成“理解”和“表达”两项标准：理解包括适龄说明、避免术语、解释结果及理由；表达包括可接受的空间、适宜沟通、照料、听取儿童及必要时听取父母（顺序页5—7/162—164）。**训练综合**：补成“信息—理解—表达—考虑—反馈—退出”六环；“父母参与”与“儿童独立支持”必须拆开，不能假设二者利益一致。 |
| `法源与规范关系` | 文章以《北京规则》《儿童权利公约》及儿童权利委员会第12号一般性意见等国际规范为参与权基础，并以欧洲程序观察检验规范实现（顺序页1—4/158—161）。中国部分把尊重儿童意见、适龄沟通、专业化和社会支持解释为现行未成年人特殊程序的实现条件（顺序页12—19/169—176）。**迁移闸门**：国际一般性意见、欧洲观察和中国现行法的规范位阶必须分别写明；域外操作不能未经国内权限和程序法源核对即直接移植。 |

| `机构、权限、程序、法律效果和救济` | **机构**：办案人员、法官、律师、监护人、社会工作者及专门少年司法机构。**权限**：原文强调官方提供参与机会和社会工作者支持，但未完整划定谁可限制或终止儿童表达。**程序**：适龄说明、避免术语、提问确认理解、提供安全表达空间、听取意见和反馈（顺序页5—7/162—164、顺序页14—18/171—175）。**法律效果**：意见应得到与年龄和成熟度相称的重视，但原文没有给出不同程序决定中的具体效力阶梯。**救济**：对未被听取、信息不足、父母冲突或支持无效的独立申诉与复核机制，原文未展开。 |

#### D1.2.1 少年司法迁移闸门

| 闸门 | 核验 |
|---|---|
| 最有利于未成年人原则 | 只能作为扩大儿童信息、表达和支持的保护性约束；替代儿童作决定须说明为何必要并接受复核，不能以“最佳利益”概括授权。 |
| 发展中能力 | 与年龄、成熟度相关，但能力应动态、任务特定并可通过说明和支持提升，不得按年龄一次性推定无能力。 |
| 支持性参与 | 原文贡献最强；训练时补足意见被考虑后的反馈和失败救济。 |
| 关系自主 | 父母、律师、社工既可能支持也可能控制；必须检查利益冲突、独立支持与儿童更换支持者的可能。 |
| 最小干预 | 表达是权利而非义务，儿童可停止参与；不参与不能自动产生不利评价。 |
| 比例原则 | 参与安排的强度、公开程度、空间限制和专业介入须与具体需要相称。 |
| 机构支持义务 | 适龄说明、语言转换、空间和专业人员是机构义务，不应转嫁给儿童证明自己“会参与”。 |
| 有效审查与救济 | 原文缺口；运行时必须追问未听取、误解、冲突代理或被迫表达时由谁复核及产生何种法律效果。 |

#### D1.2.2 低置信、新动作与复核钩子

### 3.2 对既有根动作的实质修订

1. **支持性参与闭环**：由“信息—表达—反馈”补强为“信息—理解—表达—考虑—反馈—退出”；父母、律师和社工同时进入支持与利益冲突审计。
2. **机构—权限—程序—效果—救济全链**：增加“监督不得替代”“一体化角色冲突”和“数字输入—使用—输出—异议/纠正”。
3. **规范—实证双向校验**：权利有效性不再以覆盖率终止，增加关键节点到位和实质作用；案卷记录、书面意见和实际影响须分层。
4. **能力—支持关系审查**：家庭、地区和服务资源不足不得反向成为羁押、危险或升级处分依据。
5. **法律效果全周期链**：增加去罪—免刑/从宽—非监禁—记录—替代处遇的谱系比较，并要求审查强度、期限、累计负担、可逆性和附随效果。
6. **多轴制度矩阵**：在对象、措施、机构、阶段之外增加“事实认定/证明”和“措施强度—保障强度”。
7. **解释论—立法论分层**：增加法制时点标签；旧文具体方案与可迁移方法必须双轨保存。

1. **参与与教育**：`6Z8PCVBF`要求表达自愿且可停止，`73SBPQTY`、`G8ZGD3PT`、`SAAI6XCH`中的教育、悔罪和矫治方案却可能把参与变成服从指标。候选规则必须明确“不参与不得自动不利评价”。
