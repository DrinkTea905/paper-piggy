- 通过受保护组件和 Windows 任务计划执行；普通文件处理使用未提升权限的同一用户令牌，只有 VSS 操作使用管理员能力。
- C、D 两卷进入同一个 VSS snapshot set；持续写入夹具中的主库和嵌套插件库保留有效 WAL。核验时原写入进程仍在运行。
- 两个独立完整归档分别成功：Zotero 数据及完整 profile；PaperPiggy 数据及正在运行的隔离 Chrome 资料。
- 恢复出的两份 SQLite 数据库均通过完整性检查，各含 233 条已提交记录，未提交事务记录为 0。
- 同批快照对实际来源只读枚举：Zotero 数据 8479 个文件、profile 232 个文件、专用浏览器排除缓存后 1017 个文件。96 个实际 SQLite 数据库副本全部通过 quick_check 和 integrity_check。没有生成或上传真实用户来源的 ZIP，没有修改活动数据库。
- 原生后台任务正常完成，LastTaskResult 为 0；验收任务无周期或登录触发器，结束后禁用。写入夹具正常停止，没有强杀用户程序。

## 文档与数据边界

产品内新手指引、Agent 指引、主仓库 README、独立教程的安装／备份／Agent 章节均同步；源码 README 和 macOS 说明也已核对。教程 README 和快速开始没有需要调整的步骤，保留原文。

正式安装目录保持只读，正式浏览器端口及资料关联沿用。没有执行真实来源原位恢复、自动删除历史备份、迁移系统密码、开启云同步或付费模型调用。

运行中备份保存快照时已落盘的内容；浏览器恢复后可能需要用户确认恢复会话，换机可能重新登录。Zotero 自动同步设置保持备份原值。用户更新后仍需在应用中选择目的地和周期，授权配置组件并首次执行自己的备份。
